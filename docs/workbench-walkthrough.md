# 工作台操作：本地采集数据与第 76 帧

打开本机工作台，保持现有数据。右上角“添加窗口”→类型“图像”→只勾选 camera_1/image→“添加窗口”→点图像窗口右上角的铅笔。右下角帧号输入 76 后按 Tab，再点左上“自动标注”，即可查看已有的 11 个候选（9 个托盘、2 个人）。

如果会话尚未设置参考帧，也没有参考帧描述，直接开始会返回“请先设置参考帧并保存其真值”。已有候选不代表已准备参考帧；没有本轮模型记录也不代表卡住。

当前独立演示会话已经由用户确认第 0 帧的 15 个参考轮廓，并完成第 76 帧真实运行，目标仍为未确认候选。[实际运行记录](test-results/reference-review.md)。已有参考帧和有效描述时，直接从步骤 5 开始。

1. 尚无参考帧时，点“参考帧准备”，进入“人工标注”。帧号输入 0 后按 Tab。
2. 类别选择 person 或 pallet，点“多边形”，沿目标轮廓逐点点击，最后“闭合”。逐个完成参考对象并检查。当前 MCAP 的人工参考标注使用多边形；“点选目标/生成轮廓”入口仅在单张图片模式显示。
3. 人工核对后点“保存当前帧真值”，再点“设为参考帧”。此步骤是人工确认，不应直接把未检查的模型输出当真值。
4. 切到“自动标注”；在参考帧点“生成真值描述”，等待得到描述和关键词。
5. 帧号输入 76 后按 Tab，“处理帧数”先填 1，点“开始自动标注”。
6. 按顺序查看“SAM 3 分割 → GPT 复查输入 → GPT 决策输出 → Agent 标注结果”。当前 GPT 按钮是界面名称，本机部署使用 Qwen3-VL；查看实际设置确认服务来源。
7. 人工检查类别和轮廓，确认无误后再点“保存结果”。该按钮把自动候选确认为当前帧真值。

早期导航演示验证了选源、进入标注、切帧、候选展示、缺少参考帧的真实 400 拦截和“参考帧准备”切回人工模式。保存状态摘要相同，没有保存演示真值，也没有声称已重新跑完整 Agent。新增引导和候选展示不改动原始数据。
