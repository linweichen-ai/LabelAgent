# 人员误覆盖诊断与安全约束改进

## 五张退步图的原因

逐张核对原图、人员预测、旧托盘掩膜、新托盘掩膜及投影点后，重新得到净增加 9 个参考点，分布为 1、1、4、2、1。九点全部在原人员预测保护区之外，距离原人员掩膜约 3.6～93.9 像素，因而原规则没有拦截。

其中可见人物边缘或手持物未被人员掩膜包含，也有参考投影落在人物轮廓外背景附近。后者可能涉及视角、遮挡或标定偏差，未据此修改参考标注或评分。诊断使用参考点定位问题；预测程序不接收这些点或案例编号。

## 新规则：保持旧原始点覆盖并集

使用相同真实 SAM3 候选池，仅允许新增候选覆盖旧四分块已经覆盖的原始可见点；同时仍要求覆盖全部旧可见点。这样在相同投影与3像素膨胀下，可见点并集保持，而各候选对这些点的组合可以改变。该规则不读取人员或托盘参考标签，也不改变任何原始掩膜、类别或置信度。

固定分数阈值0.5、NMS阈值0.8、原新增数量预算和全部原候选保持。原八项验收标准不变，每图点覆盖也不能退步。新方法优先保证旧四分块点覆盖与人员误覆盖不退步，尝试通过更合适的候选组合提升对象支持。
