# Ego 微孔尾部 VLM 独立复核负结果（Round485）

日期：2026-11-22

状态：离线影子复核负结果；不改 Round484 策略，不是真值或模型准确率

## 目的

Round484 的 camera1 低风险尾部共有 19 个组件，其中助手盲审认为 18 个较安全、1 个仍
不确定。本轮尝试让本地 `labelagent-vlm8b` 独立查看每个组件的多尺度复核图，检验 VLM
能否作为第二道语义确认。

VLM 只能在以下严格组合下返回 `likely_fill_ok`：图像证据清楚、目标位于同一实体表面、
不跨真实开口或背景，且置信度至少 0.85。任何模糊、低照或逻辑冲突都降级为
`uncertain`。

## 实测结果

| 项目 | 结果 |
| --- | ---: |
| 复核组件 | 19 |
| `likely_fill_ok` | 0 |
| `uncertain` | 19 |
| `likely_reject` | 0 |

| 单项平均耗时 | 5.399 秒 |
| 单项范围 | 5.133–6.281 秒 |

模型在运行前后均为 `status=ok`、`exact_requests_inflight=0`，19 次请求全部正常完成，
没有出现 `Local VLM is busy`。因此这不是服务故障，而是当前 8B VLM 对 1–15 像素微孔
物理边界缺少足够证据；典型理由均指出目标过小、低照或模糊，无法确认是真孔还是实体
表面漏分。

## 决策

本轮不接受把 VLM 加入微孔延后门禁，也不降低置信度阈值。Round484 的 227 个优先复核、
18 个延后人工复核保持不变，依据仍是两轮互不重叠的多尺度助手盲审。VLM 更适合类别、
场景和较大实例语义，微小边界应由高分辨率分割、几何信息或人工/助手局部复核处理。
