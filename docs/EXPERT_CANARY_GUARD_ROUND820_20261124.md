# Round820：外部专家8帧分层技术哨兵

## 目的

即使API合成图连通正常，真实批量运行仍可能遇到协议、延迟或Token异常。如果直接连续请求34张原图，异常发现得太晚。本轮在不增加51次授权上限的前提下加入8帧技术哨兵。

## 哨兵选择

34张全外部队列包含7种场景。算法先从每种场景各取1张，再补1张，当前8帧覆盖：

1. 批次B类别冲突；
2. 批次B平地困难负例；
3. 批次B坡道候选；
4. 密集托盘；
5. 斜坡困难负例；
6. 斜坡普通负例；
7. 斜坡正例；
8. 第二张类别冲突候选。

这8张属于34张原始任务的一部分，因此不会把最大调用数从51增加到59。

## 自动门禁

8帧完成后自动检查：

- 8次请求全部成功；
- Token用量逐帧完整返回；
- 中位延迟不超过60秒；
- 平均每次总Token不超过30,000；
- 没有自动重试或重复调用。

全部满足时自动继续剩余26张原图和17张缩放图；任一项失败则停止，不启动后续阶段，并写明失败原因。该门禁只检查技术健康，不评价分割或语义质量，不替代34帧人工复核。
