# Round778：混合困难集受控复核工作区

## 结论

34张混合困难候选包已经具备可实际完成复核的离线工作区。复核人必须逐张填写候选结论、斜坡存在性、车辆/机器人等类别冲突、托盘完整性和困难因素；页面支持浏览器本地断点保存，只有34张必填项全部完成后才能导出记录。

导出记录仍明确保持 `human_truth=false`、`approved_for_training=false`、`training_authorized=false`。它只证明有人完成了类别和问题类型复核，不等于像素轮廓真值，也不会自动进入训练集。

## 当前限制与下一步

1. 34张中的24张困难负例来自同一连续场景，仍需用不同序列替换一部分；
2. 当前只完成工作区生成，尚无声明复核记录，因此不能计算 Precision、Recall 或 F1；
3. 复核记录只覆盖类别和关键问题，不是完整像素轮廓标注；
4. 下一步先补充多材质斜坡及车辆/机器人冲突样本，再完成声明复核，冻结哈希后运行仅本地、全外部和混合路由三方案对比；
