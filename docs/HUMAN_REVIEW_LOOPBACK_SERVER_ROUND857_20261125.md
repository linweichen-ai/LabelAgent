# Round 857：困难帧人工复核本机安全入口

## 目的

34 张困难开发帧已经有完整的盲判工作区，但历史入口依赖人工查找本机 HTML 路径。Round857 新增跨 Windows/Linux 的统一启动器：启动前先核对回执、全部文件哈希和安全边界，校验通过后才在本机回环地址提供页面。

## 启动方式

```powershell
python tools/serve_mixed_hard_review.py <复核工作区目录>
```

默认自动选择空闲端口并打开浏览器。服务器只绑定 `127.0.0.1`，按 `Ctrl+C` 即可停止。只做完整性检查、不启动页面时使用：

```powershell
python tools/serve_mixed_hard_review.py <复核工作区目录> --check-only
```

## 安全行为

- 拒绝绑定公网或局域网地址；
- 启动前逐个验证 `receipt.json` 中的 SHA-256；
- 只允许浏览器读取回执明确列出的文件，其他工作树文件返回 404；
- 浏览器策略设置 `connect-src 'none'`，复核页不能调用外部接口；
- 复核集必须保持 24–40 帧，且必须是候选、非人工真值、非训练批准；
- 服务过程不修改工作区，不写正式工作台状态，不调用模型。

人工填写内容仍保存在复核页面自己的草稿与导出流程中。启动器只负责安全读取和展示，不代替人工做决定，也不会把未完成记录提升为真值。
