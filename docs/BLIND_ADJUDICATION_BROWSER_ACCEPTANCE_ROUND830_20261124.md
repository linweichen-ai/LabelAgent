## 验收发现并修复的问题

1. 旧生成器把样本 JSON 转成 `&quot;`。浏览器在 `application/json` 脚本中不会反解该实体，导致初始化脚本无法解析、页面标题为空。现改为保持合法原始 JSON，同时把 `<`、`>`、`&` 编码为 JSON Unicode 转义，阻断 `</script>` 注入。
2. 页面原先显示“高/中/低优先级”，会泄露机器置信度并影响盲判。现只显示中性“优先复核”，排序信息不展示。
3. 底部粘性操作栏在1440×1000视口中实际遮挡“托盘实例数”和机器建议区域。现改为正常文档流，浏览器实测表单交叠数为0。
4. 浏览器验收器会校验所有回执文件哈希、只绑定回环地址、拦截外部请求、拒绝非盲判工作区，并保留失败回执。
