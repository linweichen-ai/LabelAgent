# Round391：ego 提示点约束硬门禁（2026-11-22）

## 结论

本轮把“正点必须落入候选、负点必须落在候选外”从 SAM 服务的提示性警告，升级为 LabelAgent
本地独立复算的硬门禁。即使 SAM 没有返回警告，只要任一正点未覆盖或任一负点被吞入，候选就会
标记为 `blocked_prompt_constraint`、`candidate_available=false`，不能进入合并。

20 帧四相机复核包中，20/20 获得几何，14 帧可供人工复核，6 帧被提示点约束阻断，0 帧调用
失败。6 帧恰好也是 SAM 给出警告的帧，说明现有警告有真实几何依据，不能为了提高“通过数”而
静默忽略。

## 为什么不直接删掉有问题的提示点

camera1 当前第四个正点 `(x_ratio=0.641, y_ratio=0.970)` 在 0、38、76、114、151 五帧中均未被
当前候选覆盖。为避免把模板复杂度当成问题根因，本轮做了只读 A/B：

| 方案 | 结果 | 判定 |
| --- | --- | --- |
| 当前 4 正点模板 | 5 帧正点覆盖分别为 3/4、3/4、1/4、3/4、3/4 | 保留诊断，继续阻断 |
| 删除从未覆盖点的 3 正点模板 | 面积降至约 1.04%～1.19%，仍有警告；与当前候选 IoU 仅约 0.115～0.295 | 拒绝 |
| 单一稳定正点模板 | 警告消失，但面积仅约 0.90%～1.10%，分数约 0.094～0.235；与当前候选 IoU 仅约 0.099～0.226 | 拒绝 |

简化模板虽然能减少或消除警告，却把分割收缩成很小的一块，并不代表质量提高。因此没有替换
现有模板，也没有用“无警告”冒充正确分割。
