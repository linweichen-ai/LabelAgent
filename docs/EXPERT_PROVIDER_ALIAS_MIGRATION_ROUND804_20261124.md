# Round804：外部专家旧协议别名兼容与实时复测

## 背景

本机安全配置中仍保留早期界面值 `openai`，而加固后的运行时只接受明确的传输协议
`openai_chat`。这会让已经正确保存的 API Key 在调用前被命令行参数校验拒绝，容易被误判为
“外部 API 不可用”。

## 修改

- 仅兼容早期本地配置页已经产生过的 `openai`、`qwen`、`custom` 三个界面值；
- 三者进入运行时、缓存键、熔断键、服务端配置和浏览器公开配置前统一规范为
  `openai_chat`；
- 未知协议继续失败关闭，不扩大允许范围；
- 密钥仍只从环境变量读取，不进入页面、状态、日志、仓库或回执；
- 正式外部专家开关与影子路由仍保持关闭，本轮没有部署。
