# Round770：正式覆盖发布后只读验收器

## 目标

新增 `tools/verify_formal_minimal_overlay.py`，用于正式覆盖完成并重启后进行只读验收。它不会修改候选、真值、训练状态或正式文件。

## 验收范围

验收器同时要求：

1. 6 个正式目标文件全部与冻结候选 SHA-256 一致；
2. `/api/run/status` 返回 `idle`；
3. 可选托盘复核状态为 HTTP 200，并保持只读、未部署、真值写入 0、训练写入 0；
4. `slope-round160` 专项复核包成功加载；
5. 优先队列精确为 frame 95、140；
6. 优先记录继续保持助手建议、非人工真值、未批准训练、禁止自动提交；
7. 验收过程只发 GET，请求写入数固定为 0。

- 与部署器组合测试 8/8 通过。
