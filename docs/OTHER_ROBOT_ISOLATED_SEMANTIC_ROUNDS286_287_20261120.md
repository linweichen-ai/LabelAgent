# `other_robot` 隔离语义门禁复核（Round 286–287）

## 结论

本轮新增的是**离线诊断开关**，不是生产功能。它会在上下文与正例参考都支持
`other_robot`、且候选确实是物体之后，再只看候选像素做一次语义复核：

- 隔离像素仍明确支持 `other_robot`：允许保留自动候选；
- 隔离像素只能判断为 `unknown_object`：降级到人工复核；
- 隔离像素明确属于 pallet、货物、货叉、自车或其他已知负类：拦截；
- 没有任何结果会写成人工真值或进入训练集。

这道门禁在当前十图助理预审集上没有提升自动化效果，因此**不接入正式工作台**。
它保留为可显式开启的离线诊断工具，用于后续拿到当前人工真值后继续验证。
