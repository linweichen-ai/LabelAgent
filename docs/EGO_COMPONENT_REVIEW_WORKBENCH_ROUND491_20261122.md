# Round491：微孔聚焦复核工作台接入

日期：2026-11-22

## 本轮目的

把 Round488 生成的 19 项微孔聚焦证据包接入 LabelAgent 工作台，降低人工逐文件查找成本；
同时保持严格隔离：这里只提供只读证据和当前浏览器会话草稿，不修改候选 mask，不写人工
真值、训练集、正式审核记录，也不触发自动审批。

## 已实现

- 新增“微孔复核”入口，显示当前可复核项数量。
- 新增独立复核弹窗，支持优先/延后、待复核/已暂存筛选与分页。
- 每项显示聚焦证据图、组件标识、相机排名、像素数和策略理由。
- 允许暂存“倾向可补 / 不确定 / 倾向驳回 / 清除”四种会话草稿。
- 草稿只保存在当前浏览器会话中；刷新同一会话可恢复，新浏览器会话从零开始。
- 草稿同时绑定 manifest SHA-256、组件 ID 和图片 SHA-256；证据包或图片变化后旧草稿不复用。
- 服务端只有 GET 接口；组件复核命名空间没有 POST、PUT、PATCH 或 DELETE 写接口。
- 服务端校验候选态标志、队列、数量、唯一组件 ID、连续相机排名、图片哈希和图片可解码性。
- 图片只允许读取证据包目录内的基名文件，并返回 `no-store` 与 `nosniff`。
