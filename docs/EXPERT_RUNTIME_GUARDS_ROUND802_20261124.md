# Round 802：外部专家缓存、重试、熔断与本地回退

## 目的

让“本地 Qwen8B 优先、困难帧调用外部专家”的方案在外部接口超时、限流或短时不可用时仍能继续运行，同时避免对完全相同的请求重复付费。

## 已实现

1. **精确结果缓存**：缓存键绑定协议、地址、模型、输出长度、提示词、响应结构和所有图像内容哈希。只有完全一致的请求才会复用结果。
2. **有界缓存**：默认保存 128 项、有效期 3600 秒；最大项数和有效期均可配置并受范围限制。
3. **有界重试**：外部超时、HTTP 408、429、5xx 和网络暂时不可用时，默认最多重试 1 次；范围限制为 0～3 次。
4. **熔断保护**：连续重试仍失败后，默认暂停该外部模型通道 60 秒，避免每一帧都重复等待失败接口。
5. **缓存优先**：即使外部通道正在熔断，完全相同且已有成功缓存的请求仍可直接返回，不产生网络调用。
6. **本地安全回退**：外部接口失败、凭证临时缺失或返回格式损坏时，保留已有本地结果，并明确记录回退原因。
7. **SAM 结果复用**：回退记录固定声明 `sam_result_reused=true`，不重复已经成功的 SAM3 分割。
8. **可观测性**：调用轨迹记录外部重试次数、缓存命中状态和脱敏请求键，不记录 API 密钥。

## 配置项

| 配置 | 默认值 | 允许范围 |
| --- | ---: | ---: |
| `llm_expert_retry_count` | 1 | 0～3 |
| `llm_expert_cooldown_seconds` | 60 秒 | 10～3600 秒 |
| `llm_expert_cache_ttl_seconds` | 3600 秒 | 1～86400 秒 |
| `llm_expert_cache_max_entries` | 128 | 1～1024 |

这些配置已经进入模型配置校验和 `/api/model_readiness` 只读状态输出。

## 测试证据

- 外部专家专项测试：15 项通过。
- 相关全量测试：308 项通过、87 项子测试通过。
- 覆盖场景包括：精确缓存、缓存期间熔断、HTTP 503 回退、HTTP 429 重试后恢复、缺少凭证回退、不同外部协议以及密钥不进入轨迹。
