# Round494：VLM 后训练数据精确隔离审计

日期：2026-11-22

## 为什么做

已有 Qwen3-VL-2B LoRA 使用 62 条机器教师样本训练，并在 8 条内部开发样本上反复比较。
继续训练前必须先排除最基本的数据泄漏，避免把重复图片或同一来源帧带来的虚假提升当成泛化。

## 审计对象

- train：62 条，序列 000–007；
- dev：8 条，序列 008；
- test24：24 条，序列 010–012，永久只评测；
- 输入清单分别绑定 SHA-256，审计器会先核对清单本身未被修改。

## 结果

精确隔离审计通过：

- 每个 split 内的 sample ID、图像 SHA-256 和来源身份均唯一；
- train/dev、train/test24、dev/test24 之间的 sample ID 交集均为 0；
- 三组之间的图像 SHA-256 交集均为 0；
- 三组之间的来源序列+帧 ID+相机交集均为 0；
- 三组之间的来源序列交集均为 0；
- test24 的 `evaluation_only=true`、`training_return_allowed=false` 保持成立。

train 与 dev 有 4 种相同的 `target_sha256`。这表示两组中存在相同类别 evidence 答案模式，
不表示图片重复，也不构成精确数据泄漏；但它提示当前内部 dev 的语义多样性仍有限，不能仅凭
dev8 的 62/64 教师一致率宣称泛化。

## 明确未验证的部分

本轮没有宣称“近似重复已经排除”。冻结 JSONL 只包含图像 SHA 和远端路径，没有绑定在本机
可读的像素文件，因此无法可靠计算 pHash、CLIP 相似度或逐像素近重复。审计结果将该项保存为
`not_evaluated_without_bound_image_bytes`，而不是错误地写成通过。

## 新增可复现门禁

新增 `tools/audit_vlm_split_isolation.py`，会对清单哈希、数量、序列、真值/训练边界和三组精确
交集失败关闭。三个定向测试覆盖正常通过、跨 split 图像 SHA 泄漏、test24 回流与序列漂移。

机器可读结果：
`artifacts/round494-vlm-split-isolation-audit-20261122/audit-v2.json`

## 决策

现有 2B LoRA 候选可以保留为“精确隔离已通过的离线机器教师候选”，但仍不能部署：它没有
人工真值训练，dev8 很小，近似重复未验证，也没有全新未曝光外部集。下一步应先取得绑定像素
的训练/开发图像副本或在数据所在服务器运行只读近重复审计，再决定是否继续扩大训练。
