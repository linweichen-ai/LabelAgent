# 用三维参考检查二维候选覆盖

更新日期：2026-11-04（北京时间）。本轮新增可复现的稀疏参考指标，并测试图像分块是否补回托盘候选。完整验证仍在运行；调参结果不是二维像素准确率，也不代表 VLM 已改善自然错误。

## 参考及坐标检查

沿用用户指定的 `labels` 全部 152 帧。剔除 74 个忽略框后，共 4,045 个三维参考框，其中 3,285 个为托盘。托盘高度中位数约 0.154 米；尺寸与底座相符，但来源语义未经过独立人工认证。

先比较“框已在 LiDAR 坐标系”和“框在世界坐标系”的点云支持，再查看 0、76、151 帧四路相机的投影。第 151 帧，前一解释有 2,116 个点框归属、22 个框至少有 3 点；套用额外轨迹变换后为 259 个点框归属、3 个框。第 76 帧的人员点支持亦明显支持前一解释。因此本轮不额外套用轨迹位姿。该判断是对现有数据的检验，不能替代独立外参标定。

使用包内显式标定的 PINHOLE 内参和 LiDAR 到相机变换；不正交化或优化原矩阵。投影采用 [OpenCV 标定文档的相机投影关系](https://docs.opencv.org/4.13.0/d9/d0c/group__calib3d.html)。本工具遇到非零畸变、非刚体外参、错误尺寸或摘要不符会拒绝评估，不静默套用简化模型。

源文件、候选文件及每张输入图像都由导入摘要和预测收据绑定。基线 1,216 个历史真实 SAM3 响应的图像摘要及轮廓已与候选缓存核对，不能把任意候选文件通过改名解释成已执行推理。

## 指标 V2

只将非忽略三维框内、能够投影到图像中的 LiDAR 点作为稀疏参考。相机深度大于 0.2 米，8 像素单元内保留距最近点不超过 0.15 米的点，近似处理遮挡。未知区域及跨类别重叠点不作为负例。稀疏深度和粗网格不能完整解决遮挡及 LiDAR 与相机视差。

- **点覆盖**：同类候选并集覆盖的已知同类投影点比例，报告 0、3、6 像素容差。
- **实例支持率**：一个参考框至少有 5 个唯一归属可见点，单一候选覆盖至少 50% 该框点，且所覆盖的已知同类唯一实例点至少 67% 属于该框；再作同类一对一匹配。
- **异类覆盖**：例如托盘候选覆盖人员参考点的比例。未知区域没有像素真值，不能据此计算掩膜精确率。

最初版本只有 50% 覆盖条件，两个近乎相同的大掩膜可能分别匹配相邻对象、虚增实例数。V2 加入上述 67% 归属条件；解析反例测试证明原条件会计 2 个匹配，新条件计 0 个。修订没有改变任何掩膜或点覆盖数。全部方案都按 V2 重新计分，不混用版本。

分母是跨时间和视角的**对象观测数**，并非去重后的物理对象数。它衡量对现有三维参考的稀疏支持，不是二维 IoU、召回率认证或准确率。

## 调参探索与冻结

固定第 15、45、76、105、135 帧四路相机共 20 张为调参图，其余 588 张仅在方案选定后生成新的分块预测。全部来自同一段约 84 秒采集，存在时间相关；部分帧先前做过功能检查，不能声称为独立场景盲测。

先完成 `wooden pallet`、`plastic pallet`、`pallet base` 共 60 次真实 SAM3 请求，并比较两种并集方案。单独限定材质会丢失其他材质对象；合并 `pallet base` 虽有小幅实例支持增益，候选数从 143 增至 249，超出事先设定的 1.5 倍上限。按同一门槛，关键词探索未选出方案。

随后固定使用 `pallet`，对每张 1920×1536 图执行四个 1152×922 的重叠裁图，共 80 次真实 SAM3 请求。裁图位置只由图像尺寸决定，预测过程不读取参考框、点云或相机标定。各部分及孔洞按偏移映回原图；接触内部裁图边缘 2 像素内的候选被丢弃，原图外边缘允许保留。

保留全部基线掩膜及人员候选，新增托盘按 `confidence × (1 − 最大基线 mask IoU)` 排序；基线优先，以 0.8 mask IoU 去重。单图新增上限为 `max(1, floor(基线托盘数 × 预算比例))`。

第一阶段尝试置信度 0.8、0.9，预算 0.25、0.5，无实例支持增益。第二阶段在同一调参集复用并重新核验这 80 个响应，探索置信度 0.5、0.6、0.7，未新增推理请求。它属于迭代调参，不能当作新的独立验证。两阶段的全部结果均披露。

选取条件在首阶段前固定：实例支持至少提高 2 个百分点、托盘点覆盖不下降、人员异类覆盖最多增加 0.5 个百分点、托盘候选总数不超过基线 1.5 倍、并集面积不超过 1.25 倍。

| 20 张调参图 | 基线 | 选中方案：置信度 0.5、预算 0.5 |
| --- | ---: | ---: |
| 托盘实例支持 | 68/118 = 57.63% | 75/118 = 63.56% |
| 托盘点覆盖 | 79.37% | 82.32% |
| 托盘候选覆盖人员点 | 0.443% | 0.497% |
| 托盘候选数 | 143 | 190 |
| 托盘并集像素数 | 784,762 | 836,336 |

调参增益为实例支持 **+5.93 个百分点**、点覆盖 **+2.96 个百分点**。面积和数量增加并不等于新增正确掩膜；最终仍须复核。关键词失败、各档分块参数和错误删除对照见 [全部调参聚合](projected_support_studies.json)。

## 复现

安装现有模型环境及 `tools/requirements-comparison.txt`。先用经实际推理收据核验的候选导出进行只读评估：

```sh
python tools/evaluate_projected_support.py --dataset <dataset> --candidates-json <predictions> --prediction-receipt <receipt> --output <new-evaluation-directory>
python tools/collect_tiled_candidates.py --dataset <dataset> --candidates-json <verified-baseline> --prediction-receipt <baseline-receipt> --frames 15,45,76,105,135 --minimum-scores .5,.6,.7 --addition-ratios .25,.5 --output <new-tuning-directory>
```

候选收据须包含 `archive_sha256`、原始候选 JSON 的 `prediction_json_sha256` 及 `image_sha256[topic][frame]`；图像摘要须与实际请求输入核验。工具检查文件绑定，不替代对收据来源的审计。

验证阶段加 `--frames heldout --minimum-scores .5 --addition-ratios .5 --frozen-selection <tuning-selection>`。选取文件须记录 V2 指标摘要、调参选择依据、唯一参数和完整验证帧范围。所有输出目录必须新建；中断后核实旧进程已结束再以相同参数加 `--resume`，代码或输入摘要漂移会被拒绝。在输出目录创建 `STOP` 文件可于请求间停止，保留已完成的响应；恢复前移除该文件。模型服务及工作台不会因此被结束。

原始图像、逐对象参考与候选轮廓、裁图响应、私有路径和模型权重继续只在本机保存。
