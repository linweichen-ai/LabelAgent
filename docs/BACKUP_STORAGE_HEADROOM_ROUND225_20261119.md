# 第二百二十五轮：回滚备份无损迁移，恢复工作台磁盘余量

日期：2026-11-19  
状态：已完成本地空间治理、逐包校验、服务与正式状态复核

## 通俗结论

正式工作台上一轮重启时明确提示数据盘可用空间低于 2 GiB。代码和模型虽然正常，但继续导入新数据、生成缓存或保存结果时，磁盘过低可能造成中途失败，直接影响演示和新数据集体验。

本轮没有删除回滚证据，而是把 128 份普通工作台回滚包原字节迁到 C 盘，并在 D 盘原路径建立目录联接。历史文档中的路径仍可直接打开，正式工作台数据盘从约 1.84 GiB 提升到 3.02 GiB，超过 2 GiB 警戒线。唯一 2.86 GiB 的 Mask2Former 权重恢复包仍留在 D 盘，同时在 C 盘建立一份逐文件验证通过的压缩归档。

## 发现依据

正式启动器的运行临时目录位于：

`D:\Apps\LabelAgent\.local\runtime-temp\workbench-8765`

启动器规则为：

- 低于 256 MiB 时拒绝启动，避免保存损坏；
- 低于 2 GiB 时输出明确警告，要求先释放可恢复空间再导入大批量数据。

本轮治理前使用 `DriveInfo` 读取到 D 盘约 1.84 GiB，确实低于警戒线。`D:\Apps\LabelAgent\.local\backups` 共 129 个回滚目录，其中：

- Mask2Former Round157 恢复包：2,999,265,523 字节；
- 其余普通回滚包：约 1.74 GB 逻辑内容；
- 普通回滚包多为代码、状态、文件会话和运行回执，适合迁移后用目录联接保留旧路径。
