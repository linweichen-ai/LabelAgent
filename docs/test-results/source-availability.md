# 未标记源图的可用性检查

独立离线回放完整29例、58份已保存的卡片模型回答。两处合成空白原先均被一致判为托盘；检查源裁片后，两处均输出不确定，四个视图误报被拦下。其余27例的类别完全保持：19处人工确认区域仍14处正确一致、1处一致错类，原整体条件仍未通过，未接入工作台默认流程。

## 规则及实验性质

上一轮59次真实请求已经暴露空白幻觉。本轮据此开发保护规则，在另行固定全部29例、源文件摘要和规则后回放。这是已知失败样例上的事后开发验证，没有新增模型推理或独立测试集，原59次试验的原回答、失败项和判定保持。

检查对象是制作卡片前的同一份**未标记源裁片**，文件摘要与上游记录、卡片来源摘要交叉核对；不能用有轮廓、文字或边框的展示图替代。单帧RGB／灰度图解码后，如果RGB三个通道的空间极差都严格等于0，则无法从中确认目标类别，输出不确定。损坏、不支持的颜色模式和多帧输入也要求不确定；实际29例均为可读单帧RGB。

没有近似空白阈值或阈值搜索，也不读取样例编号、参考角色、预期类别、模型理由或分数。只要一个像素相差一个亮度级，就继续保留原判断。该检查只判断输入是否可用于后续复核；非均匀图并不因此成为有效托盘。所有恒定颜色都同等处理，包括纯红色。
