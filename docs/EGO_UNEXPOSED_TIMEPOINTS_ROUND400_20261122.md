# Round400：camera1 未曝光时间点固定提示族复核（2026-11-22）

## 目的与边界

Round398 的固定三组提示只在九个已曝光时间点上验证过。本轮不改提示点、不改组合、不改90%原候选保留门槛，先从同一 camera1 序列的152帧中排除已曝光的9帧，再按时间均匀冻结24个未曝光时间点，检查它是否只是记住了少数帧。

这24帧仍来自同一条序列，因此是“同序列未曝光时间点”，不是独立数据集，也不能证明跨工厂泛化。输出仍为影子候选，不写正式工作台、不作为人工真值、不批准训练。

## 冻结设置

- 已曝光帧：0、19、38、57、76、95、114、133、151；
- 未曝光帧：1、7、13、21、27、33、40、46、52、60、66、72、79、85、91、99、105、111、118、124、130、138、144、150；
- 固定提示族：`[3]`、`[0,2]`、`[1,3]`；
- 固定负点：沿用Round398的三点；
- 接受条件：四个正点均覆盖、负点侵入为0、且合并候选保留至少90%原候选像素；
- 每帧只追加3次point-SAM请求，不做结果驱动的补点或阈值调整。

## 关键发现

通过率不是均匀的。前半段帧1至72的12个样本只有2个通过，而后半段帧79至150的12个样本全部通过。助手只读总览显示，前半段车辆、驾驶员和相机相对姿态变化更大，固定图像坐标容易落到不同可见部件或只覆盖局部；后半段姿态稳定后，固定提示连续通过。

这项观察只是候选几何与提示一致性分析，不是人工像素真值。总览中没有发现固定负点被吞入，但不能据此声称person/floor误纳已经满足正式质量门槛。

## 决策

- 不部署Round398固定提示族；
- 不根据这24帧继续调整固定坐标、组合或0.90门槛；
- 不把14/24解释为分割准确率或跨数据集泛化；
- 下一优化方向改为随车体可见区域变化的几何/时序自适应提示，并必须在独立序列或人工像素真值上验收；
- 在达到固定的逐相机IoU与person/floor误纳门禁前，不批准训练、微调或自动合并。
