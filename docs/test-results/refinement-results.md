# 裁图、近似重复和完整 Agent 复验

更新日期：2026-11-04（北京时间）。本轮识别出两类质量退步，均未设置为工作台默认流程。原有 [分块参考结果](projected-support.md) 继续保留，不能把本轮流程完成当作像素准确率或大模型修正能力。

## 候选自身像素与视觉采样

为减少上下文中的其他托盘干扰，新增三张复核视图：候选自身的原始像素（其他区域置灰）、原始上下文、带独立轮廓的上下文。孔洞和多部分按原候选栅格处理；原图及输入候选不修改。

在同一组 8 个困难候选及两张空白图上预先规定：空白图不能被接受、5 个助手目视可辨的托盘示例不能被拒绝、其中至少 3 个应被接受，可疑亮点不能被接受。这些是定性功能示例，没有增加独立人工真值。每例分别询问候选自身和带上下文视图，仅在两次都判为托盘时接受。

实际 Qwen3-VL-2B NF4 请求共 20 次：8 个自然候选为 0 接受、1 拒绝、7 不确定，5 个托盘示例均不确定；两张空白图也不确定。它避免了直接接受可疑亮点，却没有达到有用的自动识别条件，因此不采用。

真实图像处理器检查发现：默认每图上限为 256，并不意味着每张裁图都分配 256 个视觉 token；三例小裁图实际每图约 70–76 个。随后保持模型、提示、输出 schema、原裁图和判定规则不变，将图片按比例上采样到不超过 `256×32×32` 像素、尺寸取 32 的倍数，再做 20 次真实请求。它增加编码器采样密度，没有增加源图细节。结果仍为 0 接受、1 拒绝、7 不确定，未达到原定条件。

这组试验只能排除“单纯放大这些输入即可达到本组目标”的假设，不能断言所有图片都不受分辨率影响。提示中的保守措辞与碎片轮廓本身仍可能影响判断。[视觉对照及处理器计数](refinement_visual.json)

## 真实完整 Agent 的八图检查

另对第 76、119 帧四路相机共 8 张图，从真实 SAM3 重新生成，执行分块、上述几何合并、生产版本 Qwen 复核及 Agent 工具循环。参考仍为第 0 帧的未确认功能示例，未转为人工真值。固定类别关键词以比较几何处理，大模型生成的详细说明继续用于复核。

实际完成 48 次 SAM3 请求、1 次 VLM 说明生成和 8 次 VLM 复核；8/8 流程均正常结束。几何预处理发生 12 次合并，大模型工具编辑为 **0 次**；几何预处理不能计为 VLM 的多轮修正。
