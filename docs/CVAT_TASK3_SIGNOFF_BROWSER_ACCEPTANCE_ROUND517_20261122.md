# Round517：离线人工签字复核台真实浏览器验收

## 目标

Round516 已在 Node VM 中验证草稿逻辑，但尚未证明真实浏览器里的下载、刷新、文件导入和按钮门禁能连续工作。本轮新增只访问本机回环地址的 Playwright 端到端验收，补齐用户实际操作链路，不替代人工签字。

## 验收流程

1. 用临时 HTTP 服务在 `127.0.0.1` 随机端口打开冻结的81项复核台。
2. 在首项填写一条合成人工字段，真实点击“导出草稿”并捕获浏览器下载。
3. 刷新页面，确认未导入前内存字段为空；再通过文件选择导入草稿并确认字段恢复。
4. 篡改首项聚焦证据哈希，确认整份草稿失败关闭，且此前恢复的决定、复核人和备注均不被覆盖。
5. 在正式导出仍禁用时，导入一份仅供测试的81项完整合成草稿；确认按钮随后解锁并捕获正式 JSON 下载。
6. 回读正式 JSON，确认 `training_authorized`、`automatic_approval`、`approved_for_training` 以及每行 `approved_for_training` 均为 `false`。

## 安全边界

- 浏览器只允许访问当前临时服务的 `127.0.0.1` 随机端口；任何外部请求都会被阻止并使验收失败。
- 临时草稿、正式导出和服务目录在结束后清理；浏览器与 HTTP 服务在成功或失败时都关闭。
- 输出目录必须预先不存在，回执文件使用排他创建，避免覆盖已有证据。
- 截图默认不生成；只有显式传入 `--screenshot` 才会保存。截图包含私有证据图和候选身份，必须留在 `.repro/`，不得上传公开仓库。
- 合成81项只测试浏览器门禁，不是人工真值，不构成训练授权，也不写回原始签字模板。

## 真实结果

- 冻结页面 SHA-256：`1a682ea7711d0cc165b9984e8016a46df289e6e72e37eb2fdeba46197a417e6d`。
- 候选数：81；部分草稿往返、刷新后恢复、坏绑定拒绝、正式导出门禁和完整合成导出均通过。
- 外部请求：0；页面错误：0。
- 无截图复跑耗时：1,407 ms；带私有截图的首次实跑耗时：1,680 ms。
- 正式导出三项训练/自动批准标志全部为 `false`。
- 定向静态测试4项、Round516 Node草稿测试1项（含39种攻击拒绝）、Python关联门禁37项均通过。

## 复现

先按 Round515–516 生成私有复核页，然后运行：

```powershell
node tools/browser_cvat_human_signoff_draft_acceptance.cjs `
  --page .repro/cvat-task3-human-signoff-reviewer-round516/index.html `
  --output .repro/cvat-task3-signoff-browser-acceptance-new
```

若确需截图，可在命令末尾加 `--screenshot`，但输出必须留在 `.repro/`。

## 当前边界

本轮确认了浏览器工作流可用，并未替81项做真实人工判断。真实签字仍为0，自动批准为否，训练授权为否；只有人工完成复核并通过 Round513–514 导入门禁后，才能形成受保护的人类复核集合，且仍需另行训练授权。
