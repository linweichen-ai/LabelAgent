# Round528：启动、停止与恢复共享生命周期互斥

## 问题

Round527 只串行化启动动作。停止或陈旧记录归档仍可能在启动尚未完成时读取记录、停止刚创建的进程，或与原子记录安装发生竞争。

## 实现

共享逻辑抽到 `tools/lifecycle_mutex.ps1`，启动与停止脚本均使用同一个按克隆绝对路径派生的 Windows 本地命名互斥锁：

- 启动在读取旧记录、预检、创建进程、安装记录和最终服务读回期间持锁；
- 停止在读取身份、停止进程、删除记录或归档陈旧记录期间持锁；
- 并发动作在任何状态读取或进程操作前快速失败；
- 不同克隆仍使用不同锁；
- 脚本崩溃后由操作系统释放，废弃锁可被后续动作接管；
- 不创建磁盘锁文件。

## 真实双进程测试

独立 PowerShell 进程持有共享生命周期锁时：

- 启动命令快速失败并明确报告已有生命周期动作；
- 停止命令同样快速失败，未读取或修改进程记录；
- 锁释放后，启动重新进入原有端口/权重预检；
- 锁释放后，停止命令正常返回“无本地受管记录”；
- 测试未创建新服务，也未停止或重启既有工作台。
