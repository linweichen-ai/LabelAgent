## 实现改动

外部专家调用现在会保留经过白名单过滤的运行元数据：

- 实际路由；
- 是否命中相同请求缓存；
- 请求哈希；
- 重试次数；
- provider 与 model；
- prompt、completion 与 total token 数。

密钥、请求原图、完整提示词和原始模型文本不会进入这些元数据。缓存命中时会沿用原请求的 token 回执，但不会把缓存读取误算成新的付费调用。

Round807 的真实困难帧执行器已同步记录逐帧元数据和整批 token 汇总，包括有用量回执的帧数、缺失回执的帧数以及输入/输出/总 token。

Round809 三路评测器现在优先按照输入与输出 token 的百万 token 单价估算成本；若网关没有提供单价，可选择每次调用均价作为后备。单价未提供时继续如实标记为未知，不伪造成本。
