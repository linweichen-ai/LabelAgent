# Round 321：LiDAR 引导的远处栈板点提示复核

日期：2026-11-20

## 结论

本轮对 `Capture_20261103` 中 4 个最高修改、远处或狭长栈板候选，使用原始 LiDAR、相机标定和
已有机器候选生成正负提示点，再调用点提示 SAM。4 个目标中 3 个能够形成提示，共执行 9 次
点提示策略，7 次返回掩码、2 次被服务以 HTTP 400 安全拒绝；没有任何候选通过完整自动扩展门禁。

因此合格自动替换为 `0/4`。本轮没有部署，没有改写工作台、人工真值、训练集或模型权重。
LiDAR 几何可以辅助产生提示点，但不能仅凭当前稀疏低矮点云可靠恢复这些远处薄栈板。

## 做了什么

1. 只读取原始点云、标定、源图和冻结的 SAM 候选；审计钩子明确拒绝读取 `labels`、
   `ali_label` 和 `wilddet3d-labels`；
2. 从原始点云拟合地面，选择离地 `0.04–0.45 m` 的低矮物体点作为正提示；
3. 选择地面带内、且避开已有全部栈板候选的点作为负提示；
4. 依次尝试单锚点、双端点和全部低矮点三种策略；
5. 继续执行候选覆盖、面积扩展、主轴方向和相邻实例重叠保护；
6. 单个策略出现 HTTP 错误时只记录该策略失败，整批继续执行。

## 当前运行风险

收尾复核时 D 盘余量下降到约 `289.91–322.06 MiB`，单帧所需 `264 MiB` 仍通过，但已不具备
多帧安全余量。新增占用主要出现在 `D:\AI\Temp` 的腾亚演示文档归档目录，其中 v154/v155 两个
目录逻辑大小约 `934.89 MiB + 234.83 MiB`；这些属于另一项目，本轮只读定位，未删除、压缩或移动。
在空间恢复前，LabelAgent 仅建议单帧演示，不启动批量推理。

## 决定与下一步

1. 不部署本轮 LiDAR 点提示补全；
2. 保留请求失败隔离、参考标签读取审计和实例几何门禁，供后续方法复用；
3. 不继续通过增加提示点或放宽扩展阈值追求表面覆盖率；
4. 远处栈板下一步转向人工确认困难样本的小规模后训练，并用独立保留集同时检查召回、误检、
   相邻实例粘连和背景吞入；
5. 所有本轮结果保持 `candidate_only=true`、`human_truth=false`、
   `approved_for_training=false`、`production_deployed=false`。
