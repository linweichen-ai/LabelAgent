# Round793：网页在线但模型组件失效时的失败关闭验收

## 目标

验证服务器网页端口能够响应、但 SAM3 或 Qwen8B 单独不可用时，Windows 连接脚本不会打开一个无法推理的工作台，并能明确指出故障组件、关闭刚建立的测试通道且不留下活动记录。

本轮不停止真实模型。测试在服务器临时端口启动两个只返回健康状态的轻量假工作台，不加载 GPU、不读取数据、不运行推理。

## 场景一：SAM3 不可用

临时端口 `18769` 返回：网页 idle、SAM3=false、Qwen8B=true。

连接结果：

```text
The remote page is reachable, but its models are not ready
(SAM3=False, Qwen8B=True).
```

连接脚本返回失败，本地 `18769` 没有残留监听，独立运行目录中没有活动隧道记录。

首次启动假服务时曾因两个匿名 Flask 路由重名而退出，连接脚本在远端预检阶段正确拒绝连接；修正路由名称后重新执行，以上结果才计入正式验收。

## 场景二：Qwen8B 不可用

临时端口 `18770` 返回：网页 idle、SAM3=true、Qwen8B=false。

连接结果：

```text
The remote page is reachable, but its models are not ready
(SAM3=True, Qwen8B=False).
```

连接脚本返回失败，本地 `18770` 没有残留监听，也没有活动隧道记录。

## 清理和正式服务复核

- 两个远端假服务都在核对 PID 命令行包含对应测试端口后才终止；
- 服务器 `18769`、`18770` 均已关闭；
- 两个本地独立测试目录在确认空目录后非递归删除；
- Round792 遗留的 310 字节 stale 记录也在文件大小和绝对路径核对后删除；
- 正式 `18765` 最终读回 `ready=true`、SAM3=true、Qwen8B=true。

## 安全边界

- 外部 API 调用：0；
- 真实 SAM3/Qwen8B 重启：0；
- 自动标注推理：0；
- 候选、人工真值、训练批准写入：0；
- test24 使用：0。

## 结论

连接层已经覆盖三类常见问题：SSH 进程退出、SAM3 单独失效、Qwen8B 单独失效。三种情况下都不会把不可用的页面当作正常工作台打开。尚未覆盖的是服务器整体重启后的自动拉起，以及已经打开的浏览器在模型运行中途失效时的页面内提示与自动恢复。
