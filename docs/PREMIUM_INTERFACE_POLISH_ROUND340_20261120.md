# LabelAgent 工作台质感深化（Round 340）

日期：2026-11-20

## 目标

解决界面已经整齐但仍偏“实验工具”的观感，在不改变操作位置和流程逻辑的前提下，进一步强化成熟产品应有的主次、留白、材质和大屏可读性。

## 调整内容

- 顶部导航增加克制的品牌蓝基线，把快捷操作收纳为统一工具组，减少零散按钮感。
- 主图区域改为带微弱点阵纹理的中性工作舞台，并增强图像窗口的独立层级和边缘质感。
- 自动标注操作台扩大区块间距，统一为 12 像素圆角、细描边和双层轻阴影。
- 主运行区增加左侧品牌色强调线，让“开始自动标注”和运行参数成为第一视觉层级。
- 候选统计、批量统计和运行统计增加窄色条，仅用颜色表达安全、警告和待处理状态。
- 筛选项统一为低饱和胶囊按钮；选中项使用品牌蓝渐变，降低小按钮堆叠感。
- 1800 像素以上屏幕提高标题、操作和统计数字字号，改善 2K/4K 屏幕的阅读体验。
- 空候选复核区自动压缩为提示卡，避免占据大面积空白。
- 右侧操作台始终支持独立纵向滚动，不会因内容增多挤压或隐藏底部功能。
