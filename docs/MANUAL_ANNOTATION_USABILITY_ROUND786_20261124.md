# 人工标注灵敏度与工具补强（Round 786）

## 本轮结果

人工标注工具从原有的多边形、矩形、自由线和 SAM 正负点，补充了椭圆框与自由线灵敏度选择。多边形现在可以双击闭合；自由线会读取浏览器合并的鼠标或触控笔采样点，并在同一帧只安排一次重绘。默认“精细”档比旧固定间距更灵敏，“平衡”和“快速”档分别适合普通轮廓与快速粗标。

## 工具与快捷键

| 工具 | 操作 | 快捷键 | 适用场景 |
|---|---|---:|---|
| 多边形 | 逐点点击，双击或 Enter 闭合 | V | 不规则边界精标 |
| 矩形框 | 按住拖动 | R | 箱体、规则区域快速起稿 |
| 椭圆框 | 按住拖动 | O | 圆形、弧形目标快速起稿 |
| 自由线 / 套索 | 按住沿边界绘制，松开闭合 | L | 托盘、斜坡等复杂边缘 |
| SAM 正点 | 点击目标内部 | P | 让 SAM 扩展目标区域 |
| SAM 负点 | 点击错误粘连区域 | N | 排除地面、人员或邻近实例 |
| 橡皮擦 | 选中轮廓后圈出删除区域 | E | 去除孔洞外溢和错误粘连 |
| 撤销 | 撤销当前输入 | Ctrl+Z | 修正误点 |

所有 SAM 结果仍是机器候选；生成、精修或人工复核界面都不会自动把结果标记为人工真值或训练许可。

## 性能与稳定性处理

- 自由线的连续移动事件被合并采样，避免丢失触控笔快速移动时的轨迹。
- 预览仍通过 `requestAnimationFrame` 合并重绘，不会为每个原始输入事件重复刷新。
- SAM 运行期间可以继续追加正负点；旧轮廓会被安全丢弃，最新点集只自动重算一次。
- 矩形、椭圆和自由线都使用 pointer capture，鼠标短暂移出画布也不会中断拖动。
