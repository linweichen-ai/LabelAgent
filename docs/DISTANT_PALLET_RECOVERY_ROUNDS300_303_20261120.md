# Round 300–303：远处栈板候选补全与实例保护

日期：2026-11-20

范围：`Capture_20261103` 四相机中全量审计后最困难的 16 个远处/狭长 pallet 候选

结论边界：只读候选实验，不改写工作台，不写人工真值，不批准训练，不自动部署

## 为什么做

Round 299 已证明 v5 可以把已有栈板区域的锯齿和木纹碎洞清理得更规整，但也确认了它的边界：
如果 SAM 初始候选只覆盖了远处栈板的一条薄边，轮廓平滑无法补回整只栈板。本轮因此分别复核
固定网格裁剪和围绕候选放大裁剪，目标是判断能否安全补全这些小目标，而不是继续放宽平滑规则。

## Round 300：历史固定网格结果重放

复用已经保存的 588 张图、2,352 个真实裁剪响应，不发起新模型请求。正式匹配门槛要求新提案
覆盖至少 50% 现有候选，面积至少扩大到 1.25 倍；16 个困难候选中 0 个通过。

放宽到覆盖 75%、面积 1.2 倍时只有 camera_1 第 89 帧出现 1 个表面匹配，但三联图显示它沿
竖直方向扩进背景，不是栈板补全。因此固定网格路线为 0/16 安全替换，不进入生产。

## Round 301：候选中心 ROI 真实 SAM3 实验

每个困难候选按 3 倍和 6 倍范围生成候选中心方形 ROI，最短边 256、最长边 1,024；触碰裁剪边界
的输出先拒绝。真实 SAM3 运行结果：

| 项目 | 结果 |
|---|---:|
| 目标候选 | 16 |
| 去重后的真实请求 | 28 |
| 请求成功 | 28/28 |
| 原始提案 | 102 |
| 触边拒绝 | 29 |
| 映射回原图 | 73 |
| 工作台写入 | 0 |

基础几何门槛得到 2/16 个表面匹配：camera_0 第 35 帧和 camera_1 第 89 帧。生产状态哈希运行前后
均为 `237844f73ff4495e575c6a3f966260b9385efbdf1edee7d0e5177518470ddfab`，没有修改候选、真值或
训练批准。

## Round 302：主轴方向保护

增加候选主轴/次轴测量：只有原候选足够细长、扩展主要沿主轴发生、次轴不得突然膨胀时才保留。
第 89 帧的背景扩张因此被拒绝，剩余 1/16。该保护同时用一正一反合成形状验证：沿长轴补全保留，
垂直吞背景拒绝。

## Round 303：相邻实例保护

继续检查第 35 帧发现，剩余提案有 52.254% 覆盖目标候选，同时还有 39.069% 覆盖同帧另一个
pallet 候选；相邻帧 32–38 也持续显示该区域存在 2–3 个独立候选。因此该提案更可能把相邻
栈板粘成一个实例，而不是安全补全。

新增规则要求提案与任一其他同帧 pallet 的重叠不得超过提案面积的 10%。最终 16 个样本中：

| 阶段 | 表面匹配 | 人工图像复核后的安全自动替换 |
|---|---:|---:|
| 固定网格正式门槛 | 0/16 | 0/16 |
| 候选中心 ROI | 2/16 | 0/16 |
| 加主轴保护 | 1/16 | 0/16 |
| 再加相邻实例保护 | 0/16 | 0/16 |

## 决定

1. 不部署固定网格或候选中心 ROI 自动替换；0/16 没有形成安全增益。
2. 主轴和相邻实例规则保留为候选复核门禁，防止后续方法吞背景或合并相邻栈板。
3. 不再通过放宽几何阈值追求表面召回；下一阶段应使用实例级检测/提示、LiDAR 或 3D 投影、
   相邻帧一致性，或经过人工确认的困难样本训练。
4. 本轮全部结果保持 `candidate_only=true`、`human_truth=false`、
   `approved_for_training=false`。
