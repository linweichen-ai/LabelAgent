# Round 335：栈板三维实例点提示与竖直背景抑制

日期：2026-11-20

## 结论

点云可以明显改善提示的“安全性”，但本轮还没有把困难远处栈板恢复成可自动替换结果。
在 Round321 同一组4个冻结困难候选上，新的三维实例聚类仍有3个目标能够形成提示，执行9次
点提示SAM，6次返回掩码、3次被HTTP 400安全拒绝，完整自动扩展门禁仍为0/4。因此本轮
不部署、不覆盖历史候选，也不进入训练集。

本轮最有价值的变化是 `camera_1 / frame 89`：旧提示选中的7,697像素高分掩码明显吞入竖直
背景；加入三维实例分离、地面负点和竖直背景负点后，保守单锚点结果缩到583像素，减少
92.43%，并保持正点覆盖、全部负点和竖直背景负点均未被掩码吞入。这证明点云负提示能抑制
背景泄漏，但不能证明恢复的边界正确。

## 方法变化

1. 旧版在图像平面膨胀低矮点后做连通域，新版只用图像位置把冻结候选关联到种子，实例成员
   由LiDAR XY平面的0.18米邻接聚类决定；
2. 若两个三维低矮簇命中候选的种子数相同，则按歧义失败关闭，不凭图像距离强行选择；
3. 至少需要2个同簇种子，且三维簇最大跨度不得超过1.8米；
4. 正提示来自选中低矮三维簇，负提示分为远离该簇的地面环和候选上方的竖直背景；
5. SAM结果继续接受旧有候选覆盖、面积扩张、主轴方向、相邻实例重叠、正负点覆盖门禁，新增
   竖直背景负点不得被吞入；
6. 提示审计与SAM评测都只写本地离线产物，人工真值、正式候选、训练批准和模型权重均不变。

## 验证与边界

- 定向测试：14/14通过；
- 提示审计：4个目标、3个可用、SAM调用0、参考标签读取0、工作台写入0；
- SAM评测：3个目标、9次请求、6次成功、3次HTTP 400安全拒绝、其他错误0；
- 正式状态SHA-256前后均为
  `d176c227e5d780106377395adfa9dc4d53abdadf7d9fb5c2f8a02d56e23f4d95`；
- 提示审计结果SHA-256：
  `b9e461ec7a4258b797451a9248983f998bce424462081ed337d98d744ef33d90`；
- SAM评测结果SHA-256：
  `894bc577b7845f0cfce0cd0ec8aa5c5d39d70d72c48c2205ec198360646a59c0`。

本轮没有独立人工像素真值，因而“背景泄漏变小”只能判定为安全性改善，不能表述为IoU、召回
或泛化提升。下一步不再放宽SAM面积门禁，而是把这3个候选加入人工复核包；只有人工确认的
像素掩码才能用于判断583像素结果是否确实更接近目标，并决定是否进入轻量SAM3后训练。
