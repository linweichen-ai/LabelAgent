# Round 801：外部专家影子路由强信号保底

## 目标

修正“提高总分阈值后，单个关键困难信号可能被总分门槛压掉”的问题。外部专家仍保持影子模式：只给出建议，不发送图像、不调用外部接口、不修改候选、不写人工真值。

## 改动

- 路由器统一保留七类强信号：边缘斜坡、类别审计冲突、Agent 不收敛、开放类别候选、标签注册冲突、协议失败、人工重点帧。
- 推荐条件改为“总分达到阈值，或命中任一强信号”。
- 输出新增 `selection` 字段，明确记录按总分命中、按强信号命中以及具体强信号代码。
- 阈值汇总工具与正式路由器共用同一份强信号定义，避免离线统计与实际路由规则漂移。
- 修复工具直接运行时找不到项目模块的问题。

## 实测结果

在既有 30 帧、零上传的 Round 785 影子审计上重放：

| 总分阈值 | 建议外部复核帧 | 外部调用比例 |
| ---: | ---: | ---: |
| 3 | 17/30 | 56.67% |
| 5 | 15/30 | 50.00% |
| 7 | 10/30 | 33.33% |
| 9 | 7/30 | 23.33% |

阈值 7 仍是当前成本与覆盖率的候选点，但尚未经过人工真值评测，不能称为最优阈值，也不得直接部署。
