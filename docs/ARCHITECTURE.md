# LabelAgent 架构与数据边界

## 1. 目标

LabelAgent 把分割模型、视觉语言模型和受控编辑 Agent 组合成可人工复核的自动标注工作台。它的目标是减少重复标注工作，而不是跳过人工确认直接制造真值。

## 2. 服务结构

```text
浏览器
  │
  ▼
LabelAgent 网页后端
  ├─ 数据读取：图片 / MCAP / 相机帧
  ├─ 项目配置：标签注册表、类别颜色和运行参数
  ├─ SAM3 客户端：文本、点和框提示
  ├─ VLM 客户端：语义复查与困难帧判断
  ├─ Agent：校验并执行有限的局部编辑
  └─ 审计：输入身份、候选、操作、失败和人工确认
       │
       ├─ SAM3 服务
       ├─ 本地 Qwen3-VL 服务
       └─ 可选外部专家服务（默认关闭）
```

推荐把网页后端、SAM3 和本地 Qwen 部署在同一 Linux GPU 服务器。Windows 仅通过 SSH 回环通道访问页面，避免把模型端口直接暴露到网络。

## 3. 一帧数据的生命周期

1. 后端从图片或 MCAP 中读取原始帧；
2. 参考帧提供人工确认过的类别和几何证据；
3. SAM3 生成一个或多个候选掩膜；
4. VLM 比较原图、参考证据和候选叠加图；
5. Agent 只接受协议允许的删改、补擦、合并、拆分或重新点选；
6. 结果作为机器候选叠加在原图上；
7. 人工接受、修改或拒绝；
8. 只有明确保存后才成为人工真值；
9. 只有另一次独立审批后才允许进入训练集。

## 4. 身份与状态边界

| 状态 | 含义 | 可否直接训练 |
|---|---|---:|
| 机器候选 | SAM3、VLM 或 Agent 产生 | 否 |
| 人工草稿 | 人工正在编辑，尚未确认 | 否 |
| 人工真值 | 人工明确确认并保存 | 仍需训练审批 |
| 训练批准 | 独立门禁通过 | 是 |
| `test24` | 只读评测集 | 永远否 |

机器产物必须保持 `candidate_only=true`、`human_truth=false`、`approved_for_training=false`。服务超时、模型离线、类别不一致或身份哈希漂移时应失败关闭，不能自动降级为真值。

## 5. 类别注册表

类别来自项目级标签注册表，前端和后端读取同一来源。全新克隆首次启动会创建默认类别；用户增加类别后，服务端负责规范化、持久化和重新读回。历史帧中的未知类别不会被静默改名或强制映射。

训练和分析保留 `floor` 与 `slope`，便于定位困难斜坡样本；下游通行语义可以在明确配置下合并。合并不应反向覆盖原始标注。

## 6. 模型路由

- SAM3 负责候选生成与交互式修正；同帧多提示应复用图像特征；
- 本地 Qwen8B 是普通帧的默认复查路径；
- 外部专家只处理低置信度、冲突、多轮不收敛或复杂遮挡帧；
- 外部服务超时或限流时回退本地模型，不重复已经成功的 SAM3 分割；
- 任何模型输出都必须经过协议校验，不能直接执行任意代码或文件操作。

## 7. 存储边界

代码、测试和文档进入 Git。模型权重、原始 MCAP、工厂图片、人工真值、运行状态和密钥不进入代码分支。受控权重使用 CNB `model-assets` 与 Git LFS 单独管理，并以许可证和 SHA-256 清单核验身份。

## 8. 部署与回滚

`release` 是普通同事入口，`linux` 是服务器部署入口，`labelagent` 是研发与审计入口。正式模型或运行逻辑更新前必须在隔离环境完成测试；失败时回滚代码提交、配置和模型指针，而不是修改人工真值。

详细命令见 `docs/REPRODUCIBLE_SETUP.md`；服务器专用的 `docs/LINUX_SETUP.md` 位于 `linux` 分支，当前交付状态见 `docs/CURRENT_RELEASE_AND_REPRODUCTION_20261127.md`。
