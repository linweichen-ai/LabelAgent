# Round402：参考真值几何提示的 ego 影子评测（2026-11-22）

## 方法

Round401证明跨数据集复用固定图像坐标会把大块地面分成ego。本轮不再使用那组手工固定点，也不读取颜色：

1. 只读取CVAT Task3第0帧既有ego和floor多边形；
2. 将ego分为连通组件，在每个主要组件内部自动取一个中心正点；
3. 在floor真值中按左、中、右三个空间目标自动取安全负点；
4. 第0帧完全排除在评测外；
5. 将这组六点冻结到另外24个均匀时间点，每个ego组件单独请求SAM后合并；
6. 任何正点失败、SAM警告或负点侵入均使当前帧候选不可用并转人工。

第0帧产生3个ego组件正点`(397,375)`、`(187,375)`、`(627,448)`，以及3个floor负点`(128,360)`、`(320,360)`、`(512,360)`。三个组件在参考ego中的面积占比约48.3%、47.3%和4.4%。

24帧中15帧通过严格提示门禁，9帧安全拒绝。安全拒绝主要发生在纸箱、木板或黑色挡板遮住货叉固定正点时；这些帧的第一个或第二个主要组件请求被SAM拒绝或无法形成完整候选。被接受的15帧全部IoU≥0.849，说明参考真值几何能显著提高“已接受候选”的精度。

全部24帧若把被拒绝帧按空候选计入，平均IoU为0.576，仍达不到正式0.85门槛；正式Round395门禁也明确禁止用高质量子集掩盖阻断候选。因此本轮不能部署为全自动路径。

## 决策与下一步

本轮证明了一条可继续开发的路线：参考帧真值几何比跨数据集固定坐标可靠得多，且不依赖颜色。当前只批准为影子候选方法，不接入正式工作台。

下一步针对9个遮挡帧做“当前帧可见性判断”：只有局部图像与参考车体组件一致时才发该组件正点；被遮挡组件直接转人工，不把遮挡物分成ego。该策略必须在一组新的、与本轮24帧不重叠的冻结帧上验证，并继续同时报告覆盖率和被接受候选质量。
