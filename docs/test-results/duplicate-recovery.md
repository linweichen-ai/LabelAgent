# 重复候选修正实验与未解决问题

更新日期：2026-11-04（北京时间）。已验证真实模型在受控重复错误上进行多轮修正；新复核入口保留为**默认关闭的实验选项**。当前工作台的候选和默认请求保留，尚不能声称实际分割准确率提高。

## 可核验的评测对象

参考图来自未确认 SAM3 功能示例。为每个目标帧选取指定类别面积最大的已有候选，复制其类别与完整轮廓，只分配新的整数 ID。对照组不注入错误。所有测试使用副本，不确认真值。

修正成功要求输出的逐类别 mask 多重集合与注入前完全相同：可改变 ID 或顺序，但不能丢失其他候选、改变类别、移动边界或留下重复实例。候选数下降或像素并集相同都不足以通过。这里衡量已知注入错误的恢复，不衡量自然场景像素准确率。

## 保留的实验路径

仅对同类、逐像素完全相同的候选提供关系信息。首先在不透露重复关系的未着色裁图上检查目标是否可见，再让本地 VLM 检查是否重复标注同一个可见对象。模型明确选择合并后，映射为原有受控合并操作，并在下一轮重新观察。待评估的 SAM 修改和有孔洞的任务继续走原复核路径。

开发帧为 camera_1 第 76 帧。冻结视觉检查版本后，在 camera_0/1/2/3 的第 58/122/45/90 帧进行交替顺序对照：

| 项目 | 原流程 | 有原图检查的局部复核 |
| --- | ---: | ---: |
| 注入的重复错误恢复 | 0/7 | 7/7 |
| 恢复后流程正常结束 | 0/7 | 6/7 |
| 其他候选轮廓保留 | 7/7 | 7/7 |
| 未注入对照原样保留 | 4/4 | 4/4 |

一例虽然已恢复全部 mask，模型随后返回 continue 和空操作，最终为 no_progress。必须保留这一未完成状态。四路图像来自同一段采集，不能当作独立场景的泛化证明。逐例记录见 [实验汇总](duplicate_recovery.json)。

## 失败证据与默认关闭的原因

- 初版虽能消除注入重复，在两张空白原图负对照上仍仅凭轮廓关系判合并，未采用。加入单独原图检查后，两类负对照均保持，完整复核循环也未合并。空白图是开发负对照，不能解释为真实场景误检率。
- 针对 continue 加空操作增加协议重试，仍重复失败且增加耗时，未采用。
- 去掉冗余状态字段的另一变体，在新帧的一例中修改了其他候选，且出现无效点提示和明显耗时增加，未采用。该批次 6 个类别可测案例中仅 5 个恢复完整 mask；另一相机帧只有人员候选，原计划托盘案例不可测，不计入成功。
- 默认流程保持原样。保留的实验入口虽在上述受控集合恢复 7/7，仍有一例未正常结束，尚未验证小目标、近似重复、复杂遮挡或独立像素真值。

## 实现与保护检查

通过 `llm_duplicate_review` 显式开启独立实验，默认不启用。原有 full/compact 默认请求的指令、图像和 schema 在契约样例中完全一致。108 项回归通过，包括像素保留、错误指标、模型拒绝、失败保留、实验关闭和待确认 SAM 回退检查。代码契约替身与真实模型结果分别记录。

1023 个原始文件、原 MCAP、6 个既有会话和保存状态 SHA256 重新核验一致。原工作台 29 个候选继续保留；所有注入及新生成结果在独立目录，没有保存为真值。[保护核验](duplicate_recovery_preservation.json)

## 复现

在本机模型服务可用时，使用新的输出目录：

```sh
python tools/evaluate_duplicate_recovery.py --dataset <dataset> --candidates-json <cached-candidates> --reference-json <reference-json> --reference-kind unconfirmed_functional_fixture --description-json <saved-description> --cases 76:none,76:person,76:pallet --duplicate-review --output <new-output>
python tools/evaluate_duplicate_recovery.py --dataset <dataset> --reference-json <reference-json> --reference-kind unconfirmed_functional_fixture --description-json <saved-description> --generation fresh --cases 76:person,151:pallet --duplicate-review --output <another-new-output>
```

去掉 `--duplicate-review` 可测当前默认路径。完整图像、逐对象轮廓、调用明细、失败代码副本和私有路径仅保存在本机。
