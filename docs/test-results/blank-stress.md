# New-shape/background blank stress comparison

Quarter-opacity arrows eliminated the four existing marked-blank view errors while retaining all protected positives. This next experiment tests whether that result depends on the earlier carrier shape and uniform gray/white sources.

Four new synthetic negative regions combine two previously unused negative-carrier contours with uniform gray and linear grayscale-gradient backgrounds. Carrier geometry comes from existing proposed regions; the synthetic backgrounds contain no physical objects. The model receives no expected category, carrier class, case ID or earlier answer. Full and quarter-opacity arrows share the same opaque contour, source crop, locator endpoint, clean source pixels, source-last order, prompt, schema and token budget.

The original fourteen cases and all their gates are retained. Their 56 full/weak quality rows are exact cached requests; no successful old request is repeated. The new negatives contribute eight views per arm, plus one fresh default guard (17 requests maximum; identical requests may be reused).

Status: **final_verified**. No stress-test success is claimed before complete response readback, generator reconstruction and original-file verification. These synthetic controls cannot establish real-scene false-positive accuracy or independent generalization. Existing suspect and positive requirements remain in force; no default or annotation is changed.

Private images, masks, coordinates and filesystem paths stay local. Prior result: [quarter-opacity comparison](faint-pointer.md).

Verified outcome: both full-arrow and quarter-arrow arms abstained on 6/8 new negative views. Both hallucinated a pallet on the gradient source with one carrier and a person on the gray source with the other contour-only carrier. Arrow reduction did not improve this new cohort. These failures show that contour shape as well as arrow appearance can bias classification.

The old quarter-arrow panel retains confirmed six 12/12, older pallets 4/4, person 2/2, plain blanks 4/4, and marked blanks 4/4. The unconfirmed suspect remains 0/2 abstentions. Original 256 annotation files, approved references and workbench state are unchanged. Thirteen unique new raw answers were verified; four same-payload new-view slots were reused in addition to the 56 old quality rows.

All-view joint acceptance failed. The candidate is not installed as a default. Per-view errors remain errors even if a later consensus rule would abstain. The next experiment should target physical-source evidence versus guide-shape interpretation rather than assume opacity alone generalizes.
