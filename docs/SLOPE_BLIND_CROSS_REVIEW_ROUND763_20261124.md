# Round763：斜坡 32 帧新一轮盲审交叉核对

## 方法

把 Round160 的 32 帧拆成三个互不重叠的本地只读任务：8 个正样本代理、两组各 12 个困难负样本。三个任务只查看本地 `raw/` 与 `review/` 图片，明确禁止读取旧 `assistant-review.json`，也禁止修改、联网、推理、训练、部署或接触 `test24`。

Codex 另外查看了完整联系表，并单独放大核对：

- frame 95：正样本代理中只在画面左边缘露出小段坡面；
- frame 30：灰色货箱由木托盘支撑，不是连续坡面；
- frame 140：大纸箱遮挡最大，前景蓝色网格面是塑料托盘。

## 结果

| 项目 | 结果 |
| --- | ---: |
| 新盲审覆盖 | 32/32 |
| 与旧助手“是否存在斜坡”一致 | 32/32 |
| 新盲审高置信 | 30 |
| 新盲审中置信 | 2 |
| 优先人工复核 | frame 95、frame 140 |
| 人工参考 | 0 |
| `test24` 使用 | 0 |

8 个正样本代理均判断画面中可见斜坡，现有二维候选未见明显大范围吞入平地；24 个困难负样本均未发现可见斜坡，托盘、货箱底座、蓝色塑料托盘和黄色地面标线没有被误判为坡面。

## 重要边界

- 三个任务虽然隔离了样本且没有看旧答案，但仍属于同类助手审阅，不是三位独立人工专家；32/32 一致不能解释为 100% 准确率。
- 这 32 帧来自同一序列，不能证明新厂区、新相机、材质或光照泛化。
- 单目图像只能审阅可见外观，不能测量真实坡度、高度或被遮挡区域。
- 所有结论继续固定 `assistant_only=true`、`human_truth=false`、`approved_for_training=false`、`ready_for_quality_ab=false`。
- 任何工厂图片对外发送仍未授权。

结构化回执：`docs/evidence/workbench-stability-20261117/round763-slope-blind-cross-review.json`。

## 下一步

优先让人工处理 frame 95 和 frame 140，再按正样本代理和困难负样本分层完成其余 30 帧。只有人工回执与帧哈希一致后，才能形成真实质量 A/B 参考；在此之前，外部模型即使连通也只能做 assistant-only 影子复核。
