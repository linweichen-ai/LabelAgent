# Round821：困难集统一离线验收套件

## 目的

外部结果完成后，原先需要分别运行三路对照、分辨率A/B和动态分辨率级联三条命令。人工选择文件容易混用清单、授权或结果，也容易只汇报有利指标。本轮新增一个统一只读入口，一次绑定同一套文件并生成完整结果。

## 统一输出

`tools/evaluate_mixed_hard_suite.py`同时生成：

1. 本地Qwen8B、全Astra、混合路由三路质量/延迟/成本；
2. 640×512与512×410的质量、斜坡误检、延迟和Token差异；
3. 512优先、必要时升级640的动态级联结果；
4. 已测语义门禁摘要；
5. 仍未覆盖、因此禁止部署的门禁清单。

所有输入记录SHA-256。任一人工复核、清单、队列、授权结果、图片哈希或安全边界不匹配都会失败关闭。该工具不调用模型、不上传图片、不修改候选和人工结果。

## 已测与未测边界

统一摘要会检查：总体宏F1不退化、斜坡召回严格提高、斜坡误检不增加、托盘数量和质量不退化，以及缩放图相对原图不退化。

即使上述项目全部通过，仍固定 `deployment_gate_passed=false`，因为以下门槛需要独立证据：

- 像素级托盘孔洞、粘连和边界；
- 车辆/机器人类别冲突不增加；
- 超时、失败与本地回退；
- 跨数据集泛化；
- 工作台进度、结果叠加与历史恢复。
