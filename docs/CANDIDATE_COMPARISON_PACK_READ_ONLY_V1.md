# 通用候选对比包（只读 v1）

## 用途与边界

候选对比包用于在当前候选旁边展示一个或多个替代候选、共识图和离线指标。它不限定数据包、帧号、目标 ID 或类别，也不把助手候选提升为人工真值。

本能力严格只读：服务端仅提供 `GET` 索引、详情、图片和当前作用域校验；浏览器中的“查看偏好”只写入本标签页的 `sessionStorage`。它不会修改 mask、调用推理、写人工真值、写训练集、自动采用替代候选或触发现有人工签核事务。

## 本地目录与清单

每个包放在 `WORK/candidate_comparison_packs/<packet_id>/`，清单固定为 `manifest.json`。清单版本为 `labelagent.candidate-comparison-pack.v1`。

顶层必须显式声明：

- `candidate_only: true`
- `human_truth: false`
- `approved_for_training: false`
- `training_authorized: false`
- `automatic_approval: false`
- `assistant_decision: null`
- `human_decision: null`

`source` 内部绑定绝对数据路径、topic 和生成时的文件载入代次；绝对路径仅用于服务器校验，不会出现在列表、详情、图片或 scope 响应中。文件重新载入或服务重启后，旧包会在 scope 门禁中失败关闭。每条 `rows` 记录绑定：

- 通用 `comparison_id`、`frame` 和工作台规范的整数 `current_candidate_id`
- 原图 SHA-256
- 当前整帧候选集合 SHA-256
- 当前候选规范指纹
- 当前候选 mask 文件、预览图及二者的 SHA-256
- 一个到八个 `alternative` / `consensus` 变体，每个变体绑定 mask 文件及 SHA-256、预览图 SHA-256、像素数和可选标量指标

所有图片必须是清单目录内的普通 PNG/JPEG 文件。读取时会验证文件名、大小、聚合大小、SHA-256、实际解码格式与像素尺寸；图片 URL 同时携带预期清单 SHA 和图片 SHA，旧 URL 遇到清单或图片变化返回 409。响应发送的是刚刚通过校验的内存字节，避免校验后文件被替换。

## 当前作用域门禁

打开一条对比记录前，浏览器调用只读 scope 接口。服务器先在状态锁外完成图片解码和整包校验，避免大包阻塞工作台；随后在状态锁内重新读取轻量清单哈希，并同时验证：

1. 请求中的清单 SHA-256；
2. 当前数据路径、topic 和文件载入代次，同时要求载入代次等于清单生成代次；
3. 当前帧号与编码原图 SHA-256；
4. 当前帧整组候选产物 SHA-256；
5. 指定候选 ID 唯一，且候选规范指纹与清单一致。

任一项不一致返回 HTTP 409，前端清空旧预览状态并禁用会话偏好。响应不回显磁盘路径。

## 浏览器会话偏好

会话偏好不是决定、审批或签核。其键和值绑定清单 SHA、记录 ID、原图 SHA、当前候选集合 SHA、当前候选指纹、当前预览图 SHA、所选变体 mask SHA 和变体预览图 SHA。任一哈希变化，旧偏好不再被识别。

## 未决限制

- v1 只比较生成器事先制作的预览图，不把替代 mask 注入画布，因此无法在工作台里交互编辑替代轮廓。
- v1 不证明候选质量或泛化效果；同源替代策略仍是候选证据。
- 生成器需要按本 schema 输出包；已有 Round729/730/731 产物不会被隐式转换或自动发布。
- 人工若决定采用某个替代候选，仍必须经过现有、独立的真值绘制与签核流程；本模块没有连接该写入入口。
