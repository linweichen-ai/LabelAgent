# Round 566：托盘候选复核资源校验缓存

## 结论

本轮优化只读复核页的资源加载：同一候选包在进程内首次访问时完整读取并校验清单、页面、PNG 签名和逐文件 SHA-256，后续页面与图片请求直接复用已验证的内存字节，不再重复读取和哈希全部资源。

实际 5 候选、6 资源包的本机基准：

- 首次完整校验：4.3756 ms；
- 500 次复用中位数：0.5657 ms；
- 复用 P95：0.7022 ms；
- 首次校验 / 复用中位数：7.735 倍；
- 500 次内容逐字节一致。

该数字是本机只读资源加载微基准，不代表完整工作台推理速度，也不包含模型调用。

## 安全边界

- 缓存只保存已经通过哈希和 PNG 校验的不可变字节；不会在缓存命中时重新打开可能被替换的资源文件。
- 清单或页面任一字节发生变化时，缓存键失效并重新执行完整校验。
- 如果资源文件在缓存建立后被篡改而清单未变，当前进程继续返回之前已验证的安全字节，不会返回篡改内容。
- 清单变化后若资源哈希不匹配，重新校验会失败关闭。
- 返回给调用方的资源字典是副本，调用方不能修改内部缓存。
