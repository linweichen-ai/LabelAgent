# Round513：CVAT Task3 人工签字导入校验门

## 本轮完成内容

新增 `tools/validate_cvat_human_signoff_import.py`。它只接收完整、人工填写的81项签字表，并逐项对照冻结的人工实例复核清单。每项必须同时匹配候选身份、帧号、源图哈希、规范几何哈希和聚焦证据图哈希；任何缺行、重复、冲突、未知项或哈希漂移都会整批拒绝，不产生部分通过结果。

签字决定只允许 `pass`、`reject`、`uncertain`。每行必须带非空复核人和带时区的合法 ISO 时间。工具不会补写人工结论，也会拒绝输入中夹带的训练批准字段；重复 JSON 键也会被拒绝，避免后一个同名字段悄悄覆盖前一个。私有结果会单列人工 `pass` 子集及数量，但明确命名为 `human_pass`，不等同于训练批准。即使81项全部完成，输出仍固定为 `approved_for_training=false`、`training_authorized=false`，后续训练授权必须经过独立门禁。

## 验证证据

- 新增16项导入器单测，覆盖有效完整输入、重复JSON键、每个绑定字段的缺失/漂移、空复核人、空决定、非法时间/时区、重复冲突、缺行、未知ID、训练批准注入、输入文件只读，以及失败日志不泄露私有候选ID。
- 与签字模板和时序复核测试合并执行，共20项通过。
- Python 编译检查与 Git 差异检查通过。
- 公开回执只包含计数和布尔门禁，不含候选ID、坐标、图片、本机路径或复核人身份；失败日志也只报告行号和错误类型。

## 当前状态和边界

Round511 私有模板仍是81项待人工签字，因此本轮没有导入任何人工结论：`human_signoff_count=0`。本轮只把“人工签字后如何安全导入”做成可复现、失败关闭的门禁，并未授权训练。

复核人目前是签字表中的声明身份字符串，不等于账号认证或数字签名；时间戳仅校验格式、时区和日历合法性，不证明真实签署时刻。`human_pass` 只代表人工复核结果，不代表可以进入训练。真正允许训练仍需另行验证签字来源并生成独立授权回执。
