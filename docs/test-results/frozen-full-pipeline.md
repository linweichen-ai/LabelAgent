## Windows 写盘错误恢复

仅为共用元数据保存函数加入最多十次的有限替换重试，JSON 序列化保持。真实 Windows 文件句柄占用检查证明，占用解除后可完成原子保存；永久拒绝则报错，旧文件保留，不会吞掉磁盘错误。冻结的采集、预测、分块处理和 V2 评分文件摘要未改。此次改动的是共用写盘辅助函数，不宣称所有运行依赖均未改。

`tools/complete_frozen_raw_validation.py` 默认只做只读预检。使用现有项目路径运行 `--execute --wait` 后，先验证已有控制器身份，等同一采集完成。它不启动第二个采集任务；所有后续输出写入新的研究目录。
