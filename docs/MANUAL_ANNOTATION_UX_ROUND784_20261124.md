# Round784：人工标注交互提速与工具扩展

日期：2026-11-24

## 本轮目标

在不改变人工真值边界、不触碰 `test24` 的前提下，提高人工修订的灵敏度、工具覆盖和连续操作体验。机器结果仍只能作为候选；只有用户明确完成复核并保存后，才能进入人工真值流程。

## 已实现

- 多边形：逐点绘制，`V` 切换，`Enter` 闭合。
- 矩形框：按住拖动即可生成四点矩形，`R` 切换；过小的误触矩形自动取消。
- 自由线 / 套索：按住鼠标沿目标边界绘制，松开后自动闭合为有面积的分割多边形，`L` 切换。
- SAM 正点与负点：`P` 添加目标点，`N` 添加排除点。
- SAM 连续修正：模型生成期间仍可继续添加正负点；旧点集结果会安全丢弃，最新点集合并后只自动重算一次，避免重复排队和界面卡顿。
- 橡皮擦：`E` 切换；`Ctrl+Z` 撤销当前输入；`Esc` 取消当前草稿。
- 绘制预览使用浏览器逐帧合并刷新，鼠标移动不再每次都触发完整重绘；Pointer Events 与指针捕获让拖动跨出画布边缘时更稳定。

## 安全边界

- 矩形框和自由线最终都写成现有闭合多边形结构，没有引入无法被训练与导出工具识别的“无面积线”。
- 没有伪造 SAM 框提示接口；当前服务器 SAM 契约仍是正负点提示。真正的 SAM box prompt 只有在 5090 服务端模型接口完成独立验证后才会加入。
- 本轮没有自动批准候选、没有把机器结果改成人工真值，也没有修改 `test24`。
