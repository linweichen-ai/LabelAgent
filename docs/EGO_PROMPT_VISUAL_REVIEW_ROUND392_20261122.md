# Round392：ego 提示点可视化复核（2026-11-22）

## 结论

Round391 已能用数字说明提示点是否满足，但人工仍要在 JSON 和叠加图之间来回核对。本轮把 130 个
正负提示点直接绘制到 20 张本地候选叠加图上：

- 绿色圆圈：正点已被候选覆盖；
- 红色圆圈加叉：正点漏覆盖；
- 青色圆圈：负点安全地处于候选外；
- 紫色圆圈加叉：负点被候选错误吞入。

每个叠加图改为无损 PNG，避免 JPEG 压缩让小型点位标记变糊。`review_queue.json` 同时保存每个
点的坐标、正负标签和 `satisfied` 状态，人工可看图快速判断，也能按结构化数据复核。
