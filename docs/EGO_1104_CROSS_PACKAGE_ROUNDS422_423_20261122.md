## 当前结论与下一门

这轮支持“冻结的相机专属两组件方案可从 003/004 迁移到 000/001，并保持提示约束和危险
区域隔离”，比同包留出更强；仍不支持“已获得完整 ego 真值”或“可直接进训练/生产”。

下一门按以下顺序推进：

1. 把 000/001 的 12 张并集送入独立像素级复核，标记缺口与误纳，而不是继续回调提示点；
2. 再从至少一个未使用包抽同样的小样本，保持 v2 完全冻结；
3. 只有跨包像素误纳与召回门槛同时通过，才讨论默认关闭的工作台影子接入；
4. 人工真值、训练批准和正式候选均继续保持不写入。
