# LabelAgent 宽屏工作台布局优化（Round 337）

日期：2026-11-20
状态：已部署至本地正式工作台并通过浏览器验收

## 用户反馈

自动标注页在宽屏下把 4:3 图像放在一个横跨整页的画布中央，导致图像左右出现大面积黑色空区；收起的复核模块仍保留固定高度，页面下方也出现大块无效留白。

## 原因与调整

1. 4:3 原图与超宽画布比例不同。若坚持完整显示且不裁图，横向铺满画布必然出现大面积侧边空区。
2. 批量复核、候选复核在收起、不可用或无候选状态下仍保留最小高度。

本轮在不改变原有操作顺序、按钮、数据和推理逻辑的前提下完成以下调整：

- 宽屏自动标注页改为双栏：左侧完整显示原图和播放控制，右侧承载类别、推理、风险复核和运行进度。
- 原图继续采用完整适配，不裁切、不拉伸；画布背景改为浅色中性舞台，暗色主题仍保留暗色画布。
- 收起的批量复核区不再保留 132 像素空壳，正式验收高度为 53 像素。
- 无候选或不可用的候选复核区取消强制最小高度。
- 小屏继续使用原来的上下布局，避免左右栏过窄；收起工作台时自动恢复单栏。
