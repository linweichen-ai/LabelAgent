# 联合数值要求可行：参考诊断达到上界 82

本工具**有意读取参考标注**，用途是诊断已有候选池能否同时满足数值要求。它没有生成新的实际预测，没有输出参考挑选的候选 ID、轮廓或标注文件。82 是参考参与求解的诊断上界，实际自动排序仍未通过全部采用要求。[完整脱敏结果](joint_feasibility_results.json)

原采用标准保留：实例至少 76、点覆盖至少 5,179、人员交叉点最多 55，相对原基线的增益、数量和面积限制不变。求解器在原新增预算、NMS 和预测人员保护下，证明匹配最大值为 82，并在内部验证了一个同时通过数值要求的选择。没有最小化候选数，166 仅是这次可行组合的数量。

这说明当前数值约束没有根本冲突，已有池中存在足够的组合；后续应改善不读取参考的候选选择。它不证明当前模型能找到该组合，也不证明二维轮廓正确。

## 约束与独立回读

- 原始候选始终固定，保持几何、类别、置信度；新增候选置信度至少 0.5。
- 每图新增额度为 `max(1, floor(原托盘数×0.5))`；对原候选及新候选之间的 NMS 都取 0.8；预测人员 mask 零重叠保护保持。
- 一个参考实例最多匹配一个候选，一个候选最多匹配一个参考实例。匹配边沿用冻结 V2：唯一归属点至少 5、覆盖至少 50%、同类纯度至少 67%。
- 点覆盖使用真正的集合并集，重叠候选不会重复累计。人员交叉点同样按并集计数。不同图像的点编号分别处理。
- 求解器暂不展开逐像素面积变量，但随后回读内部组合的实际面积并验证原上限。更强地，整个候选池并集 910,781 已小于原上限 980,952.5，所以任何子集都满足该面积限制。

问题包含 620 个二元变量、1,019 条约束和 238 个允许的新增候选；SciPy 1.17.1 / HiGHS 返回最优状态，间隙 0。这一次求解耗时约 0.047 秒，不代表其他规模或硬件的性能。内部选择再用原最大匹配、真实点并集和实际 mask 面积回读，所有要求均通过。求解变量与候选索引仅在进程内存在，输出只含计数、状态和摘要。
