# 困难帧人工复核顺滑化（Round 789）

## 目的

Round787 已经补齐严格评测所需字段，但每帧包含多项选择，且当前帧只有翻页时才落入浏览器草稿，容易造成漏填或重复操作。本轮只改善人工复核效率，不自动填写任何判断。

## 改动

- 每次下拉选择、勾选、数量或文字变化后，立即写入当前浏览器 `localStorage`；
- 顶部持续显示“已完整填写 N / 34”和当前帧是否完整；
- `J` 保存并进入下一帧，`K` 保存并返回上一帧；输入框、下拉框和备注获得焦点时不抢快捷键；
- 操作按钮固定在面板底部，长表单滚动后仍可翻页和导出；
- 八类存在性在宽屏双列、窄屏单列显示；
- 浏览器中保存的越界页码会被安全夹回 1–34。

没有加入“一键全选未见”“复制上一帧”或机器自动预填，避免为了省操作而诱导人工答案。旧 Round786、Round787 均保留。

## 入口与边界

服务器只读入口：`http://127.0.0.1:18765/hard-review/round789/`

数据仍为原 34 帧、68 张图，70 个收据约束文件，远端 SHA-256 复核 0 异常。所有输出继续保持 `candidate_only=true`、`human_truth=false`、`approved_for_training=false`；本页面不构成像素真值或训练批准。

## 验证

- 复核、转换、三臂与只读服务定向测试：18/18 通过；
- 生成页内 JavaScript 语法验证通过；
- 在线页面、图片、自动保存标记、进度标记和 J 快捷键代码均成功回读；
- 外部 API、模型推理、训练和人工真值写入均为 0。
