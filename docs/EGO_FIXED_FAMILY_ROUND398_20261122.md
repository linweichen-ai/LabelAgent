# Round398：camera1 固定提示族压缩与非退化门禁（2026-11-22）

## 目标

Round397 的15组穷举在九帧上都满足提示约束，但每帧15次point-SAM不适合实时工作台。本轮严格只读取五个开发帧的尝试记录，求能覆盖四个正点的最小固定提示族；四个留出帧不参与选择。

开发集唯一的最小提示族为：

```text
[3]、[0,2]、[1,3]
```

即每帧固定追加3次point-SAM，相对15次穷举减少80%。全部请求继续携带同一组三个负点，不使用车体颜色。

## 为什么增加非退化门禁

首轮只看“正点是否全部命中”时，固定提示族得到开发5/5、留出3/4。但助手查看叠加图发现frame38、57只保留很小的车体碎片，形式上命中四点却明显丢失主体。

因此同轮追加固定安全规则：新并集至少保留原候选90%的像素，否则即使四点全部命中也拒绝。这里的原候选不是人工真值，只用于防止速度优化把现有覆盖大幅缩小。

## 结论

- 请求数从15降到3，效率方向成立；
- 非退化门禁正确抓出了frame38、57的碎片化假通过；
- 加门禁后只剩6/9，不能替换Round397的离线穷举，也不能部署；
- 下一步只能在门禁失败时按需追加少量候选子集，不能把90%保留阈值悄悄降低来换通过率；
- 人工像素真值、person/floor误纳和跨厂区样本仍是生产前必需证据。

本轮没有修改正式模板、工作台候选、人工真值、训练批准或模型权重。真实叠加图继续只保留在本地：`artifacts/round398-camera1-fixed-family-v2-20261122/contact_sheet.jpg`。
