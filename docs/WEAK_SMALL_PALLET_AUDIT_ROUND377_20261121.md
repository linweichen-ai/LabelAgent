# Round377：小型低置信栈板误检拦截

## 本轮解决什么

新实采数据的三帧中，边界清理已经较克制：34 个栈板候选没有内部孔洞，既有清理最多只改变
2.1374% 像素，并可把外轮廓顶点从 1834 个降到 1331 个。继续强行平滑并不是当前最值得做的
事情；更明显的风险是少量很小、置信度又低的区域仍带着 `pallet` 类别通过。

因此新增一个窄门禁：仅当候选类别为 `pallet`、分数不高于 0.52、外接框面积在 400 至
5000 像素之间时，送入现有的类别盲审。盲审看不到候选当前类别，只看隔离后的目标像素。
它不会删除候选、不会自动改类别，也不会写成人工真值；证据不足时只进入人工复核。

## 实际命中

当前常熟实采三帧共有 34 个栈板候选，新规则只新增拦截 4 个：第 0 帧候选 5、6，第 76 帧
候选 9，第 151 帧候选 14。5090 快速 VLM 的隔离盲审把这 4 个全部路由为
`human_review_required`。与此同时，两个面积较大的低分栈板控制样本仍被确认并保留，说明规则
不是简单地把所有低分结果都判错。

跨 7 个已有会话核算，共 11,592 个栈板候选，仅 304 个会新增盲审，占 2.62%。这让复核集中在
最可疑的小区域，避免全量候选都调用 VLM；上一轮的双 VLM 尾项并行仍会吸收一部分新增耗时。
