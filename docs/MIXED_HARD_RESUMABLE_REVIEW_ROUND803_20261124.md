# Round 803：34帧困难集可恢复人工复核工作台

## 目的

降低34帧困难集的人工裁决成本，并避免浏览器缓存丢失后从头复核。该页面只生成复核记录，不写工作台真值，不授权训练。

## 新增交互

- 候选叠加图、原图和左右对比三种视图，支持 `V/R/B` 快捷键。
- 点击图像全屏放大，便于检查小目标、边缘斜坡和托盘孔洞。
- `G` 跳到下一张未完整填写的样本。
- 可显式复制上一张填写，适用于相邻时刻；复制后仍需人工逐项检查。
- 草稿可随时导出并重新导入，绑定同一复核包哈希和每张源图哈希。
- 导入时拒绝其他数据包、重复样本、未知样本、图片哈希变化以及越过安全边界的文件。
- 完整导出仍要求复核人、34张全部字段、八类存在性和托盘实例数齐全。
