# Round380：栈板轮廓按尺度自适应平滑

## 本轮解决的问题

上一版固定使用亚像素级轮廓简化，对远处小栈板足够保守，但近处大栈板仍会保留较多像素台阶，界面上看起来有“凹凹凸凸”的感觉。本轮把候选轮廓简化改为按栈板面积分档：大目标先尝试更强但仍受限的平滑，中等和小目标使用更保守的参数。

所有提议仍必须同时通过以下安全门：

- 总改动像素比例不超过既有上限；
- 不增加或误合并有效连通区域；
- 结构孔洞至少保留 75%；
- 仅修改机器候选，不写入人工真值；
- 不自动批准训练或部署。
