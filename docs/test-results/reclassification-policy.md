# 排除无变化重分类的隔离对照

上一轮 8B 在第 76、151 帧请求把已有 `person` 再改为 `person`，导致 `no_progress`。候选清单已包含实际类别，原 schema 却允许任意候选与任意目标类别组合。本轮只约束解码中的这项组合：目标类别必须不同于该 ID 的当前类别，所有原有工具、正确跨类操作、无进展停止规则和 `done` 语义保留。

工具 `evaluate_reclassification_policy.py` 在独立、顺序执行的进程中暂时替换 schema 构造函数，结束时恢复。生产 `workflow.py` 和 `protocol_schema.py` 不改动，工作台默认行为不变；没有模拟模型响应，也不强制修改或返回 `done`。

## 预设对照

使用同一相机第 76、151 帧、上一轮真实 SAM3 候选及 8B 生成的同一规范，参考仍为第 0 帧未确认示例。两种策略均使用同一批图像字节和文本，只改变响应 schema；首轮实际请求逐对核对。每帧分别测试原候选和一个类别翻转对照：仅将面积最大人员候选的类别改成 `pallet`，几何不变。这不是人工真值，也不能评估自然语义准确率。

两帧、两类输入、两种策略，共 8 个有界运行，策略顺序交错，每项最多 3 轮。复用历史真实 SAM3 候选，不把它计为新分割；若模型选择局部 SAM3 工具，真实调用另记。原始输入、代码和计划摘要在模型调用前固定，模型不获知对照身份。

预设要求：

- 八项均有真实 VLM 调用，四对首轮文本和图像输入相同。
- 新策略同类重分类为零。
- 两个已知类别翻转均完整恢复原候选，实际修改后再次复查并收敛。
- 两组原候选保持几何和类别并收敛。
- 原始图像、候选文件、参考、工作台状态及生产代码保持不变。

任何一项失败均不启用。即使功能门槛通过，也只证明本组协议与已知注入错误的恢复，不证明自然错误或像素质量提高。三维投影参考指标仍使用原 V2，候选冻结后单独计分。

195 项完整回归通过，包括真实格式解析器对三类 ID/类别组合、单类空操作、有效跨类修正、待评估 SAM 结果及作用域恢复的检查。真实模型结果见下节。
