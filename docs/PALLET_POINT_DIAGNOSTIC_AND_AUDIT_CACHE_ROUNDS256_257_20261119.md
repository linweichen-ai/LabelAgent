## 结论先行

本轮没有把“固定坐标的 SAM 点提示”接入生产。它在相邻帧中会因为目标移动而漂到地面：第 124 帧错误区域达到 84,803 像素，其中 76,069 像素落在限定区域外，属于明确失败。

生产侧上线的是更稳妥的提速：当原图、候选集合、候选指纹、标签表、模型配置、审核代码版本、审核回执和复核绑定全部一致时，主自动标注复用已完成的栈板隔离复核；任何一项变化都重新调用 VLM。复用只减少重复审核，不改变候选，不写人工真值，也不批准训练或部署。

## Round 257：主流程严格复用隔离审核

### 安全条件

复用必须同时满足：

1. 审核状态为完整；
2. 原图 SHA-256 一致；
3. 整个候选文件 SHA-256 一致；
4. 目标栈板候选的逐实例指纹和 ID 一致；
5. 标签表、模型配置和审核协议版本一致；
6. 审核回执自身哈希可重新计算并一致；
7. 候选复核绑定存在，且候选、审核回执、路由三者完全一致。

命中后只复用不可变审核回执，并从回执重新生成界面上的人工复核提示。候选几何、人工真值、训练批准和部署批准均不改变。

## 下一步

1. 继续做“当前候选派生点 + 有限 ROI”的离线实验，不把固定点或颜色规则写入生产；
