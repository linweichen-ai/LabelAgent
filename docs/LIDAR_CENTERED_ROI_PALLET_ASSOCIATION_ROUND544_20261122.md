# Round 544：LiDAR 定位 + 单托盘 ROI + SAM 实例关联

## 结论

本轮把已有的低高度 LiDAR 组件从“直接给 SAM 点提示”改为“先定位单托盘局部区域，再做文字分割，最后用当前候选和 3D 中心共同关联实例”。

- 冻结困难样本：4 个，其中 3 个具备可用 LiDAR 组件。
- SAM 请求：3/3 成功；没有 HTTP 400。
- 关联诊断：3/3 通过本轮候选门槛；上一版仅靠精确中心选择时为 0/3。
- 正式工作台写入：0。
- 人工真值读取：0。
- 正式模型替换：0。

这证明“LiDAR 负责找位置，局部 SAM 负责描边，已有实例负责防串目标”在这 3 个困难样本上可行；它还不是人工真值精度结论，也没有跨序列泛化证据，因此保持离线候选状态。

## 为什么上一版不稳定

旧方案把稀疏 LiDAR 点直接作为正负提示。4 个目标中只有 3 个能构造提示，9 次请求里有 3 次因为正负提示冲突返回 HTTP 400，并且 0 个结果通过安全扩张门槛。

本轮第一版只要求分割掩码精确覆盖 3D 中心。由于相机与 LiDAR 投影存在数像素偏差，只有 1/3 精确覆盖中心，最终仍为 0/3。

## 本轮方法

1. 使用冻结的低高度 3D 组件确定局部 ROI，不依赖颜色。
2. ROI 内只运行一次 `pallet` 文字分割。
3. 对返回的多个掩码先检查与当前单托盘候选的覆盖关系，避免选中相邻托盘。
4. 再检查掩码到 3D 组件中心的距离，允许最多 24 像素的标定/投影容差。
5. 最后检查负点、相邻托盘重叠、面积比例；只输出离线诊断结果，不写回工作台。
