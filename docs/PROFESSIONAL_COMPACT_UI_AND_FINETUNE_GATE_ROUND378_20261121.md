# Round378：专业精简工作台与微调门禁复核

日期：2026-11-21

## 结论

本轮把正式工作台调整为更简洁、专精的标注界面：顶部只保留高频模式切换和连续推理，低频功能
改为图标；四步引导默认收起但可随时展开；减少渐变、阴影、圆角和多层卡片感，让原图、候选与
人工复核成为视觉主体。数据切换、人工真值、候选复核、连续推理、夜间和专注模式均保留，未改变
原操作流程。

质量侧重新复核了微调边界。Qwen3-VL-2B 已存在一份真实完成的 LoRA 离线候选：内部 dev8
为 8/8 合法 JSON、62/64 类别证据与 8B 机器教师一致，静态缓存中位 4.594 秒；但训练标签
仍来自机器教师，不是人工真值，且独立 `other_robot` 影子检查仍漏 1/2 正例。因此本轮不把它
替换正式 8B，也不继续在同一 dev8 上盲目加训练步数。

SAM3 像素微调仍未启动。冻结训练门禁显示 96 帧中 0/96 完成人工像素签核，train/test 两份
`human_verified` COCO 均缺失；机器候选不能自动升格为训练真值。当前实际质量改进继续采用
Round377 已部署的小型低置信栈板语义拦截，以及最大改动 2.5% 的有界栈板边界清理；它们只
改变候选或复核路由，不写人工真值。
