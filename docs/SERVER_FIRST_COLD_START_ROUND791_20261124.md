# Round791：服务器优先工作台隔离冷启动验收

## 目的

验证 Linux 服务器上的网页后端可以在不重启 SAM3、Qwen8B、不影响正式工作台的条件下独立启动、读回状态并受控停止。本轮不运行推理，不写候选、人工真值或训练批准，不使用 test24。

## 隔离方式

- 正式工作台：`127.0.0.1:18765`；
- 隔离工作台：`127.0.0.1:18768`；
- 隔离 Git worktree：`/home/clw/projects/labelagent-coldtest-round791`；
- 隔离状态目录：`/home/clw/projects/labelagent-coldtest-work-round791`；
- 模型服务只读复用：SAM3 `127.0.0.1:18766`，Qwen8B `127.0.0.1:18878/v1`。

隔离实例使用自己的 `.repro/linux-processes.json`，不会覆盖正式克隆的生命周期记录。

## 异常与处理记录

首次自动清理调用受到 Windows 到 Bash 管道的 CRLF 影响，停止脚本已经成功关闭隔离进程，但最后一个临时目录清理函数没有被调用。随后先只读确认 `18768` 已关闭，再分别核对两个绝对路径，通过正式 Git worktree 管理命令和精确目录删除完成清理。正式 `18765` 在清理后再次读回为 idle。

这一异常没有触发服务重启、模型加载、数据写入或正式状态变化，但说明跨平台临时脚本应避免通过带 CRLF 的标准输入传递 Bash 函数。本项目正式的仓库脚本本身没有使用该临时传递方式。

## 结论

服务器优先架构的网页层能够独立冷启动、使用现有热模型、完成健康检查并受控停止，正式工作台在整个过程中持续可用。本轮只证明运行链路和隔离能力，不证明分割精度、VLM语义质量或后训练效果。
