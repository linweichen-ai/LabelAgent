# Round 267：近景栈板边缘凹口清理 v5

日期：2026-11-19

状态：已部署、已完成生产在线验收；只修改机器候选，人工真值与训练集未改变。

## 1. 本轮解决什么

Round 266 已经把木纹、反光等造成的内部碎洞大幅清掉，但有些缺口与掩码外部背景连通，不属于“内部洞”，所以仍会在栈板边缘形成白色凹口。简单做大范围闭运算虽然能抹平缺口，却可能吞并背景、连接相邻物体，或填掉真实叉孔和板缝。

本轮增加原图引导的边缘凹口修复，只处理“窄、浅、局部外观与栈板相近”的缺口，并继续保留结构孔、深色板缝和塑料网格。

## 2. v5 的安全门禁

1. 只对覆盖整图至少 30% 的近景大栈板启用；远景和小栈板保持原结果；
2. 候选凹口必须面积不超过 1,024 像素、跨度不超过 96 像素；
3. 结合原图判断凹口是否属于木板同材质区域，不依赖某一种固定颜色；
4. 图像边缘、明显暗色结构孔、板缝和外观突变区域不填；
5. 单实例总变化不超过 6%；
6. 只有确实修复边缘凹口时才允许局部木板碎片合并，且最多合并 2 个连通组件；
7. 所有修改仍是可逆机器候选，不写人工真值，不自动批准训练或部署。
