# Round 794：服务器模型在线状态与手动标注流畅度

## 本轮目标

继续落实服务器优先架构：网页后端、SAM3 和 Qwen8B 全部运行在 Linux GPU 服务器，本机只通过 SSH 安全通道打开浏览器。同时提升人工标注的可见性、工具完整度和拖动响应。

```text
本机浏览器 http://127.0.0.1:18765
    │
    └── SSH 安全通道
            │
            └── Linux 网页后端 127.0.0.1:18765
                    ├── SAM3 127.0.0.1:18766
                    └── Qwen8B 127.0.0.1:18878/v1
```

本机地址中的 `127.0.0.1:18765` 只是隧道入口，不代表模型运行在 Windows。本轮没有把 Flask 服务直接暴露到公网或局域网。

## 本轮改进

1. 页面左上角不再显示容易误解的“本机运行”，改为真实服务器模型状态；
2. 页面打开后持续检查 SAM3 与 Qwen8B，而不是只在点击开始时检查一次；
3. 模型中途掉线时，明确显示哪个组件不可用，暂停新任务，并自动重试；
4. 正在运行的任务不会因为状态提示而失去“停止”按钮；
5. 模型恢复后页面自动解锁，并只提示一次恢复信息；
6. 单次状态读取最长等待 5 秒，避免状态接口拖住页面；
7. 手动拖线与框选预览继续使用 `requestAnimationFrame` 合并重绘；
8. 画布只在原图尺寸变化时重建，普通拖动只清空并重绘，减少高分辨率图像上的重复内存分配。

## 部署验收

部署时只更新网页后端代码，不重启 SAM3 与 Qwen8B。部署后应确认：

1. `/api/model_readiness` 的总体、SAM3 和 Qwen8B 均为 `ready=true`；
2. `/api/run/status` 为 `idle`；
3. 页面版本为 UI 177、`app.js?v=215`；
4. 左上角显示“服务器模型正常”；
5. 多边形、矩形框、椭圆框、自由线 / 套索、SAM 正点和负点均可见；
6. SAM3 与 Qwen8B 进程号在网页重启前后保持不变；
7. 未发生人工真值、候选或评测集写入。
