旧C托盘参考点覆盖495/579；本轮C为482/579。限制范围丢失了旧补充候选带来的部分参考点覆盖，面积通过不能代替质量提升。

旧新增11个掩码没有增加新的合格参考对象；增量主要重复已有对象的范围。按原规则，点覆盖达到0.5、纯度达到0.67并满足一对一匹配才增加支持。新增像素不能全部称为误检，因为缺少完整二维真值。

本轮用37次局部SAM3调用和16次原图模型核验生成实例子候选。B仅使用原SAM裁剪，C增加训练模型裁剪提示；原掩码保留，新掩码限制在其并集内，按冻结规则排重和限量，没有使用3D参考筛选预测。这控制面积但不扩展空间召回。事后上界诊断确认3个漏检对象原并集覆盖不足0.5，无法被该子集方法恢复；另2个对象需要更好的实例分离。

旧33次填补中30个操作框不完整，29次实际填补后留有目标像素。原因是闭区间缺口框被按半开区间处理；修复右、下边界后，完整缺口不再因一像素边条反复出现。首轮有8、18、14、26个批准任务，原每轮3项也构成预算限制。

新增可选SAM批处理是真实的一次多点调用，所有缺口先逐项图像复核。仅当实际返回的SAM掩码包含某个批准缺口100%的像素，才接纳该完整缺口；未满足区域整块不改并显式待办，下一轮必须真实比较前后图。正点覆盖警告保留，其它警告仍拒绝。未批准像素锁定、原像素不删除。少量剩余任务仍按单项工具执行。

首次试跑错误地把不确定保留区域用作负点，触发负点排除失败；改为锁定而非负证据。预检按完整满足缺口数量选择正提示模式，没有使用参考分数。即使这样，部分剩余缺口仍不被SAM完整覆盖，三轮预算不足；失败和待办都保留，没有把阈值或最大轮数放宽。

模型原图核验仍存在将黄线定位符描述为物体等问题。协议收敛不等于地面语义正确；这不是人工真值。两张已暴露同采集图仅用于工程诊断，未评估独立泛化或密集像素准确率。

原验收：数量比例≤1.5，面积比例≤1.25，严格实例支持提升，参考点及人员保护不退化，原候选保留，零协议错误，全部六组在三轮内收敛。每轮最多3项、SAM累计最多32点。本轮新增238张报告图片、4段真实阶段回放视频，非连续桌面录屏。
