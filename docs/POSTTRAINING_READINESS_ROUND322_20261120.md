# Round 322：后训练状态统一审计

日期：2026-11-20

## 结论

当前存在一份真实完成训练、通过张量审计并做过冻结 `test24` 外部比较的
Qwen3-VL-2B LoRA 离线候选；它使用 62 条机器教师样本训练 62 步，`test24` 未进入训练，适配器
SHA-256 为 `3327bf5e4b32abaf170fcd6a7696ad8d12cd1175d68eade9f87996f6b05fe25a`。

但这不是人工真值后训练：冻结外部比较只证明 180/192 个类别 evidence 与 8B 机器教师一致，
即 `93.75%` 教师一致率，不能解释为人工准确率。该适配器没有部署，正式 8B 保持不变。

SAM3 像素级微调当前仍不具备训练条件。本地冻结训练门禁显示 96 张图中 `0/96` 完成人工签核，
train/test 两份 `human_verified` COCO 均不存在；Round 321 的4个远处栈板也全部仍为机器候选，
可用于训练的人工真值为0。

## 新增统一审计器

新增 `tools/audit_posttraining_readiness.py`，把过去分散的五类证据绑定在一起：

1. `train72/test24` 人工训练门禁；
2. 2B LoRA 训练收据；
3. LoRA 张量审计；
4. 冻结 `test24` 外部比较；
5. 最新远处栈板困难样本报告。

审计器会主动拒绝：`test24` 回流训练、适配器哈希不一致、机器教师冒充人工真值、离线候选冒充
生产部署、困难样本未经人工确认直接进入训练。即使人工门禁未来通过，输出也只允许
`ready_for_isolated_run`，不会直接授权替换生产模型。
