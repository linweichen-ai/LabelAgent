# 工作台操作：相机 1，第 76 帧

本机入口：<http://127.0.0.1:8765/>。本页对应已导入的采集数据。当前独立演示会话已保存用户确认的第 0 帧参考轮廓和描述，第 76 帧已有 11 个未确认候选：9 个托盘、2 个人员。

## 先把标注界面打开

1. 点击页面右上角 **「＋ 添加窗口」**。当前数据已经加载，无需重新导入 ZIP。
2. 弹窗的「窗口类型」选择 **「图像」**；消息源只勾选 **`/capture/camera_1/image`**，再点弹窗右下角「添加窗口」。
3. 出现相机画面后，点击该图像窗口**右上角的铅笔「✎」**。这是进入标注模式的入口；只添加窗口还处于查看画面的状态。
4. 点击页面**左上角「自动标注」**。

如果图像窗口已打开且铅笔已选中，直接从下一部分开始。

## 用 1 帧熟悉流程

1. 在画面下方**右侧帧号框**输入 **`76`**，按键盘 **Tab** 完成切帧。帧号框在播放速度下拉框的右侧。
2. 下方操作区的 **「处理帧数」填 `1`**，表示从当前帧开始只处理一帧。这与当前帧号是两个输入框。
3. 仅查看已有结果时，直接点击 **「Agent 标注结果」**。需要重新生成时，点击 **「开始自动标注」**；会更新本帧的自动候选。本地管理器会让 SAM3 与 Qwen 轮流使用显卡。
4. 按顺序点下面四个阶段，检查真实运行记录：

   | 阶段按钮 | 可以查看的内容 |
   | --- | --- |
   | SAM 3 分割 | 关键词、输入原图和初步轮廓 |
   | GPT 复查输入 | 视觉模型实际收到的原图、候选图和提示词 |
   | GPT 决策输出 | 判断依据和要求 Agent 执行的操作 |
   | Agent 标注结果 | 最终候选、轮次和停止原因 |

5. 点击结果图可以放大。人工检查类别、漏标、多标和边界，确认合适后再点击 **「保存结果」**，将该帧候选确认为真值。教程演示没有代替用户执行这一步。

界面里的「GPT」是现有按钮名称，当前本机部署使用 Qwen3-VL；服务来源以设置为准。模型切换期间可能需要等待，以阶段状态判断进度。「复查完成」代表这一轮流程结束，仍需要人工检查结果。

## 换新数据时怎样准备参考帧

**当前会话已经准备好参考帧和描述，跳过本部分即可。**

1. 在同一相机内点击「参考帧准备」，进入「人工标注」，帧号输入 `0` 后按 Tab。
2. 选择类别 `pallet` 或 `person`，点击「多边形」，沿可见轮廓逐点绘制，最后点击「闭合」。逐个完成对象并核对。
3. 点击「保存当前帧真值」，再点击「设为参考帧」。仅把人工检查过的轮廓用于参考。
4. 切回「自动标注」，在参考帧点击「生成真值描述」，等待描述和关键词生成。
5. 切到目标帧，再按上面的单帧流程运行。

「生成真值描述」仅在参考帧显示；切到第 76 帧后看不到该按钮是正常的。当前 MCAP 人工参考使用多边形；「点选目标／生成轮廓」入口只在单张图片模式显示。

## 常见卡点

- **没有图像或提示「无效的相机话题」**：重新添加图像窗口，只选 `camera_1/image`，再点铅笔。点云源不能当图像源使用。
- **提示先设置参考帧并保存真值**：检查当前相机是否与参考帧相同，并完成参考真值、设为参考帧和生成描述三个步骤。已有候选不代表参考帧已准备好。
- **帧号没有变化**：输入数字后按 Tab，或点输入框外完成切帧；不要误改「处理帧数」。
- **看到绿色轮廓但尚未保存**：这是自动候选；只有点击「保存结果」才会成为该帧人工确认的标注。
