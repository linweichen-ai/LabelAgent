# 当前二维标注规则

- 每个物理托盘作为一个实例；堆叠托盘按每层分别标注。
- 同一托盘的不同可见侧面或断开的可见部分不能仅因轮廓断开而重复计数；实例归属不确定时保留为待复核候选。
- 按可见边界标注，遮挡部分不外推。当前批准参考采用托盘外轮廓，格栅小孔暂未逐孔扣除；更换边界口径须另立版本，不能改动已有参考来迎合预测。
- 货物、车辆部件与托盘需要区分。模型新增区域只作候选，未得到对应人工复核的区域不自动成为人工参考。

当前相机1第0帧保留15轮廓原批准版本，另有18轮廓离线批准版本（13个托盘、5个人员）。后者只增加3层已确认托盘，前15个轮廓逐对象保持，尚未替换工作台当前参考。两版均来自经复核的模型轮廓，不能等同独立重画的全数据集精度基准；未标区域也未自动视为负样本。

这些二维规则不改变原始三维labels、原始采集包及既有标注。详见[已批准参考核查](test-results/approved-reference-audit.md)。
