# Round532：隐藏工作台暂停版本探针

## 目标

多人演示或长时间调试时，浏览器常同时保留多个 LabelAgent 标签页。此前每个页面无论是否可见，都会每 30 秒读取一次首页确认 UI 版本；隐藏页虽然不再轮询任务状态，仍会持续产生版本探针。本轮只消除这类后台请求，不改变推理、候选、人工真值或模型配置。

## 实现

- 页面隐藏时，版本探针立即返回，不发起网络请求；
- 页面重新可见时，既有 `visibilitychange` 路径立即补查版本；
- 窗口重新获得焦点时仍会补查，因此旧标签页不会错过新版提示；
- UI 版本提升到 `169`，`guide.js` 资源版本提升到 `120`。

单个持续隐藏标签页的版本探针由每分钟约 2 次降为 0；这是定时策略直接推导值。可见页仍维持每 30 秒探针，不把该变化解释为模型推理提速。

## 验收

- 新增逻辑测试确认隐藏时请求数为 0、切回可见后立即请求 1 次；
- 完整 Python：1523 项，1522 通过、1 项按设计跳过；
- 完整网页逻辑：175/175 通过；
- 隔离真实 Edge 32 秒验收：UI 169、运行状态 4 次、摘要 2 次；
- 外部请求、受保护写入、HTTP 错误、页面错误和控制台错误均为 0。

## 边界

本轮没有运行真实数据推理、训练、微调或后训练，没有修改候选、审核记录或人工真值。正式工作台需在候选提交固化后使用原子部署脚本更新，并再次现场读回。
