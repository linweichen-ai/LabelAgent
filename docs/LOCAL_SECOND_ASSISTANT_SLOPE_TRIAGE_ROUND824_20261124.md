# Round824：本地第二助手斜坡分歧复核

## 目的

在不上传工厂图片、不调用外部API、也不把机器判断写成人工真值的条件下，对34帧困难复核集做第二路本地视觉审阅，与现有Qwen建议比较，缩小后续人工复核范围。

## 方法

第二助手只读取本地原图和34帧联系表，重点检查：

- 画面边缘只露出一小部分的黄色过渡；
- 被货物遮挡的坡道；
- 集装箱入口、门槛和内部地板的空间关系；
- Qwen判断为`absent`或`uncertain`的斜坡候选。

新增 `tools/audit_second_assistant_slope_triage.py`，逐项核对复核清单、Qwen建议、样本ID和图像绑定哈希，并强制候选边界。任何哈希漂移、训练批准、人工真值或`test24`状态异常都会失败关闭。

## 结果

| 项目 | 数量 |
|---|---:|
| 本地复核帧 | 34 |
| 优先分歧帧 | 11 |
| Qwen判定`absent` | 5 |
| Qwen判定`uncertain` | 6 |
| 第二助手高置信候选 | 3 |
| 第二助手中置信候选 | 6 |
| 第二助手低置信候选 | 2 |

困难因素中，货物遮挡4帧、画面边缘3帧、局部可见3帧、集装箱过渡5帧。该结果表明固定全图语义判断容易漏掉局部过渡，后续人工复核和外部专家试验应优先处理这11帧，而不是平均查看全部34帧。

## 安全边界

- `candidate_only=true`；
- `human_truth=false`；
- `approved_for_training=false`；
- `training_authorized=false`；
- `test24_used=false`；
- 外部API调用0；
- 工厂数据上传0；
- 正式部署0。

这11条是第二机器建议，不是人工裁决，不能用于直接计算真实精确率、召回率，也不能直接进入后训练。
