# Round396：camera1 遮挡车体分块合并候选（2026-11-22）

## 为什么做

Round392 的可视化表明，camera1 的可见车体经常被人员、方向盘和黑色结构分成多个不连通区域。现有模板把四个正点一次交给 point-SAM；模型往往只保留其中一个连通块，导致五个既有样本全部被正点约束门禁阻断。

本轮没有更换人工真值，也没有放宽门禁。只读候选把每个正点分别与同一组三个负点送入 point-SAM，仅保留正点命中、负点未命中、无服务警告且面积不超过 25% 的分块，最后取并集。策略完全使用固定几何点，不依赖红色车漆或其他颜色。

## 严格数据隔离

- 已曝光开发帧：0、38、76、114、151；
- 此前未参与本轮设计的留出帧：19、57、95、133；
- 真实图片、叠加图和总览只保存在本地未跟踪目录；
- 输出仍为 `candidate_only`，不写工作台状态、人工真值、训练批准或生产配置。

## 结论

分块合并把 camera1 候选可用率从 0/9 提升到 2/9，并在留出帧上取得 1/4，说明“遮挡造成不连通”确实是一个真实原因。但 7/9 仍不能覆盖四个正点，且没有人工逐像素真值、person/floor 重叠指标和独立人工收据，因此：

- 不替换当前正式单请求模板；
- 不进入训练集或自动合并；
- 保留为可复现候选工具；
- 下一步测试固定的多正点子集组合，再用确定性的覆盖选择合并，仍在同一留出集上报告，不按视觉结果临时改点。
