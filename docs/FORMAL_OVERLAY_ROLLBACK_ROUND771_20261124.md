# Round771：正式最小覆盖独立回滚器

## 完成内容

新增 `tools/rollback_formal_minimal_overlay.py`。它只接受部署器生成并位于对应备份目录内的正式部署回执，默认仍为无写入预检；只有显式 `--execute` 且正式服务状态为 `idle` 时才执行恢复。

回滚器逐项验证：部署回执 schema、显式执行状态、正式当前新哈希、旧文件备份哈希、备份路径边界和重复文件。正式文件在部署后若又发生未知变化，回滚器会失败关闭，不会覆盖后续现场修改。

## 恢复行为

- 原来存在的文件从冻结备份恢复，并进行 SHA-256 读回。
- 原来不存在的新增文件在回滚时删除。
- 回滚前再次保存当前已部署版本，若恢复过程本身中途失败，会把已恢复项目重新切回部署版本。
- 回滚结果写入原备份目录，不接触人工真值、训练集或 `test24`。

## 验证

部署、发布后验收与回滚组合测试共 12/12 通过。其中回滚专项 4/4，覆盖默认零写入、恢复旧文件并删除新增文件、服务忙碌时阻断、部署后文件漂移时阻断。

本轮没有对正式 `D:\Apps\LabelAgent` 执行部署或回滚；正式 8765 服务未停止、未重启、未写入。
