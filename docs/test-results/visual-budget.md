10张图片×256/1024视觉token，20次真实回答。输入照片从相同原生裁块和相同完整mask视图范围重建为1024像素；两组图像字节完全一致，仅image_token_budget不同。与更早512像素请求不是字节相同的复用。1024图插值不新增原生信息，测试的是更多视觉采样/token是否改善描述，不能称为拍摄质量提升。
