# 第 356 轮：参考帧起稿的低空间前置保护

## 解决的问题

第 355 轮首次非首帧验收时，D 盘临时空间一度不足。旧流程已经开始参考帧请求，随后在保存阶段失败，用户看到的只是难理解的响应解析错误，很容易误以为 SAM3 或 Local VLM 离线。

本轮把磁盘检查前移到参考帧自动起稿入口。现在空间不足时，流程会在读取当前图像、调用 SAM3、调用 VLM 或保存候选之前停止，并明确显示：

> 保存空间不足，尚未启动推理

因此不会白跑模型，也不会让失败看起来像“推理一直卡住”。

## 改动

### 后端

- `/api/reference_draft` 在正式解码图像前检查单帧安全保存余量；
- 空间不足返回结构化 JSON、HTTP 507 和 `storage_low` 原因码；
- 回执明确保持 `candidate_only=true`、`human_truth=false`、`approved_for_training=false`；
- 低空间路径不会调用 `frame_image` 或模型推理函数。

### 前端

- 参考帧起稿不再直接假定服务端一定返回 JSON；
- 若返回低空间状态，明确提示“尚未启动推理”；
- 若服务端意外返回网页或其他非 JSON 内容，显示 HTTP 状态并拒绝采用任何结果；
- 不把磁盘故障、服务异常包装成 SAM3/VLM 已生成结果。
