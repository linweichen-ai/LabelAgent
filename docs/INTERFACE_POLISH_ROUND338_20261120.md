# LabelAgent 界面质感优化（Round 338）

日期：2026-11-20

## 目标

在 Round337 宽屏双栏布局基础上继续提升页面完成度，使工作台更接近成熟产品，同时不改变现有操作位置、推理流程、候选内容、人工真值和训练审批边界。

## 本轮调整

- 字体改为 Windows 原生的 Segoe UI Variable / 微软雅黑 UI 组合，中文、英文和数字层级更统一。
- 统一按钮、输入框、卡片、状态标签的圆角、边框、悬停反馈和键盘聚焦状态。
- 顶部工具栏采用克制的半透明纸面与轻微模糊，品牌标记和模式切换形成清晰主次。
- 自动标注操作台改为分区卡片：运行设置、推理类别、候选覆盖、批量复核、风险复核、运行进度和过程标签各自成组。
- 主操作按钮使用深蓝层级；清除候选保留红色风险提示，绿色、黄色、红色仍只用于状态语义。
- 候选统计、运行统计和复核卡片增加轻量阴影与统一数字排版，减少“表格拼接感”。
- 优化滚动条，降低长页面滚动时的视觉干扰。

## 响应式处理

- 2560×1112：顶部单行，图像与操作台全部主要区域同时可见，无需在操作台内部滚动。
- 1280×720：自动隐藏次要顶部文字，工具栏由两行恢复为单行；图像完整显示宽度由首轮检查的 437.5 px 提升到 495 px。
- 小高度屏幕中，右侧操作台独立滚动，页面结构和左侧图像保持稳定。
- 1280×720 实测操作台可视高度 444 px、内容高度 974 px，`overflow-y: auto` 生效。
