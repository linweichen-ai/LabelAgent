# 以2342方案为基准的候选名额回收实验

完整588图正在运行，结果尚未得出。当前联合通过的离线参考仍为2342对象支持、142404托盘覆盖点、2184人员误覆盖点；原始标注和工作台默认策略保持。

## 改进依据与规则

2342方案已用满6420个托盘候选预算，其中23个新增候选各自覆盖不足3个原始点。按原V2规则，一个至少5点的可评估对象需覆盖至少一半才能匹配，只有2个原始点的候选不可能在原3像素口径支持一个对象。原程序合成测试确认3/5可以匹配、2/5不能匹配。

不是将这23个候选一律移除。新实验仅允许移除旧四分块前缀以外、少于3个原始点、且移除后每张图在0/3/6像素三档的全部原始点并集仍逐点相同的新增候选。逐一更新覆盖计数，避免同时移除多个重复候选导致丢掉最后覆盖者。已确认及已批准参考不作为预测输入；所有原始候选与历史方案继续独立保留。

腾出的预算依原有分数、NMS、空间排序、1.5倍数量上限和1.25倍面积上限分配。新补入候选至少覆盖3个原始点，而且每档全部命中点必须位于2342方案已有并集内，不允许新增任何原始点覆盖。旧四分块每个轮廓仍保持原样前缀，人员候选不改写。此规则只优化离线候选分配，不将少点轮廓视为错误目标或删除源标注。

## 已完成的小范围验证

406项回归全部通过，无跳过。原20图实际回收1个冗余新增轮廓、补入1个候选；原V2评分仍为78/118对象、5214/6291覆盖点、55/11068人员误覆盖，与2342方案对应的20图相同。两类逐图三档点覆盖与交叉计数完全一致，原八项门槛保持；尚无小范围分数增益。

完整实验在评分前已预声明：因全量预算受限且有23个低点数新增候选，验证这一名额回收机制在588图上的效果；小范围不退步不能当作全量改进。完整588图统一分配预算，预测冻结后才实际评分，不读取参考或按参考点坐标筛选。

## 完整验收要求

必须严格超过2342对象支持、托盘覆盖不少于142404、人员误覆盖不高于2184；原八项门槛、逐图三档保护、旧轮廓和已批准13托盘/5人员保留全部保持。本实验额外要求每图两类在0/3/6像素的覆盖及交叉计数与2342完全相同。任一失败均不替换当前方案，不能只因超过历史2298就采用。

本轮新增模型调用0，不训练模型或修改权重。新旧候选均为离线未确认输出；指标为同一反复使用采集的稀疏投影参考一致性，不是独立像素精度。
