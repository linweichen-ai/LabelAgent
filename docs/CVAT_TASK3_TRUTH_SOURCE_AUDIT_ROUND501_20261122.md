# Round501：CVAT Task3 人工/自动来源审计

## 结论

`CVAT_Task3_20261028/imported_truth.json` 不能直接当作完整人工真值训练集。

- 150 帧、1,550 个形状均可解析，来源字段没有缺失或未知值。
- 1,469 个形状的 `cvat_metadata.source=auto`，81 个为 `manual`。
- 81 个人工形状全部是 `pallet`，分别位于 81 帧，每帧恰好 1 个人工形状。
- 这 81 帧同时包含自动形状；其余 69 帧全部为自动形状。
- 非空且全形状均为人工的帧数为 **0**，所以完整人工真值帧候选为 **0**。
- 没有哈希绑定的独立复核签字，因此整帧训练和人工实例训练均不放行。

这不是说 81 个人工栈板轮廓没有价值。它们可以进入“人工实例候选”队列，后续采用只在已确认实例区域计算损失、其余区域全部忽略的偏标注训练协议；但在协议和复核回执完成前，不能把同帧的自动结果或未标区域当作真值/负样本。

## 为什么之前容易产生误解

这份文件名叫 `imported_truth.json`，并且工作台能显示全部 1,550 个形状；但文件名和可显示性都不能证明标注来源。真正决定来源的是每个形状里的 `cvat_metadata.source`。

原导入清单也明确记录：它来自本地已验证快照，`remote_cvat_current_state_checked=false`、远端写入为 0。因此本轮只能对冻结快照做来源审计，不能把它表述成当前在线 CVAT 已全部人工复核。

## 新增可复现审计

- 工具：`tools/audit_imported_cvat_truth_sources.py`
- 定向测试：`tests/test_audit_imported_cvat_truth_sources.py`
- 结构化结果：`artifacts/round501-cvat-task3-source-audit-20261122/audit.json`
- 输入文件 SHA-256：`381a8f2e76a4d58d013302cd416842eaed88cb720b8cfc42185efe6e0e0f6c8a`
- 审计结果 SHA-256：`c7fed8cbff2702f549e191ba6a514af16be17a58d52ca1a0a4fe853900ac6c23`

审计器会：

1. 同时识别实际使用的帧号对象结构和列表结构；
2. 检查帧、形状、类别、多边形和 parts 的基本结构；
3. 按帧与类别统计 `manual`、`auto` 和未知来源；
4. 将混合帧与全人工帧严格分开；
5. 对未知来源失败关闭；
6. 即使出现全人工帧，也必须提供输入哈希绑定、含复核人身份的独立签字回执才放行。

4 项定向测试全部通过：混合帧不会冒充全人工帧；全人工帧在无签字时仍拦截；合法签字只能批准全人工帧；未知来源失败关闭。

## 决策与下一步

1. 不用 Task3 的 150 帧做整帧监督微调；不把 1,469 个自动形状升级为人工真值。
2. 保留 81 个人工栈板实例作为“偏标注训练候选”，先生成只包含人工实例、其他像素为 ignore 的训练清单。
3. 在候选清单上增加人工/助手复核回执，明确每个实例是否轮廓完整；未签字的实例不进入训练。
4. train72 仍是人工训练门的主路径；test24 继续只做冻结评测，禁止回流训练。
5. 当前 SAM3 基线继续保留；已退化的投影伪真值 checkpoint 不部署、不恢复长训。

本轮只读取冻结文件并写本地审计产物；未修改 CVAT、原始数据、真值、候选、权重或生产工作台，也未启动 GPU 训练。
