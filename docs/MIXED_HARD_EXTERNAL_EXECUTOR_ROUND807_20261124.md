# Round807：外部专家影子执行器授权门禁

新增 `tools/run_mixed_hard_external_shadow.py`，用于在未来获得明确授权后执行 Round806 的17张
困难帧外部复查。当前没有生成授权回执，也没有执行任何真实图像上传。

执行器在读取图像或调用模型前必须同时验证：

1. 队列、34帧清单、工作区回执和授权回执的 SHA-256 绑定一致；
2. 授权回执明确写明 `authorized=true`、17张范围、授权人和
   `mixed_hard_external_shadow` 用途；
3. 所有候选、真值、训练批准和 test24 边界保持不变；
4. 每张图片的本地文件哈希同时匹配队列与工作区回执；
5. 既有续跑结果必须属于同一授权和同一队列。

本轮测试包括：缺失授权、授权为 false、授权队列哈希不匹配、图片哈希漂移，以及使用注入的
假模型完成候选结果。3项测试全部通过。

又以真实 Round806 参数但不存在的授权文件运行一次命令：执行器在任何网络调用前以退出码1
拒绝，且没有创建结果文件。正式工作台、外部 API、人工真值、训练批准与 test24 均未触碰。
