# 密集栈板跨帧点提示 SAM 复核（Round 700–701）

日期：2026-11-23

## 结论

对跨帧几何门筛出的 7 个提示机会进行了真实、只读的 SAM 点提示复核。7 个实例均未通过完整验收，恢复数为 0/7；旧的中心帧 LiDAR 基线同样为 0/7。因此本轮证明“跨帧能提供更多稳定提示位置”，但尚未证明“这些提示能恢复密集栈板实例分割”。

两次真实运行的语义结果、候选掩码 SHA-256 和逐策略指标完全一致。报告文件因输出绝对路径与服务缓存计数不同而不要求逐字节相同；去除这些运行环境字段后的规范化语义 SHA-256 均为 `768519c32aa938963200c204b97ce40c9bf6e82dfa4bc2119702ebbf680fc0b4`。

## 固定评测协议

- 只处理 Round 699 中 7 个 `opportunity`，并与 Round 676 的未解决实例逐项核对；
- 不信任报告中的坐标，而是从绑定的 11 帧标签/PCD 重新计算跨帧新正点；
- ROI 固定放大 2 倍，每实例最多选 3 个分散正提示和 4 个中心帧冲突负提示；
- 每实例冻结 8 种策略：原三种、纯正点、以及四个单负点分支；
- 验收使用全部跨帧正点与全部中心冲突负点，而不是只检查送给模型的提示子集；
- 同时要求定位、正点覆盖、负点排除、深度拆分和实例间分离全部通过；
- 2 个实例各出现 1 个正负投影同像素。模型输入中删除矛盾负提示，但该像素仍同时保留在完整正/负验收分母中，门槛没有放松。

共绑定 73 个输入，包括机会报告、重叠报告、旧基线、图像/PCD 清单、工具源码、实际图像、中心与时间窗标签/PCD、标定和所有相关拆分掩码。SAM URL 强制为本机回环地址，输入在解析前后及运行结束时复核。

- 全量回归：`1676 passed, 1 skipped, 262 subtests passed`；
- 两轮各评测 7 个实例、56 个策略，候选掩码 SHA 全部一致；
- 与 Round 677 只是同源开发对照，不是独立验证；

下一步冻结本轮负结果，转向“冲突组联合候选选择”：同时为一组互相遮挡的栈板选择候选并统一深度拆分，检验当前失败是否主要来自其他栈板旧掩码，而不是目标提示本身。
