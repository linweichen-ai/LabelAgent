# Round818：困难集受控机器提示复核台

## 改进目的

34帧人工复核页原先只能逐图填写，无法按需查看已经完成的本地Qwen8B判断。本轮新增一个默认折叠的机器建议面板：复核人先独立看图，需要时按 `H` 展开建议进行交叉检查。

机器建议只显示存在/不确定类别、总体置信度、斜坡形态、托盘实例与质量、类别冲突、困难因素、未知候选和机器备注。页面不会把这些值复制到人工表单；切换帧时面板自动关闭，减少先入为主。

## 数据与哈希绑定

- 复核样本：34帧；
- 原图与候选叠加图：各34张；
- 本地Qwen建议：34/34；
- 建议文件SHA-256：`b0bff89db15a664d0e6bae1ce1a06b3a357b89c7efd3825b517e4a90051c8b1b`；
- 复核页面SHA-256：`b23c2ebb84d7ffb0deebf1c3aa6061eb5ee53a99217add62c698611f7fafd9c0`。

加载建议前会验证建议包状态、安全边界、清单哈希、34个样本ID，以及每张实际复核原图的SHA-256。最初实现错误地拿原始采集图哈希与复核JPEG哈希比较，被门禁拒绝；修正后明确绑定模型实际读取的复核原图，且在复制文件前完成校验，避免失败时生成半成品页面。

## 使用方法

打开：

`artifacts/round818-diverse-hard-adjudication-assisted-20261124/reviewer.html`

- `J/K`：下一张/上一张；
- `G`：跳到下一张未完成；
- `R/V/B`：原图/候选叠加/左右对比；
- `H`：展开或关闭机器建议；
- 随时可导出草稿；全部34帧填写后导出 `mixed-hard-adjudication.json`。

## 安全边界

该页面不会联网，不会调用API，不会写入正式工作台。机器建议保持 `candidate_only=true`、`human_truth=false`、`approved_for_training=false`；人工复核完成也不自动授权训练或部署，不使用test24。

完整项目回归为1968项通过、1项跳过、294项子测试通过。
