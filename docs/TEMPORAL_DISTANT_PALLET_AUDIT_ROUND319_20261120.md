# Round 319：远处栈板相邻帧补全审计

日期：2026-11-20

## 结论

在 `Capture_20261103` 四相机中，对 Round 299 选出的 16 个远处/狭长困难栈板，读取前后
`-2/-1/+1/+2` 共 64 个相邻帧组合，以双向光流运输已有 SAM3 栈板候选。515 个候选通过了
光流往返一致性与多边形导出门槛，但没有一个同时满足：

1. 覆盖当前薄片候选至少 50%；
2. 面积至少扩展到 1.25 倍；
3. 只沿候选主轴补全，次轴不突然吞入背景；
4. 与同帧其他栈板的重叠不超过提案面积的 10%。

因此合格扩展为 `0/64`，两帧独立一致的扩展也为 `0/16`。这条路线没有安全自动替换，未部署、
未改写工作台，也没有通过放宽阈值制造表面增益。

## 为什么做

近景木栈板的木纹碎洞、边缘凹口和像素锯齿已经由 v5 受限几何清理处理；全量 4,423 个候选
审计中没有组件合并、结构孔保留或修改预算违规。剩余困难样本主要是远处栈板只被 SAM3 找到
一条薄边。Round 300–303 的固定裁剪与候选中心 ROI 都没有形成安全替换，本轮验证相邻帧是否
能提供更完整、且不粘连相邻实例的同一目标证据。

## 方法与门禁

- 只读取已有原图和已有 SAM3 候选，不发起新模型请求；
- 双向光流在 `480×384` 网格计算，再映射回 `1920×1536`；
- 前向/反向往返一致的前景比例至少 80%；
- 多边形重新栅格化 IoU 至少 95%；
- 候选分数至少 0.5；
- 继续复用 Round 302 的主轴门禁和 Round 303 的相邻实例门禁；
- 即使单个相邻帧通过，也必须至少由另一个不同相邻帧以 IoU ≥ 45% 独立支持，才列为时序一致
  候选。
