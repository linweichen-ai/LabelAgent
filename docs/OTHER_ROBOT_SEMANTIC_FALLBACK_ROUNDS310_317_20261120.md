# `other_robot` 语义补漏与生产部署：Round 310–317

日期：2026-11-20

## 一句话结论

在 8B 已明确判断画面存在 `other_robot`、而基线 SAM 查询 `robot` 返回 0 个候选时，工作台现在会额外尝试一次颜色无关的 `autonomous pallet truck` 查询，按 SAM 分数只保留前 3 个候选，并继续走原有高风险类别盲审。隔离新数据实测从 0 个提升到 3 个 `other_robot` 候选，其中 1 个被 8B 高置信保留、2 个转人工；本车和普通人工设备没有被自动写成人工真值。该能力已带源码备份部署到本机工作台。

## 强制边界

- 补漏候选始终是机器候选，不是人工真值。
- 没有候选自动批准进入训练集，也没有修改 SAM/VLM 权重。
- 只有 8B 可见类别发现明确包含 `other_robot` 且基线 SAM 结果为空时才触发。
- 每帧最多保留 3 个补漏候选；未保留候选只记录原因，不能据此宣称完整覆盖。
- 所有保留候选仍由既有盲审判定为保留或转人工，不绕过审核门禁。

该帧同时存在多台远处机器人和本车双货叉。原始 6 个候选中：
