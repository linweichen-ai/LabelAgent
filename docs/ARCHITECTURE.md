# LabelAgent 架构与数据边界

## 1. 目标

LabelAgent 将工厂采集的图片或 MCAP 转换为可人工复核的分割候选，减少从零绘制标注的工作量。系统不把模型输出直接当成人工真值，也不自动将候选投入训练。

## 2. 运行链路

1. **数据读取**：加载图片或 MCAP，选择相机 topic 与帧。
2. **参考准备**：使用人工参考帧、已批准轮廓或显式提示点。
3. **SAM3 候选**：生成目标掩码；此时结果仍是机器候选。
4. **VLM 复查**：检查类别、遗漏、冲突和开放集目标；不可用时明确降级，不伪造复查结果。
5. **Agent 修改**：只执行允许的局部操作，并保留输入、决策与修改记录。
6. **结果叠加**：将最终候选叠加回原图，供人检查。
7. **人工确认**：接受、修改或拒绝；只有确认后的内容才可保存为人工真值。
8. **训练审批**：人工真值进入训练前仍需独立审批、划分隔离和质量门禁。

## 3. 状态边界

| 状态 | 含义 | 能否直接训练 |
|---|---|---|
| 机器候选 | SAM3/VLM/Agent 自动生成 | 否 |
| 会话草稿 | 浏览器本地暂存，绑定数据和清单哈希 | 否 |
| 人工真值 | 人工检查并确认 | 仍需训练审批 |
| 训练批准 | 通过数据质量和划分门禁 | 可以 |
| 训练产物 | 新权重或适配器 | 不能自动部署 |
| 正式模型 | 通过独立验收后人工部署 | 是当前线上版本 |

## 4. 服务关系

```text
浏览器工作台 :8765
    ├─ Agent 服务：数据、流程、候选、VLM 和审计记录
    ├─ SAM3 服务 :8766：点提示 / 多提示分割
    └─ VLM 服务：OpenAI 兼容视觉接口，可本地或远程部署
```

`Local VLM is busy` 表示共享模型槽位被占用，不应通过重复点击制造更多请求。服务不可用时应保留 SAM3/人工路径，并明确提示降级状态。

## 5. 斜坡口径

当前项目约定斜坡属于可通行区域，可以在业务评估中与地面统一；如果标签体系仍保留 `slope`，需要在评测配置中明确“保留独立类别”或“合并为 floor”，不得混用两套统计口径。

## 6. 发布边界

`release` 分支只保留运行、安装、核心测试和主文档。研发过程证据留在 `reproduce`/`labelagent`，私有数据、权重和密钥不进入 Git。
