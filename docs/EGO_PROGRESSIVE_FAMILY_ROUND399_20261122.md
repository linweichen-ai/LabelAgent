# Round399：camera1 固定提示族按需回退（2026-11-22）

## 方案

Round398 的固定三请求在普通帧很快，但frame38、19、57未通过90%原候选保留门禁。本轮不降低门槛，而是在固定三组失败时，按预先固定顺序追加剩余正点子集：先三点组合，再两点、单点；每次追加后立即复算正点覆盖、负点侵入和原候选保留率，一旦通过就停止。

固定提示族仍只由开发帧产生；回退顺序与图像内容无关，留出帧不参与选择。所有结果仍是影子候选。

## 结论

按需回退只救回了已曝光开发帧frame38，没有改善留出集；留出集仍为2/4，而困难帧需要14次追加请求。这是明确的泛化负结果：继续在同一九帧上堆提示会增加延迟并过拟合开发帧。

因此：

- 不接入正式工作台；
- 不降低90%非退化门槛；
- 停止在这九帧上继续调提示组合；
- 下一步转向人工像素真值或独立新相机序列，验证Round397候选是否真的改善IoU和person/floor误纳；
- 在有独立质量证据前，不做微调、训练批准或自动合并。
