# Round515：81项离线人工签字复核台

## 本轮目标

Round511 已生成81项空白人工签字模板，Round513–514 已完成失败关闭的签字导入门禁，但此前仍缺少一个不依赖服务、不会自动替人做决定的实际复核界面。本轮由 WorkBuddy 在隔离分支实现初版，再由主线逐项审计、补强并用冻结私有输入生成真实复核包。

## 已完成能力

- 单个静态 HTML 内嵌81张经 SHA-256 复核的聚焦证据图；页面不联网、不读取外部脚本、不使用 `localStorage`。
- 每项只能由人工选择 `pass`、`reject` 或 `uncertain`，并填写复核人、带时区的合法 ISO 时间和可选备注。
- 支持全部/未完成/三种结论筛选、循环导航、未完成计数，以及把复核人和时间统一填入所有未完成项。
- 81项未全部完成时，导出按钮保持禁用；导出的 JSON 仍明确 `training_authorized=false`、`automatic_approval=false`，人工通过不等于训练授权。
- review manifest、空白模板、81项身份字段及三类哈希、图片规范路径和图片哈希全部失败关闭校验。

## 主线补强

WorkBuddy 初版通过8项合成测试。主线复核后继续补齐：

1. 页面端严格校验带时区 ISO 时间，避免形式完整但导入门禁必然拒绝的结果。
2. 增加“统一填写全部未完成项”的真实操作，不再只有文字提示。
3. JSON 单文件上限4 MiB、单图上限8 MiB、图片总量上限128 MiB，防止异常输入占满内存。
4. 输出先写临时目录，再原子改名；任何写入失败都删除本轮临时内容，不留下半成品。
5. 私有输出只允许是仓库 `.repro/` 的直接子目录，已存在目标永不覆盖。
6. 命令行失败只输出短错误，不暴露本机敏感路径或 traceback。
7. 空白模板若预填 decision、reviewer、reviewed_at、note 或非零签字计数，整包拒绝。

## 验证结果

- 复核台生成器12项定向测试全部通过。
- 与既有签字导入门禁合并共36项测试全部通过，并以 Python warning-as-error 模式运行。
- 冻结真实输入成功生成81项私有复核台：81项待定、81张图全部内嵌、页面哈希与 manifest 一致。
- 静态检查确认外部脚本0、网络调用0、`localStorage` 0，训练授权与自动批准均为否。
- 自动化浏览器因安全策略禁止直接打开 `file://`，因此本轮没有把“视觉点击验收”冒充已完成；这不影响静态完整性结论，首次人工使用时仍需手动打开页面做一次交互确认。

## 使用方法

1. 使用生成器，并显式提供两份冻结输入的 SHA-256；输出必须是仓库 `.repro/` 下一个全新的直接子目录。
2. 人工打开输出目录内的 `index.html`，逐项复核并完成81项。
3. 下载页面导出的 `human-signoff.json`。
4. 把该文件交给 Round513–514 的签字导入门禁；即使全部人工通过，也只形成私有通过集合，不会自动进入训练。

## 当前边界

本轮没有代替人工填写81项，没有读取 test24，没有训练、部署或改写真值。复核人仍是声明字符串，不是账号认证或数字签名；浏览器刷新会丢失尚未导出的内存状态。因此训练授权继续关闭，下一步是人工完成复核并通过既有导入门禁。
