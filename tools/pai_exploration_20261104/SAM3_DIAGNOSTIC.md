# SAM3：先判断需要训练哪一部分

目前只有三维框参考与少量已确认二维标注；本包60例的模型轮廓仅用于指定复查对象，不是人工掩码。它们不能直接作为SAM3监督信号。

先在20—30张开发图上人工画精确二维框，对漏分、粘连、小目标分别测试同一原版SAM3：文本提示、人工框/点提示。提示来源必须写入记录，人工框提示属于诊断，不是自动方法。

| 结果 | 后续 |
|---|---|
| 人工提示后轮廓明显恢复 | 先改善VLM定位或提示生成，保留SAM3权重 |
| 人工提示后仍明显错误 | 人工补齐100—200张精细掩码开发数据，再做SAM3领域微调 |
| 轮廓可用、类别错误 | 优先Qwen复查任务微调 |
| 意见正确、工具没改结果 | 先修Agent执行 |

每例记录：图像哈希、目标类别、提示来源/坐标、原始候选、人工掩码、mask IoU、边界指标、漏检/粘连和耗时。高质量掩码尚未提供，不能现在给出有效训练提升。按采集序列分训练/开发/独立测试，所有相机与相邻帧同组；新序列测试隔离。

SAM3官方支持自定义数据训练及单机多GPU，但需要按其配置正确转换数据、类别和提示，本包**未提供一个假装已适配本数据集的Hydra配置或未经验证的训练入口**。完成上述数据后，使用独立环境、锁定SAM3提交、适配COCO实例标注，先做10步训练和保存/重载验证，再小规模训练；初次预算单张80GB卡，实际按显存测量调整，不与32B常驻服务争抢显存。训练与推理的显存需求不能互相代替。
