# Round384：ego 正负点补漏影子复核（2026-11-22）

## 结论

本轮确认了一个可继续研究、但尚不能上线的方向：当主 VLM 高置信判断 `ego`
可见，而文字提示和原有单点补救都没有合格候选时，多正点加负点可以让 SAM 3
从人和地面中分出相机载体车身。这个能力在 `/capture/camera_1/image` 的
0、1、2、5、10、76、151 七个时点都出现了，但掩膜仍有孔洞、缺口，固定坐标
也不能直接迁移到其它相机。因此本轮没有修改正式候选逻辑、人工真值或训练批准，
也没有部署新的自动补漏。

## 为什么要做这轮

正式状态中的第 0 帧有 17 个机器候选，主 VLM 对 `ego` 给出 `present=0.99`，
但正式候选里没有 `ego`。原有保护逻辑已触发底部点补救，但 18 个原始候选全部
被 guard 拒绝。拒绝原因从新增加的有界几何摘要可以看清：高分候选多数是大范围
粘连，另一些是人或小碎片。保护逻辑没有误杀一个明显完整的车体候选。

## 实验结果

### 1. 文字提示没有解决定位

在同一真实帧上测试 `ego robot`、`forklift`、`forklift body`、
`forklift chassis`、`robot chassis`、`forklift hood`、`camera robot`，
7/7 都没有返回候选。继续堆同义词没有证据支持。

### 2. 单正点仍然欠约束

原有 18 个底部正点产生 18 个原始候选、0 个守门后候选。典型高分结果会覆盖
整片下半画面或把人与车体粘在一起；现有 guard 的拒绝是正确的。

### 3. 正负点能够分离，但只达到影子候选水平

首轮三组正负点都只覆盖局部。第二轮的四个车体正点加三个负点在第 0 帧得到：

- score：0.5195；
- bbox：`[968, 905, 1605, 1536]`；
- 面积比例：0.0923；
- 视觉结果：覆盖大部分前景红黑车体，能够避开主要人物区域，但仍有内部孔洞、
  边缘缺口和不连续区域。

人物负对照能单独分出人物，说明模型在这帧具备车体/人物分离能力；这不等于
候选已达到人工真值质量。

### 4. 同相机跨帧有重复性，但固定点会随运动欠分割

同一套点位在 camera1 七个时点都返回车体候选：

| 帧 | score | 面积比例 | bbox |
|---:|---:|---:|---|
| 0 | 0.5195 | 0.0923 | 968,905,1605,1536 |
| 1 | 0.5156 | 0.0916 | 974,905,1604,1536 |
| 2 | 0.4941 | 0.0902 | 966,906,1605,1536 |
| 5 | 0.4785 | 0.0397 | 1048,1030,1545,1536 |
| 10 | 0.4688 | 0.0381 | 1047,1032,1558,1536 |
| 76 | 0.4531 | 0.0887 | 982,913,1600,1536 |
| 151 | 0.5391 | 0.0909 | 962,918,1612,1536 |

一次点提示请求约 0.31–0.67 秒。第 5、10 帧的面积明显下降，说明固定坐标会随
遮挡和姿态变化而只切出部分车体。

### 5. 跨相机不能复用同一坐标模板

camera0、camera2 同样能产生车体附近候选，但会混入人或漏掉车体部分；camera3
对三组车体点位全部返回“无法排除当前负点区域”。这证明下一步必须按相机建立
独立归一化模板，并保持 VLM 可见性门禁；不能把 camera1 的点位直接作为通用规则。

## 工具与可观测性改进

新增 `tools/diagnose_ego_guided_points.py`：

- 只允许本机 point-SAM 地址；
- 每次最多 8 组、每组最多 32 个点，且必须有正点；
- 只写独立影子结果，明确 `human_truth=false`、
  `approved_for_training=false`、`production_deployed=false`；
- 单组 HTTP 失败不会中断其它实验；
- HTTP 400 现在会显示服务端原因，例如“无法排除当前负点区域，请补充或调整提示点”。

同时增强原有底部点诊断，保存有界 bbox、面积、宽高比例、底部距离和中心位置，
避免为了查错保存完整 mask 像素。

## 下一步门槛

进入正式候选前至少要完成：

1. 按相机建立归一化点位模板，禁止跨相机复用固定像素坐标；
2. 每路相机覆盖开头、中段、末段和遮挡变化，至少 20 帧人工对照；
3. 用人工确认的 ego 真值计算候选召回、人物侵入率、车体覆盖率和孔洞率；
4. 任何候选碰到人物主干、面积突变超过预设范围、跨越错误画面区域或 point-SAM
   返回排除失败，都必须失败关闭；
5. 影子评测不得阻塞正式首批结果，不得写候选、真值、审核状态或训练批准。

当前决定：保留现有正式 guard，不把多点结果接入生产；下一轮只做相机感知的归一化
模板与人工真值小样本 A/B。
