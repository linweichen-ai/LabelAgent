# 同区域SAM3类别证据保护：全图及局部实测

全部29例参与，复用58份原卡片VLM回答。加入同图SAM3区域证据后，人工区域正确一致保持14/19，一致错类1处降为0处，两个新增相反类别视图错误均被拦下，疑似反光也输出不确定。但旧五处目视托盘的确认数由4处降为全图保护1处、补充局部保护2处，仍未满足原至少3处要求。两套方法均未采用，工作台默认保持。

## 同一目标与原始文件的核对

19处人工类别区域与旧10例功能面板全部保留，其中两处是合成空白。27处非空白目标找到原模型多边形及原始图像，逐一重建用于卡片的三个原JPEG输入，81份文件摘要完全一致。没有从压缩图片反推精确轮廓，也没有把展示卡片的坐标当作原图坐标。

27处目标实际来自10张原图，复用原始全帧托盘／人员各一次、共20份SAM3缓存；每份缓存核对图像摘要、帧、相机、提示类别、状态、返回数和有效几何。推理侧的目标轮廓只保留几何，去掉原轮廓类别、编号和分数，预期类别只在独立计分时读取。

## 固定规则与两阶段试验

先执行已固定的未标记源图可用性检查，空白保持不确定。对其余目标，将原轮廓转为精确像素区域：某类别至少一份同图SAM3轮廓覆盖目标像素的一半，才算有该类别支持，边界采用整数`2×覆盖像素≥目标像素`。不联合多个零碎轮廓凑支持；两个类别对称，不读取分数或预期答案。

仅在VLM提议恰好等于唯一有支持的类别时保留；两类都支持、都不支持或与提议不符时输出不确定。保护步骤不主动生成相反类别或改变轮廓。

第一阶段只使用原全图缓存，0次新推理。完整回放后发现旧小托盘支持不足，第二阶段另立固定方案：对全部27处非空白区域的同一未标记原裁片，分别实际调用托盘和人员两个提示，共54次新SAM3请求。裁片与原图的偏移、尺寸、目标像素完整保留均在调用前固定，提示次序交替。原全图轮廓按对应裁片截取后，与局部轮廓共用原单轮廓半覆盖规则，未降低覆盖门槛或原验收要求。

第二阶段先完成54份响应，再用固定规则计分；没有根据结果选择只补跑哪些失败例。两阶段均使用相同58份已保存的VLM回答，0次新VLM推理。

## 验证、运行状态和限制

新增8项类别证据检查及4项裁片检查，覆盖类别对称、恰好半覆盖、双类冲突、邻近物体与碎片、空／错误尺寸、缓存身份与类别、洞结构、输入不改写、坐标偏移、原图与裁片摘要不能互换以及新增相反类支持应弃权。连同8项原源图检查，最终20项通过，耗时0.130秒；未重跑整套历史回归。

另一个只读核查程序逐例重算27处全图及局部覆盖、58个视图决策和两套完整类别计数；54份新请求体逐份重建摘要，管理器及服务日志各核对54次成功请求。原224个全图、231个局部输入／代码／状态绑定，以及新响应摘要保持。

本地显卡由现有管理器切换给SAM3，54次实际分割完成后，临时SAM3工作进程由管理器回收，本地2B NF4恢复，默认图像预算256，管理器仅有一个就绪工作进程。工作台仍为已完成10帧，状态文件摘要保持。此次0次新VLM调用、0次训练、0次原标注／工作台／候选写入，原三维指标不变。

这是已知失败样例上的开发试验；19处人工类别区域来自两张已使用图像，轮廓本身由模型生成。SAM3缓存与部分目标轮廓具有共同来源，这种相符可能是模型自一致，不能视为独立语义或像素真值。尚未获得独立场景验证或新的完整Agent修正验收，不能把一致错类减少等同全数据集分割精度提升。

下一项值得检验的是：当同区域SAM3只有一个支持类别，而VLM回答冲突时，是否能触发新一轮有针对性的视觉复查。当前只记录机会，不改写原回答或启用新的自动确认规则。
