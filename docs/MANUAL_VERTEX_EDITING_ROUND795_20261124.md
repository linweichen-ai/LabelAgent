# Round 795：人工轮廓节点编辑

## 目的

在不调用模型、不写入人工真值的情况下，让操作员可以快速修正机器候选或尚未确认的手工草稿边界，减少为了移动一个边界点而整段重画的成本。

## 操作

1. 在轮廓列表中选择一个尚未确认的简单轮廓；
2. 点击“节点编辑”或按 `M`；
3. 拖动白色节点调整边界；
4. 双击轮廓边线插入新节点；
5. 选中黄色节点后按 `Delete` 或 `Backspace` 删除；
6. 按 `Ctrl+Z` 撤销最近一次节点编辑；
7. 按 `Esc` 取消正在进行的拖动。

## 安全边界

- 只修改浏览器中的当前草稿，不调用任何保存 API；
- 已通过人工确认的真值保持只读；
- 多部件或含孔洞轮廓不做不完整的节点修改，界面引导使用“补区域 / 橡皮擦”；
- 节点拖动绑定帧、相机、文件、文件载入代次和工作模式；任何一项变化都会回滚旧拖动；
- 坐标限制在原图范围内；
- 删除后至少保留三个节点；
- 重复相邻节点、零面积和自交轮廓会被拒绝并回滚；
- 编辑机器候选后，旧 SAM 生成绑定和旧人工逐项检查状态立即失效，必须重新检查；
- 仍需经过原有显式人工保存和服务器读回门禁，才能成为人工真值。

## 与现有工具的优先级

节点编辑与多边形、矩形、椭圆、自由线、SAM 正点/负点、补区域和橡皮擦互斥。SAM 正在生成时，不允许启动节点编辑，但继续添加正负提示点的原有能力不受影响。

## 验收范围

- 简单轮廓顶点和边线命中；
- 多部件与孔洞拒绝；
- 拖动、插点、删点和一步撤销；
- 指针捕获、取消和作用域回滚；
- 人工真值保护；
- SAM 绑定与复核状态失效；
- 节点编辑代码段零 API 调用；
- 原有 SAM 点选与其他绘制工具回归。
