# Round525：陈旧进程记录的安全恢复

## 目标

Round524 能阻止 PID 复用导致的误停，但身份不匹配时会保留记录。用户随后再次启动仍会被存活 PID 阻挡，只能手工寻找并删除 JSON，使用体验不够顺畅。

## 新恢复入口

默认停止命令仍然失败关闭。只有在它明确报告记录陈旧后，用户才能显式运行：

```powershell
powershell -ExecutionPolicy Bypass -File tools\stop_local.ps1 -ArchiveStaleRecord
```

恢复规则：

- 当前克隆根目录必须与记录一致；
- 全部身份必须可读取且记录结构可验证；
- 不得存在任何仍与本克隆匹配的受管进程；
- 所有仍存活 PID 必须被正向确认成其他可执行文件或不同创建时间；
- 匹配身份与陈旧身份混合时拒绝恢复；
- 满足条件后只把记录移动到 `.repro/stale-process-records/`，不停止无关进程，也不直接删除记录。

## 真实双阶段测试

临时构造一份指向其他环境既有工作台进程的陈旧记录：

1. 不带恢复参数执行：退出码 1，记录保留，无关进程保持存活；
2. 带 `-ArchiveStaleRecord` 执行：退出码 0，原记录移入归档，无关进程仍保持存活；
3. 测试生成的归档随后清理，正式工作台未停止、未重启、未修改。
