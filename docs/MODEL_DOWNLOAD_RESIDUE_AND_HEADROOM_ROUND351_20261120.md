# 第 351 轮：模型下载残片取证、无损压缩与低空间预警

## 结论

本轮没有删除模型、数据集、候选、人工真值或训练资产，也没有启动 GPU 任务。通过逐字节只读核验，确认 125 个历史下载残片共 4.42 GiB，全部来自 2026 年 11 月 3 日的 Qwen3-VL-2B 下载过程；它们与现存完整权重重复。采用可逆的 Windows LZX 文件压缩后，物理占用减少 1,026,558,424 字节，D 盘可用空间从约 260.5 MiB 回升到约 1.19 GiB。

## 为什么可以认定为重复下载残片

- `model.safetensors.partial` 覆盖完整权重开头 146,800,640 字节；
- 123 个 `.range_chunks/*.part` 从该位置开始连续覆盖到完整权重末尾，没有缺口和重叠；
- 将 partial 与 123 个分片按偏移顺序读取后，与完整权重 4,255,140,312 字节逐字节一致；
- Hugging Face 的 470 MiB `.incomplete` 文件与完整权重前缀逐字节一致；
- 完整权重 SHA-256 为 `7de1838c87a5349b016c26a1c3f7d2bc400a3d485f95ef39a7059ffd734977a0`，与下载回执中的官方哈希一致；
- 没有业务进程使用这些残片。

因此，本轮只压缩历史下载副本，正式模型文件 `model.safetensors` 保持不变且不压缩，避免影响后续冷启动加载速度。

## 安全边界

精确删除动作被本机安全策略拒绝，因此没有绕过策略，也没有删除任何文件。压缩前后 `work/state.json` 的 SHA-256 均为 `9EF08118DD2BA0760CC93CF57BBEAAE4B3BED062D383DF4E6A454C389D4AB115`，说明候选、人工真值与训练许可状态均未改变。工作台始终在线，最终状态为 `idle`，当前数据集、topic 和激活代次未变化。

## 新增的长期保护

启动管理器现在会只读扫描模型目录下超过 24 小时的 `.partial`、`.part` 和 `.incomplete` 文件。当数据盘可用空间低于 2 GiB 时，管理器会明确报告残片数量与逻辑体积，并显示“不会自动删除”。该扫描不读取文件内容、不修改时间戳、不自动清理，也不会把残片混入训练资产。
