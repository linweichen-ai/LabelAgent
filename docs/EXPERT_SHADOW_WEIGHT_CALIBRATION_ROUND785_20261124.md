# Round785：困难帧影子路由权重校准

日期：2026-11-24

## 背景

困难帧影子路由器已经具备置信度、类别冲突、SAM 稳定性、Agent 轮数、边缘/小目标、未知类别和人工重点帧等信号，但旧版几何信号分值固定。工厂图像中靠边托盘与小托盘非常常见，因此需要先检查外部专家调用比例，不能直接启用真实上传。

## 离线审计

输入为当前开发工作台中已有的 30 个 Agent 运行回执。审计只读取候选元数据，不读取或发送图像，不调用外部 API，不修改工作台状态，并跳过任何明确标为 `test` 或 `test24` 的运行。

旧默认权重结果：

- 建议调用外部专家：29/30；
- 本地结果足够：1/30；
- 估算外部调用比例：96.67%；
- 主要原因：28 帧含靠边候选，28 帧含小候选。

这是一项明确负结果：旧规则几乎把所有已有开发帧都升级，不符合“普通帧本地、困难帧外部”的成本目标。

## 本轮修改

- 所有困难信号权重改为配置项，范围 0–20，不再把分值散落硬编码在判断逻辑中；
- `edge_candidate` 默认权重从 3 降为 1；
- `small_candidate` 默认权重从 2 降为 1；
- 画面边缘的 `slope` 保留额外 2 分，确保局部坡道仍能越过默认 3 分门槛；
- 未知类别、标签冲突、Agent 未收敛、SAM 不稳定和类别复核冲突仍保留强触发；
- readiness 回执新增完整权重表，便于界面和审计工具记录实际配置；
- 路由协议升级为 `labelagent.expert-shadow-routing.v2`。

校准后对同一 30 帧重放：

- 建议调用外部专家：17/30；
- 本地结果足够：13/30；
- 估算外部调用比例：56.67%；
- 12 个只有常见边缘/小托盘几何信号的帧不再升级；
- 两个含边缘坡道的帧仍被保留；
- Agent 未收敛、SAM 不稳定或类别冲突帧仍被保留。

## 边界与结论

本轮将影子建议比例降低 40 个百分点，但 30 帧本身是已有 Agent 运行子集，不代表未来全量普通帧分布。由于 34 张困难复核集尚未获得人工裁决，本轮不能计算精确率、召回率或 F1，也不能证明 56.67% 是最佳调用比例。

因此当前状态仍是：

- `dispatch_performed=false`；
- `external_upload_performed=false`；
- `candidate_only=true`；
- `human_truth=false`；
- `approved_for_training=false`；
- 不部署真实自动外部调用。

下一门槛是完成 34 张多样化开发集的人工裁决，再用同一真值比较仅本地、全外部与混合方案，并据此选择权重和阈值。
