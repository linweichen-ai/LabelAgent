这是使用已有三维标注定位目标后做的分类与载货状态小样本诊断。包内参考来源为 ali_label 与主 labels 的类别/状态一致部分，人审来源未核实；它没有替代用户选定的 labels 全帧主基准。该测试没有评测检测、分割边界或完整 Agent 纠错能力。

当前最明显的问题是人员全部误判及载货状态混淆。应先人工核查这 12 个目标的裁剪、青色目标框与参考状态，再固定输入对照提示或更大模型，最后检查能否改善实际 Agent 修正；不能仅凭增加显存宣称效果已经提高。
