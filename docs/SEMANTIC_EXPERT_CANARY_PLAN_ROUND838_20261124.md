# Round838：19帧专家候选的8帧分层哨兵计划

## 目的

真实图片尚未获得本轮外发授权，因此没有调用API。本轮只把Round837的19帧哈希队列进一步拆成“先8帧技术哨兵、通过后剩余11帧”，避免授权后一次性运行全部候选。

## 8帧覆盖

固定哨兵覆盖6种场景，并用两张补足数量：斜坡普通负例、斜坡正例、斜坡困难负例、批次B类别冲突、批次B平地困难负例、批次B坡道候选，以及第二张斜坡正例和第二张普通负例。8帧中包含1张由容器口专项复查新增的候选。

每帧只保存样本ID、场景组、源图SHA-256、实际复核图SHA-256和路由来源，不保存绝对路径。全部逐帧固定`external_upload_authorized=false`。

## 授权后的技术停止条件

只有得到明确授权后才能执行。每张图最多请求一次，不自动重试。首8帧必须同时满足：

- 8/8请求成功；
- 每次均返回Token用量；
- 中位延迟不超过60秒；
- 平均每次不超过30,000 Token。

任一门禁失败都停止，不运行剩余11帧。门禁通过也只允许继续同一哈希队列，不允许扩大样本；模型输出仍是候选，不写人工真值、不进入训练、不触碰test24、不部署。
