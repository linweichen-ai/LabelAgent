# 候选选择的参考匹配上界：诊断用途

此工具**有意读取参考标注**，只计算诊断上界，不是预测器，也不导出被参考标注挑选的候选。数值不能作为模型效果或准确率。它用于判断某一候选池和固定选择规则下，继续改排序是否还有实例增益空间。[脱敏结果](proposal_feasibility_results.json)

原基线、旧四分块和不受限全池的计分分别复现 68、75、83/118。对每张图，固定候选的最大匹配数为 r，固定加可选候选的最大匹配数为 R，剩余额度为 k，则忽略新候选之间冲突的乐观上界为 min(r+k, R)。匹配使用原 V2 的唯一点、同类纯度及一对一关系，没有把重叠掩膜重复算成多个实例。

| 条件 | 乐观匹配上界 |
| --- | --- |
| 保留全部原始候选、重选新增项；置信度、对固定候选 NMS 和原预算保持 | 82/118 |
| 上项再加预测人员零重叠保护 | 82/118 |
| 固定保留旧四分块已选结果，再用剩余额度补充 | 75/118 |
| 上项再加预测人员零重叠保护 | 75/118 |

这里放宽了新候选之间的 NMS、总并集面积和人员参考点覆盖上限，因此 82 仍不是已证明可以实现的成绩。但在同一池、同样预算与对固定候选去重规则下，即使放宽这些要求，“保留旧四分块再补充”的上界仍为 75。这个分支无法达到严格超过 75 的采用门槛，继续替换其余量排序权重也不能解决实例数量限制。

下一步应从未改动的原始基线重新选择新增候选，或产生新候选，而不是保留全部旧新增项后继续叠加。参考上界本身不参与预测排序。后续仍需遵守原数量、面积、人员保护及点覆盖要求，并用实际未读取参考的输出计分。

复现：`tools/diagnose_proposal_feasibility.py`，须提供三个已绑定数据集／图片摘要的基线、全候选池和旧选择导出。该入口明确是参考诊断，不接入工作台默认流程。当前没有用于这组目标帧的独立人工二维评测真值，全部数据仍来自同一短采集。
