# Round775：困难帧外部专家影子路由

## 本轮结论

已在现有 LabelAgent 流程中完成“本地模型默认处理、困难帧只记录外部专家建议”的可解释影子路由。它目前不会调用外部 API、不会上传图片、不会改变 SAM3 候选，也不会写入人工真值或训练集。

路由不再只看 Agent 轮数，而是同时记录本地 VLM 置信度、类别冲突、SAM3 候选稳定性、Agent 轮数、画面边缘目标、小目标、未知类别、专项类别和人工重点帧。所有阈值均可从工作台设置，不需要修改代码。

## 路由规则

每个信号产生可解释分数。默认综合分数达到 3 分才建议外部专家：

| 信号 | 默认分数 | 说明 |
|---|---:|---|
| 未知类别候选 | 3 | 进入外部语义专家候选，不修改标签表 |
| 标签注册冲突 | 3 | 例如已知类别别名或类别边界冲突 |
| 本地 VLM 低置信度 | 2 | 默认阈值 65% |
| Agent 未收敛 | 3 | error、no_progress、max_rounds 等 |
| Agent 轮数过多 | 2 | 默认达到 2 轮 |
| SAM3 候选不稳定 | 3 | 回退、多候选过滤或显式稳定性指标异常 |
| 专项目标接触画面边缘 | 3 | 排除天然贴边的 floor 和 ego |
| 小目标 | 2 | 默认候选框面积不超过画面 1% |
| 类别审查冲突 | 3 | 类别盲审要求人工处理 |
| 人工重点复核帧 | 4 | 用户在设置中显式指定 |

`pallet`、`slope`、`车辆`、`other_robot`、`cargo_floor` 会作为专项上下文记录，但类别本身不会单独触发外部调用，避免所有托盘或斜坡帧都被送往 ChatGPT。

## 新增可配置项

- 综合分数阈值；
- 本地模型低置信度阈值；
- Agent 轮数阈值；
- 画面边缘范围；
- 小目标框面积阈值；
- SAM3 候选过滤数阈值；
- SAM3 掩膜一致度阈值；
- SAM3 面积变化阈值；
- 人工重点复核帧列表。

每次路由回执均包含原因、分数、阈值、局部模型耗时、外部模型耗时占位、是否回退、是否复用 SAM3、缓存占位和候选安全边界。

## 影子审计

对正式工作台当前持久化状态进行了只读审计。当前只有 1 个带完整 Agent 运行记录的候选帧，该帧被建议进入外部专家通道，触发原因是：Agent 未收敛、类别审查冲突、边缘候选、小目标和人工复核队列。

这次 1/1 只证明路由能识别当前困难帧，不能作为未来外部调用比例。需要在下一阶段的 24–40 张困难复核集和普通帧对照上校准阈值。

审计期间：

- 外部 API 调用 0 次；
- 图片上传 0 张；
- test24 使用 0；
- 正式工作台保持 idle；
- 机器候选和人工真值均未修改。

## 验证

- 困难帧路由与审计工具定向测试：7/7 通过；
- 专家配置、路由和服务器集成定向测试：21/21 通过；
- 网页主逻辑测试：95/95 通过；
- 完整 Python 回归：1855 通过、1 跳过、286 个子测试通过。

第一次完整回归在非 UTF-8 PowerShell 环境下出现 18 个失败，失败内容为中文 JSON 按 GBK 读取和残留 Git 配置变量导致的环境错误。按项目既有 `PYTHONUTF8=1` 协议并仅清理当前测试进程中的残留 Git 变量后，完整回归全部通过；没有通过修改业务代码掩盖这些失败。

## 当前限制与下一步

1. 当前路由仍是影子建议，不执行外部调用，因此不存在真实回退和缓存命中数据。
2. SAM3 显式稳定性接口已预留 `mask_iou`、面积变化和实例数变化；旧运行记录没有这些指标时，只能使用回退模式和候选过滤数量作为代理。
3. 下一步应建立 24–40 张开发集复核包，混合困难正例和普通负例，再校准外部调用比例，不能根据当前单帧把 100% 当作目标比例。
4. 只有影子统计证明斜坡召回提升、普通地面误检不增加、车辆/机器人冲突不恶化后，才进入显式外部调用与故障回退测试。

## 部署决定

本轮不部署到正式工作台。代码保留在 `labelagent` 开发分支，待困难集影子校准和独立浏览器验收后再决定是否发布。
