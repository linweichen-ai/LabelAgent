# Round346：多窗口切换数据时主动暂停与明确同步提示

日期：2026-11-20  
状态：已实现、已隔离浏览器验收、已部署正式工作台

## 问题

Round343正式验收期间，另一个窗口切换了服务器当前数据。旧页面虽然已有强绑定保护，不会把旧任务
结果写到新数据，但用户只能从禁用按钮和过程区文字判断原因，容易误以为平台卡住或推理没有响应。

## 改进

工作台现在发现服务器数据文件或相机与当前页面不一致时会：

1. 立即暂停本页推理入口，继续拒绝沿用另一个窗口的任务状态；
2. 按钮直接显示“数据已切换 · 请点右上‘切换数据’同步”；
3. 弹出一次“本页已安全暂停”的提示；
4. 同一切换状态后续轮询不重复弹窗；
5. 数据重新同步后恢复正常状态轮询。

系统没有自动刷新页面，因为自动刷新可能覆盖当前未保存的人工编辑。用户明确点击右上“切换数据”
后再选择当前文件，兼顾安全和可理解性。

## 真实浏览器验收

验收工具强制拒绝正式端口，只允许在本机隔离端口改变活动文件。隔离工作台从
`Capture_20261103/常熟0920_四相机与点云.mcap`切换到另一张示例图后，旧页面在4.297秒内得到：

- 推理按钮禁用；
- 按钮文字正确指向右上“切换数据”；
- 标题说明“已暂停推理且不会沿用其任务状态”；
- 一次性提示可见；
- 人工真值写请求为0；
- 页面脚本错误为0。
