日期：2026-11-20
状态：兼容性根因已修复；4,423 个真实候选全量审计、三组图像抽查、全套回归、生产备份与部署均已完成。现有候选、人工真值、训练集和模型权重未被改写。

## 1. 本轮解决的问题

用户反馈部分栈板轮廓呈现明显的凹凸和密集锯齿。Round 275 虽然读取了全部 573 张对应原图，却得到 `adjusted_count=0`，当时把它解释成候选全部被尺寸门禁主动跳过。

继续检查后确认该解释不完整：Capture 数据的机器候选 ID 是 `sam3-camera_1-99-pallet-4` 一类稳定字符串，而交互编辑使用的通用校验器只接受整数 ID。栈板清理已经生成替换几何，但在最终校验时被拒绝，因此没有进入审计结果。

修复只放宽几何清理内部的验证适配：

1. 整数 ID 继续走原校验；
2. 非空字符串 ID 用临时整数副本验证几何合法性；
3. 输出仍保留原字符串 ID，不改变候选身份；
4. 空字符串、其他类型和非法几何仍被拒绝；
5. 交互编辑的整数 ID 约束本身没有放宽。

## 2. 可复现审查工具

新增 `tools/audit_pallet_contour_complexity.py` 与对应测试，用于：

- 按尺度归一化轮廓点密度寻找最毛糙候选；
- 按全量审计的真实改动比例抽取变化最大的候选；
- 单独抽取 `large` 近景大目标；
- 输出“原图 / 原候选 / 修复后候选”三联图；
- 记录候选 ID、改动像素、改动占比和前后轮廓点数；
- 每次运行都核对输入候选文件未被改变。

- 把机器候选标成人工真值；
- 自动批准候选进入训练；
- 修改历史候选文件；
- 启动 SAM3/VLM 微调或后训练；
