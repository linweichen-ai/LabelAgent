## 4. 结论

本段是当时基于 `adjusted_count=0` 得出的解释，现已由 Round 276 的字符串 ID 兼容性实测取代。573 张原图确实全部读取，但不能据此推断所有候选都被尺寸门禁主动跳过；旧最终校验错误拒绝了字符串 ID 候选的几何替换。
