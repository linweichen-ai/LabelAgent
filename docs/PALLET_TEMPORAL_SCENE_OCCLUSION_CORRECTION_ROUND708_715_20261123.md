## 纠错结论

本轮发现并修复了一个重要定义缺口：Round 698–699 的跨帧点只在“目标聚合点自己之间”判断可见性，没有让中心帧中更近的其他栈板/场景点参与遮挡。因此原先 7/8 的提示机会偏乐观，不能继续作为安全路由依据。

修正后，每组 temporal 点都与完整中心帧 PCD 一起进入可见性计算；中心场景中更近的回波可以抑制被遮挡的历史点。真实结果从 7/8 收紧到 3/8，只保留 `obj12、obj13、obj78`。两次机会报告逐字节一致。

## 为什么必须修

跨帧局部坐标对齐能把其他时间看到的栈板表面映射回中心帧，但“其他时间看见”不等于“中心画面当前可见”。如果目标点在中心帧被更近的栈板挡住，要求 SAM 覆盖它反而会造成粘连。

新定义对每组 `(cell, depth_slack)`：

1. 合并完整中心帧场景 PCD 与 temporal 目标聚合点；
2. 在同一相机、同一网格中做最近深度筛选；
3. 只保留未被中心场景更近回波压住的 temporal 点；
4. 再执行原有双网格、不同像素、至少两个非中心贡献帧、属性和尺度一致性门。
