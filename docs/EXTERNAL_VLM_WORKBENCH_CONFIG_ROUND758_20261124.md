# Round758：外部专家模型工作台配置入口

## 目的

在不改变本地 Qwen8B 默认流程的前提下，为已经实现的外部专家通道提供一个可读、可控、默认关闭的工作台入口。该入口只负责保存非秘密配置和显示就绪状态，不会自动调用外部模型，也不会自动上传工厂图片。

## 本轮改动

- 在“模型设置”中新增“外部专家模型”区域，支持选择 OpenAI 兼容、OpenAI Responses、Claude Messages 和 Gemini 原生接口。
- 可配置模型名、基础地址、超时、困难帧轮数阈值，以及仅记录分流建议的影子模式。
- 工作台只接受“密钥环境变量名”，没有明文专家 API Key 输入框；真实 Key 仍只允许预先写入本机环境变量。
- 状态区区分：全部关闭、仅影子记录、配置不完整、缺少环境变量、配置已就绪但尚未进行连通性测试。
- 补充浅色、深色和窄屏样式；更新前端缓存版本，避免浏览器继续使用旧脚本。

## 安全边界

- 默认 `llm_expert_enabled=false`，不会因打开设置窗口而发送外部请求。
- `/api/model_readiness` 只读取本地配置与环境变量存在性，不探测外部服务。
- 影子模式只记录困难帧分流建议，并明确“不上传图片”。
- 机器结果继续保持 `candidate_only=true`、`human_truth=false`、`approved_for_training=false`。
- 本轮没有 API Key、外部请求、图片上传、训练、推理、正式部署、人工真值或 `test24` 写入。

## 验证结果

- `node --check source/web/app.js`：通过。
- `node --test tests/test_web_polling.js`：95/95 通过。
- `python -m unittest tests.test_expert_review tests.test_expert_vlm_smoke tests.test_agent`：303/303 通过。
- 新增测试确认页面没有专家明文 Key 输入框、配置请求只发送环境变量名，并持续展示影子模式不上传说明。
- 独立只读检查再次运行网页测试为 95/95，通过并确认此前 4 个失败只是缓存版本断言未同步，不是翻帧、区域编辑或类别保存逻辑回归。

## 当前限制与下一步

该入口尚未部署到正式 `D:\Apps\LabelAgent`，也没有证明任何外部模型的连通性或分割效果。下一步由用户选定首个供应商并在本机安全设置环境变量后，只用程序生成的合成图片进行一次受控连通性测试；通过后再制定固定困难样本的影子 A/B，真实工厂图片外发仍需单独明确授权。
