# Round 576：密集托盘候选像素结构与助理视觉复核

日期：2026-11-22

> 历史基线说明：本报告冻结的是修复前结果。后续 Round 577–584 已修复跨实例像素转移并做保守去碎屑，最新结论见 `PALLET_SOURCE_OWNED_DEPTH_SPLIT_ROUND577_584_20261122.md`；本文件保留用于前后对照。

## 结论

对 Round 572 的 9 个密集托盘候选进行了逐实例放大复核：7 个有二维掩码，2 个此前已被安全门抑制。结果不是“7 个都可以训练”，而是：

| 复核结论 | 数量 | 后续 |
| --- | ---: | --- |
| 助理视觉初步通过候选 | 3 | 优先人工确认，仍非真值 |
| 仅剩可见细条、证据不足 | 3 | 补时序证据或人工描边 |
| 明显碎片化，拒绝当前掩码 | 1 | 重新分割或人工重画 |
| 保持系统抑制 | 2 | 不生成二维候选 |

因此本轮把原来的“7 个待复核掩码”进一步收窄为 3 个优先确认候选；其余 6 个均不能直接进入训练回流。

## 自动像素结构检查

新增只读工具：

`tools/audit_pallet_candidate_pixels.py`

它会逐项验证 bundle、图像清单、拆分报告和掩码 SHA-256，并计算：

- 连通域数量与最大连通域占比；
- 小碎片比例；
- 孔洞数量与孔洞面积比例；
- 包围框填充率；
- 网格周长 / 面积比例；
- 凸包填充率；
- 3D 投影覆盖率和原始掩码保留率。

同时生成原图放大、叠加轮廓和二值掩码三联图。全过程不修改候选、人工真值、训练集或正式工作台。
