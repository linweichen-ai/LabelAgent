# 密集栈板跨帧局部坐标提示机会（Round 696–699）

日期：2026-11-23

## 结论

同帧换相机没有形成提示机会后，本轮改为利用同一栈板在前后 11 个标注帧中的独占 LiDAR 点。第五批 8 个困难实例中，7 个通过了跨帧提示机会门，1 个因新增点只来自 1 个非中心帧而保持 `insufficient`。

这是“值得继续调用 SAM 的几何提示机会”，不是已经恢复的分割，不是像素真值，也不是训练许可。两次加固复跑结果逐字节一致，图像读取、SAM、GPU、人工真值、训练集、正式工作台和 OSS 写入均为 0。

## 方法

对每个目标栈板、每个时间帧：

1. 用人工 3D 框和 `class_membership` 只保留该目标的独占点，所有落入多个框的歧义点排除；
2. 把点从该帧 3D 框转换到逐轴归一化的局部坐标：`u=((p_f-c_f)@R_f)/s_f`；
3. 再映射到中心帧框：`p_center=(u*s_center)@R_center.T+c_center`；
4. 在中心全局坐标中按固定 0.02 m 体素去重，体素代表点取样本均值；
5. 在中心主相机上用 `(4 px, 0.10 m)` 与 `(8 px, 0.15 m)` 两组可见性参数复核；
6. 只有两组参数都至少保留 3 个不同体素和 3 个不同像素、两组共享至少 3 个相同体素，并且至少 3 个中心帧没有的新体素来自至少 2 个非中心帧，才记为机会；
7. 目标属性和 3D 框尺度必须在 11 帧中保持一致。

每个编号目录的 11 个 PCD 各读取一次，多目标共享内存缓存；两个编号目录合计读取 22 次。实际绑定 47 个输入文件，标签和 PCD 在解析前后校验，结束前再全量回读。工具源码 SHA-256 也写入报告。
