## 1. 为什么继续做这一轮

Round 267 已对 CVAT Task3 全量候选做几何回归，也依据 Capture_20261103 候选尺寸判断新边缘规则不会触发。但原有跨数据工具没有把新数据原图真正传入 v5，只能证明“尺寸门禁不满足”，不能证明完整的图像引导调用链工作正常。

本轮把原图读取、话题到相机目录映射、帧号到 PNG 对齐和尺寸核验纳入正式审计工具，然后对完全相同的四路相机分层样本重新执行。

该结果证明的是这 160 个确定性分层候选不会被 v5 误修；不等同于全部 4,423 个候选或未来所有新数据均已人工确认。

## 4. 可复现工具变化

`tools/audit_pallet_geometry.py` 新增：

- `--image-root` 参数；
- `/capture/camera_N/image` 到 `camera_N/` 的严格映射；
- 帧号越界、图片缺失和分辨率不一致时明确失败；
- 审计记录原图路径、是否实际使用图像、候选面积比例和动态变化预算；
- 审计只读，测试验证输入候选 JSON 前后字节不变。

新增两项测试覆盖正确图像对齐和非法话题拒绝。正式 `tests/` 测试集为 1,040 项通过，另有 186 个子测试通过。直接从仓库根运行无范围限制的 pytest 会把 SAM3 自带演示脚本误收集为测试，并因可选 matplotlib 缺失而停止；正式验收命令明确使用 `pytest tests`，没有为演示脚本额外污染项目环境。
