# Round768：正式工作台最小覆盖候选包

## 为什么没有直接复制最新版

正式目录包含 76 条现场改动，且 `index.html` 中保留了与当前开发分支不同的脚本版本。直接复制最新整文件会顺带部署外部专家设置等其他尚未正式验收的功能，或者覆盖现场已有集成。因此本轮从正式目录的实际文件出发，只在隔离副本上加入 Round764–766 必需的变化。

## 候选包内容

候选包包含 6 个精确文件：正式 `server.py` 的最小局部补丁、正式 `index.html` 的专项复核缓存版本与一个筛选按钮、三个专项复核网页文件，以及绑定 Round160/763 的优先侧车。每个文件同时记录正式旧哈希和候选新哈希；正式文件在部署前只要有任何变化，部署必须停止。

候选文件位于 `artifacts/round768-formal-minimal-overlay-candidate/files/`，结构化清单为同目录 `manifest.json`。它固定声明 `deployment_performed=false`、`formal_files_written=0`、`automatic_deployment_allowed=false`。
