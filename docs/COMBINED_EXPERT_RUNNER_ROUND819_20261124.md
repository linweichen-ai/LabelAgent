# Round819：51次外部专家调用严格计账运行器

## 背景

Round814授权模板限定最多51次调用，但旧单任务命令允许每帧自动重试1次，且重新运行会再次尝试失败帧。极端情况下，实际HTTP请求可能超过用户授权上限。本轮在真实图片外发前修复该问题。

## 新运行规则

新增 `tools/run_combined_expert_shadow.py`，统一执行：

1. 34张原始640×512任务；
2. 混合路由选中的17张512×410任务。

在第一个网络请求前，运行器会同时验证两份队列、51张授权上传、34张唯一源图、图片哈希、清单、回执和同一授权文件。任一项不一致时零网络退出。

每个授权上传最多进行一次API尝试：

- 自动重试固定关闭；
- 成功和失败均记录 `external_attempts=1`；
- 再次运行会复用成功或失败的终态，不会重复付费；
- 如果34张原始任务没有全部完成，17张缩放任务不会启动；
- 需要重试失败图片时必须取得新授权。

统一回执记录累计尝试数、本次新增尝试数、两阶段状态、两个结果文件哈希以及安全边界。总尝试数超过51时失败关闭。

## 当前实测

使用尚未授权的Round814模板执行真实命令预演：

- 退出码：1；
- 错误：需要匹配的明确外部上传授权；
- 输出目录：未创建；
- API调用：0；
- 真实图片上传：0。

第一次CLI预演暴露项目根目录未加入模块搜索路径，已修复并增加直接脚本入口测试；修复后的未授权失败发生在任何输出和网络动作之前。

## 边界

本轮不修改授权模板，不代替用户授权，不使用test24，不写人工真值，不批准训练，不部署正式工作台。

完整项目回归为1975项通过、1项跳过、294项子测试通过。
