# Round773：外部视觉专家本机配置与合成图连通测试

## 本机配置入口

新增一次性本机配置页 `tools/local_api_key_setup.py`。页面仅绑定 `127.0.0.1`，使用随机路径令牌、禁止缓存、禁止外部资源和跨站表单，并且不记录HTTP请求。Key只写入当前Windows用户环境变量，不进入命令参数、项目文件、日志、GitHub、CNB或对话。

本轮用户选择OpenAI兼容接口，模型为`openai/gpt-6-astra`。证据仅记录Key存在，不包含Key内容。原生PowerShell窗口方案因桌面可见性和编码兼容失败，已删除，避免保留两个配置入口。

## 合成图测试

先完成零网络dry-run，确认配置、Key环境变量名和上传边界。随后只发送程序生成的640×512几何测试图：10,335字节，SHA-256为`0a309a25...6dd0`。权威可审计请求成功返回严格JSON，耗时35,608.801毫秒，响应SHA-256为`31344e20...390d`。

第一次真实请求完成后因调用方没有保留最终标准输出，不能作为验收证据；确认进程结束后才执行第二次可审计请求。因此本轮可能产生两次合成测试调用，但没有并发请求。只有第二次回执用于结论。

## 当前结论

外部专家API已经具备真实结构化视觉调用能力，但35.61秒不适合作为普通帧默认路径。它应只用于低置信度、类别冲突、多轮不收敛或复杂遮挡帧。下一步需要用户明确授权选定的工厂困难开发图外发，才能开展本地Qwen8B与外部专家的影子A/B；未经授权不发送真实图片。
