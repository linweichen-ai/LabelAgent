# Round776：混合困难帧34张人工复核包

## 结论

本轮在不读取或使用 test24 图像内容进行调参的前提下，建立了一份34张的候选复核包，作为困难帧路由校准的人工确认入口。它不是人工真值，不授权训练，也没有部署到正式工作台。

复核包包含：

- 4张斜坡正候选：包含画面边缘局部坡、遮挡坡和完整坡；
- 4张斜坡负候选；
- 24张连续困难负候选：用于观察普通地面、人员、托盘和机器人结构是否诱发斜坡误检；
- 2张密集托盘候选：覆盖远处小实例、重叠、粘连与实例归属困难。

实际清单为34行、34个唯一源图哈希，冻结 test24 哈希交集为0。输出包含34张原图副本、34张带安全提示的复核图、总览图、离线浏览页、清单与哈希回执，总计约21.5 MiB。71项回执逐项读回，缺失和哈希失败均为0。

## 安全边界

清单统一保持：

- `candidate_only=true`；
- `human_truth=false`；
- `approved_for_training=false`；
- `training_authorized=false`；
- `test24_used=false`；
- `production_deployed=false`；
- `human_truth_writes=0`；
- `workbench_writes=0`。

工具在构建时读取冻结 test24 的图片 SHA-256 清单并做交集检查；发现任意交集、源图重复、来源边界缺失或帧数不在24至40之间时失败关闭。复核包不保存人工决定，人工裁决仍必须经过现有工作台人工门禁。

## 本轮验证

- 新工具及路由相关定向测试：9/9通过；
- Python 正式测试协议：1857项通过、1项跳过、286个子测试通过，耗时60.07秒；
- 总览图已目视读回，可见分组颜色、样本编号和候选边界声明；
- 回执文件71项全部存在且 SHA-256 一致；
- 本轮外部 API 调用0次，外部调用成本0；
- 没有训练、推理部署或 GPU 长时任务。

一次无筛选的全仓库 `pytest` 在收集 SAM3 自带定性演示脚本时，因为项目虚拟环境没有可选 `matplotlib` 而中止。该入口不属于现有正式测试协议；随后按既有 `tests/` 协议重跑并全部通过。本轮没有为此污染项目环境或安装额外包。

## 当前工作台状态

只读检查显示：SAM3在线，备用快速 VLM 在线，但主 VLM 连接被拒绝，因此总体模型就绪状态为 false。正式工作台没有加载本轮开发代码，当前人工真值帧和已验证真值帧均为空。本轮没有为生成复核包而启动正式推理，也没有改动生产权重和服务。

## 当前限制

这份包是第一版结构化入口，不等于完整困难集：

1. 24张困难负候选来自同一连续场景，时间变化充分但场景多样性不足；
2. 斜坡正候选仍主要是同一序列的黄色坡板，不足以证明不同颜色、材质和光照泛化；
3. 车辆、`other_robot`、`ego`、`cargo_floor` 与未知类别的冲突在 dev8 外部专家记录中存在，但尚未形成独立人工裁决；
4. 密集托盘只有2个源帧，能够承载多个实例复核，却不能代表跨数据集泛化；
5. 34张均未由人工确认，因此现在不能计算真实 Precision、Recall、F1 或启动新一轮后训练。

## 下一步

1. 在离线复核页对34张逐项完成人工存在性和关键轮廓确认，签字与训练授权继续分离；
2. 另补少量不同材质/光照斜坡、车辆/机器人冲突和新类别候选，替换部分同场景连续负例，仍保持总量24至40张；
3. 人工裁决完成后，冻结清单和哈希，再比较仅本地、全外部、混合路由三种方案；
4. 依据真实误检、漏检、延迟和调用比例校准路由阈值；
5. 只有门禁通过后，才准备小规模 LoRA 后训练，SAM3 像素微调继续等待足量人工像素真值。
