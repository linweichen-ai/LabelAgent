# Round379：单/双候选类别复核快速通道

日期：2026-11-21

## 问题

Round376 已把“主 VLM 三候选批审 + 1～2 个尾项”并行化，但一帧总共只有 1～2 个高风险候选时，
旧流程仍全部占用主 VLM 串行复核。Round377 新增的小型低置信栈板门禁会更频繁地产生这种短尾，
因此存在一个不改变模型质量即可缩短等待的明确空档。

## 改进

当候选总数只有 1～2 个、5090 快速 VLM 可用时，直接逐项使用原有 `chat_fast_only` 严格结构化
复核；若快速通道忙、离线、超时或协议失败，立即回退原主 VLM。三候选以上的既有批处理和并行
尾项路径保持不变。

该变化只改变计算路由：候选多边形、类别、人工真值、训练批准、最低 0.90 置信门槛和失败关闭
策略均未改变。快速通道自身绝不自动回退主路，回退只由调用方显式执行，避免同时向主 VLM 提交
重复请求。
