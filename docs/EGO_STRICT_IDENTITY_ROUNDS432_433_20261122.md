# Round432–433：严格身份绑定与单次字节校验

日期：2026-11-22

## 审阅发现与修正

Round428–431 的来源根和面积门禁有效，但只读审阅又发现三个正式接入前风险：命令行可以
漏传门禁、同一根目录内仍可能替换成另一帧、哈希和解码分两次读取存在竞态窗口。本轮逐项
关闭：

1. 命令行默认严格模式，必须同时给出允许根、面积规则和身份清单；只有显式
   `--allow-unguarded` 才能做隔离研究；
2. 新增冻结身份清单，绑定 `sample_id ↔ 包号 ↔ 相机 ↔ 帧号 ↔ 图像 SHA-256`；
3. 图像和掩膜均只读取一次，同一份内存字节同时用于 SHA-256、解码和叠图。

身份清单包含 1104 包 000/001/002 的 18 张已校验图：
`docs/evidence/workbench-stability-20261117/ego-1104-sample-identity-manifest-v1.json`，
SHA-256 为 `75095dc9bf858702fab49c40d6ba237ecd10ad9249d2e3702f57b859c53bced9`。
