# 保留已发现实例的全局候选分配

上一方案通过原3px联合要求，但在新增的逐层批准参考中漏掉一层托盘；0px与6px还有点计数退步。因此本轮将旧四分块的全部轮廓作为不可删除的前缀，包括没有点云支持的轮廓，再增加候选。此规则统一作用于全部图像，不读取批准对象ID、边界或三维参考。

新增候选必须在0、3、6px三个椭圆容差下都不增加旧四分块已覆盖的原始可见点集。这样保留旧实例，并使任意类别的点覆盖与交叉覆盖保持。新增候选仍采用原空间簇排序、0.5置信度和0.8 NMS；未用完的名额在整个离线批次分配。原有全局数量1.5倍、并集面积1.25倍限制保持，改变的是分配算法，不是评估门槛。批次组成会影响分配结果，不能将独立分批选择的输出拼成同一全局实验。
