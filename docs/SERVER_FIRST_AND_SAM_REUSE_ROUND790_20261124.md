# Round790：服务器优先架构与 SAM3 多提示复用实测

## 结论

当前推荐架构已经是“Linux 服务器统一运行，本机只访问网页”：网页后端、SAM3 和 Qwen8B 均运行在 `factory-5090`，Windows 通过 SSH 回环通道访问，不在本机加载模型。

本轮只做服务状态和一张公开测试图的短时性能验证，没有调用外部专家模型，没有运行正式自动标注，没有写候选、人工真值或训练批准，也没有使用 test24。

## 实时服务核对

核对时服务器端口为：

| 服务 | 服务器回环地址 | 状态 |
|---|---|---|
| 网页后端 | `127.0.0.1:18765` | ready / idle |
| SAM3 | `127.0.0.1:18766` | model loaded |
| Qwen8B | `127.0.0.1:18878/v1` | ready |

本机访问地址为 `http://127.0.0.1:18765/`。这个端口由 SSH 安全通道转发到服务器，不代表后端运行在 Windows。

## SAM3 多提示性能实测

使用仓库公开测试图，分别执行 `warehouse floor` 和 `traversable ramp surface` 两条文本提示。为避免把缓存误当作模型加速，本轮使用当前正式 SAM 服务的真实前向，并核对服务返回的特征复用字段。

| 方案 | 总耗时 | 图像特征提取次数 | 相对结果 |
|---|---:|---:|---:|
| 两条提示分别调用 | 0.1806 s | 2 次 | 基线 |
| 两条提示一次调用 | 0.1125 s | 1 次 | 约 1.61 倍加速 |

服务回执包含 `feature_reuse=true`、`image_feature_passes=1` 和 `prompt_count=2`。测试图在这两条提示下均未返回 mask，因此本轮只能证明图像特征复用和延迟改善，不能据此声称分割质量提高。

## 手动标注现状

当前服务器版本已经提供：

- 多边形；
- 矩形框；
- 椭圆框；
- 自由线 / 套索，并提供精细、平衡、快速三档；
- SAM 正点与负点；
- 已有轮廓的局部补标和擦除；
- 撤销、取消、快捷键、连续采样与高频绘制合并。

自由线使用 Pointer Events、指针捕获和合并采样，减少拖动断线和高频重绘。SAM 运行时允许继续增加提示点；旧点集的结果会被丢弃，最终只对最新点集补算一次。
