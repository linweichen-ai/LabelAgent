# 单张图增加6个人员误覆盖点：诊断与无额外边距保护实验

本轮针对旧15厘米方案剩余的人员退步开展隔离实验。完整588图正在按冻结规则重跑；结果未出前，当前联合通过的离线方案仍为2298对象 / 139492托盘覆盖点 / 2184人员误覆盖点，不改变工作台默认策略。

## 原因与改进

旧方案的6点增加集中在同一相机图像、同一个新增托盘候选。六点均不在原模型人员种子的15厘米邻域内：距最近跨视角人员种子约20.4–28.5厘米，距原人员二维轮廓约15.1–25.0像素。模型人员轮廓在手臂/持物附近存在遗漏。这里的“人员点”来自三维参考框投影，不能直接当作独立标注的六个人体像素。

另做16次原生SAM3局部人员推理，补充的种子仍未保护到六点；这些调用只用于诊断，不进入本轮候选选择。未按六个错误点坐标设定过滤规则、修改标签或调整相机参数。

新主方案使用原模型每个人员实例**既有、未加边距的外接框**作为保守保护种子，通过四视角原始点身份合并，再按原15厘米做一次邻域扩展。原6像素膨胀、15厘米半径、不递归、候选分数、排序、数量及面积约束保持。保留旧四分块轮廓的原样前缀；新候选在0/3/6像素任一档新增保护点覆盖时即被拒绝。外接框只作离线保护证据，不写入人员标注。
