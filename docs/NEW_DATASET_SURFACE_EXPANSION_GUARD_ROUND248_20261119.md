# LabelAgent 新数据地面误扩张保护（Round 248）

时间：2026-11-19 14:40（Asia/Shanghai）

## 1. 为什么要修

在 `Capture_20261103` 新数据集的一张 1920×1536 厂内图像上，SAM 已经给出了带物体空洞的地面候选，但无参考帧的 Agent 又提出一个覆盖画面下半部的大矩形 `add_region`。旧逻辑直接执行，导致地面遮罩吞掉人员、设备、栈板与自车区域。该问题不是 SAM 没找到地面，而是后续自动修改范围过大。

本轮只限制“没有参考帧时，对 floor/slope 做大范围新增”的自动操作；局部补洞仍允许，存在参考帧时仍可按原流程扩展。所有结果继续作为机器候选，未修改人工真值，也未批准进入训练集。

## 2. 新保护规则

对无参考帧的 `floor` / `slope` `add_region`，同时计算：

- 新增像素占整图比例；
- 新增像素占原候选比例；
- 操作多边形覆盖整图比例。

满足任一高风险条件时不自动应用，并进入人工复核：

- 多边形区域超过整图 25%；
- 实际新增像素超过整图 5%；
- 实际新增像素超过整图 1%，且超过原候选面积的 50%。

保留的能力：小范围地面修补仍可自动执行；带参考帧的大范围扩展仍按原策略处理。这样避免为了挡住误扩张而把正常局部修补一并禁用。

## 6. 当前结论与下一步

本轮已经把“新数据无参考帧时，Agent 用一个大矩形把非地面目标全部吞掉”的风险从自动执行改成保留原候选并转人工复核。它是明确的安全性和视觉质量改善，但只在一张真实新数据图上做了同图复跑，不代表跨数据集精度已经完成验证。

下一步优先处理两项：一是 `ego` 可见但没有候选的召回链路；二是冷路径中 5 次逐个盲审造成的首次运行时延。任何提速都继续保持候选/人工真值/训练批准隔离。
