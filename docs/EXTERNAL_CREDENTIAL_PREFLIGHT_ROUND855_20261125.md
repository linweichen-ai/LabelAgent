# Round 855：外部专家凭据本地预检

## 问题

持久化授权账本会在请求前占位。如果 API Key 缺失或格式错误，而执行器在占位后才发现，虽然不会重复付费，但会无意义地消耗一次授权额度。

## 修复

组合外部专家执行器新增本地凭据预检，严格顺序变为：

`数据与授权绑定核验 → 目标模型核验 → 凭据本地预检 → 授权账本占位 → 模型/API 请求`

预检只确认：

- 外部专家功能已显式启用；
- provider、HTTPS 地址和模型与授权一致；
- 指定的环境变量存在；
- API Key 不含首尾空白或控制字符。

预检结果只返回 `credential_available=true` 和无凭据的目标信息，不返回、记录或打印 API Key。凭据缺失时，账本目录和网络调用均不会产生。
