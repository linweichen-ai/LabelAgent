# Round405：正负提示组正式接入与严格回退

## 本轮目标

Round404 已证明同一图像的三组正负点可以共享一次 SAM 编码，并在隔离 4090 上获得约 3.02 倍加速。本轮不再调同批参数，而是把兼容接口安全接入正式服务，并确保旧服务、服务繁忙和畸形响应不会被错误的“自动回退”掩盖。

## 接入方式

- 正式 4090 点提示服务升级为 `labelagent.remote-sam3.v3-point-groups`，旧 `/segment_points` 与 `/segment_points_batch` 保持不变，新增长度受限的 `/segment_point_groups_batch`。
- 客户端新增带 HTTP 状态的 `SamHttpError`。只有明确的 HTTP 404 才说明旧服务没有新接口，此时缓存协议能力并退回逐组 `/segment_points`。
- HTTP 503、超时、响应缺组、顺序错误、点组不一致等情况全部原样失败，不允许借回退变成“成功”。
- 旧服务逐组返回的合法 400 几何失败只落到对应 item；其它组仍可保留，与新批接口的 item 级失败契约一致。
- Round402 评测器改为一次提交全部三组提示，仍复用原有逐组质量门禁和遮挡失败规则。
