# 更细分块的固定调参对照

在四分块历史真实结果上比较显式九分块（3×3、宽高占比 45%），目标是检查较小托盘是否获得更多可用候选。固定原调参 5 帧、四相机共 20 张图，计划 180 次新 SAM3 请求；四分块历史为 80 次。置信度 0.5、追加预算 0.5、NMS 0.8 不变，保留全部原候选。预测只使用原图与原候选，不读取三维参考；先冻结预测及绑定源图摘要，再由原 V2 指标计分。

上一轮最好四分块在这 20 张图为托盘 75/118、5179/6291 个参考点，人员交叉覆盖 55。新配方必须严格增加参考实例匹配、点覆盖不降、人员交叉覆盖不超过 55，并继续满足相对原始基线的 +2 个百分点、候选数 ≤1.5 倍、并集面积 ≤1.25 倍、人员交叉覆盖增幅 ≤0.5 个百分点。不能只胜过更弱原基线就取代四分块。

新选项默认关闭，原四分块输出和默认工作台流程保持。冻结验证同时绑定分块数量与占比，拒绝用另一种裁图几何验证所选方法。219 项完整回归通过，覆盖密集网格全像素覆盖、边界、间隙、重复格及几何漂移拒绝。

本次先为另一项正在使用同一显卡的工作保留资源，按准确进程身份等待其结束，再通过现有管理器运行 SAM3；排队时不计为实际推理结果。计划及状态见 [脱敏记录](dense_grid_progress.json)。不会自动扩大到其余图。

20 张图属于多轮复用调参；其余图也已在历史配方中计分。后续同采集复验不能称为独立外部验收，更不能将稀疏参考支持解释为二维像素准确率。
