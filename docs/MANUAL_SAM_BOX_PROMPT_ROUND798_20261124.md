# Round 798：手工工作台新增 SAM 框选提示

## 目的

原工作台已有手工矩形和 SAM 正负点，但手工矩形只生成矩形标注，不能让 SAM 根据目标边界生成掩膜。现在新增独立的 **SAM 框选（X）**：用户拖框锁定单个目标，松手后立即运行 SAM；生成后仍可追加正点补漏、负点排除粘连区域。

## 交互流程

1. 在人工标注模式选择类别；
2. 点击 `SAM 框选（X）`，或按快捷键 `X`；
3. 按住鼠标框住一个目标，松手即提交；
4. 蓝色虚线框持续显示，SAM 返回黄色候选轮廓；
5. 漏分时切换 `SAM 正点（P）`，粘连时切换 `SAM 负点（N）`；
6. 点击重新生成，框和正负点会一起送入 SAM。

## 安全与一致性

- 框采用原图坐标 `XYXY`，必须为 4 个有限数字、方向正确、完全位于图像内且宽高至少 2 像素；非法框在模型运行前拒绝。
- 框被纳入点提示请求哈希；不同框不会错误合并，相同文件、相机、帧、框和点才可共享在途请求。
- 文件、相机、帧或文件载入代次在推理期间变化时，旧结果继续安全丢弃。
- 推理期间更新提示仍只排队一次最新重算，不重复占用 SAM。
- 该功能只生成页面候选草稿，不自动写人工真值，不改变 `candidate_only=true`、`human_truth=false`、`approved_for_training=false` 的项目边界。
- 未使用 `test24`，未调用外部专家 API，未上传工厂数据。
