# 栈板重叠链联合恢复（Round 627–634）

## 结论

单个目标逐一恢复会被同一重叠链中的其他失败目标拖住。本轮增加了只读联合审计：
先保留每个目标通过本地 LiDAR 点证据的候选，再对完整传递冲突组统一做深度拆分和实例分离。

在独立序列 `005` 的 9 实例重叠组中：

- 联合组从基线“3 个未处理目标”变为 **9/9 全部通过候选门槛**；
- 12 条实际重叠边全部实现 0 像素交叠；
- obj109（61 px）和 obj110（52 px）是单连通、无孔洞、无结构告警的新复核候选；
- obj107（54 px）虽然通过几何门槛，但存在 2 个碎片且边界复杂，继续抑制；
- obj102（44 px）仍保留之前的高边界复杂度告警；
- 独立重复的组合选择、拆分指标、12 条边、9 个掩膜哈希和结构指标完全一致。

该结果是离线候选改进，不是人工真值、训练批准或正式工作台部署。

## 为什么需要联合恢复

原流程每次只替换一个失败目标，其余目标继续使用旧掩膜。例如：

- obj110 自身的 LiDAR 提案已经通过，但邻接 obj109 仍失败，因此整组被拒绝；
- obj109 的 6 负点方案通过点证据，但 obj110 的旧掩膜为 0；
- obj107 的单独提案面积不足，和旧掩膜的证据并集才能达到最低几何支持。

联合流程没有降低任何门槛，而是让同一组内彼此依赖的候选同时参加最终裁决。

## 证据链修复

旧恢复报告只保存“单目标深度拆分后”的掩膜，无法完整复核原始 SAM 定位证据。
Round 627 开始同时保存：

- 原始 SAM 提案及 SHA-256；
- 单目标拆分掩膜及 SHA-256；
- 原始定位指标、正点覆盖率和负点清除率。

联合工具使用原始提案做局部证据复核，再使用完整传递冲突组做全局拆分。

## 联合门槛

候选进入组合前必须满足：

1. 原始定位门槛通过；
2. 正点覆盖率至少 0.8；
3. 负点清除率至少 0.8；
4. 输入、标签、标定和旧掩膜均来自冻结报告。

组合验收必须满足：

1. 完整传递冲突组每个实例为 `candidate_pass` 或明确不可观测；
2. 每条真实重叠边的交叠比例不超过 15%；
3. 在所有通过组合中，先选择结构告警最少者，再选择总像素更保守者；
4. 结构告警目标只进入人工复核或继续抑制，不自动变成人工真值。
