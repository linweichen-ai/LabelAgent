# LabelAgent 个人主页视觉主题（Round336）

日期：2026-11-20  
范围：只调整工作台外观，不改变推理、标注、复核、保存和训练边界。

## 目标

用户希望自动标注页面参考其个人主页的视觉风格，同时保留原有操作台、四步流程和控件位置。
本轮取用个人主页的视觉语言，而不是照搬主页布局：白色纸面、深蓝标题与链接、低饱和灰色
正文、细分隔线、克制阴影和较小圆角。

参考页面：`https://linweichen-ai.github.io/`  
参考源码：`https://github.com/linweichen-ai/linweichen-ai.github.io`

## 实现

- 新增独立视觉层 `source/web/homepage-theme.css`，放在全部既有组件样式之后加载。
- 页面版本由154提升到155，新增主题缓存版本 `homepage-theme.css?v=1`。
- 主色从大面积绿色品牌色调整为个人主页的深蓝 `#224b8d`；绿色、黄色和红色仍只承担
  候选通过、风险和失败等语义，不混淆状态含义。
- 顶部工具栏改为白底细线导航语言，统一品牌标记、模式切换和快捷操作层级。
- 数据集身份条由渐变横幅改为克制的信息条；名称、相机、帧数和切换入口均保持原位。
- 四步向导、播放条、复核工作台、候选卡片、对比浮层和运行前弹窗统一字体、边框、圆角、
  阴影和聚焦态。
- 图像画布继续使用深色背景，保证掩码和边界可读性，不因页面美化降低标注辨识度。
- 夜间主题同步适配，仍保留减少动画和键盘聚焦样式。
- 浏览器标签页LA图标同步为深蓝色。

## 功能边界

本轮没有修改任何元素ID、按钮顺序、事件处理、API、推理配置、候选内容、人工真值或训练
批准状态。新主题是最后加载的覆盖层，移除单个CSS引用即可回退视觉效果。
