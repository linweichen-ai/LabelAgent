# Round401：固定 ego 提示族的 CVAT 像素真值诊断（2026-11-22）

## 为什么做

Round400 只说明固定三组提示在同一条camera1序列的部分时间段能满足提示点和原候选保留门禁，仍没有像素真值。本轮改用另一份本地数据身份`CVAT Task3`，在模型输出完成后与其150帧既有CVAT多边形标注比较。

提示族、负点和90%非退化门槛均冻结自Round398；CVAT标注没有参与选点、调参或挑帧。24帧按全序列均匀抽取。

## 数据边界

- CVAT Task 430、Job 423，150帧，640×480；
- 本地清单确认原图哈希、1550个标注和掩膜往返一致，并与已复核快照内容匹配；
- 标注来源字段为`auto=1469`、`manual=81`，远端CVAT当前状态未重新检查；
- 这些多边形已经作为工作台真值导入，但没有Round389规定的逐样本人工v3哈希签收；
- 因此本轮是独立数据身份的像素诊断，不是正式人工验收，不批准训练或生产。

## 冻结样本

抽取帧：0、6、13、19、26、32、39、45、52、58、65、71、78、84、91、97、104、110、117、123、130、136、143、149。

每帧先调用原camera1基线七点提示，再调用固定三组提示`[3]`、`[0,2]`、`[1,3]`。第117、123、143帧因固定负点无法被SAM排除而返回HTTP 400，评测器按候选缺失失败关闭，没有移动负点或跳过样本。

补充结果：

- 固定族有14/24帧通过自身“正点覆盖、负点不侵入、原候选保留”门禁；
- 但固定几何只在3/24帧的IoU高于基线；
- 3帧出现明确负点冲突请求失败；
- 本抽样最大人物重叠为0，只能说明抽中的候选没有覆盖人物标注，不能外推人物安全性；
- 热态追加三请求中位0.899秒，不代表冷启动或端到端生产耗时。

## 图像复核

本地总览以绿色显示CVAT ego真值、橙色显示固定族候选。多数有效帧中，绿色真值是两条自车货叉，橙色候选却沿右侧货叉外缘扩到大块地面；帧19、26、32、52、71、97等地面误纳为约59%至77%。这与precision下降和floor overlap升高一致。

总览位于`artifacts/round401-cvat-task3-ego-truth24-v3-20261122/contact_sheet.jpg`，包含厂内图像，只保留本地，不上传GitHub/CNB。

## 决策

固定提示族在独立数据身份上明确失败：提示点约束通过不能替代像素真值。Round398方案继续拒绝部署，也不能进入训练数据。

下一步采用“参考帧人工ego真值 → 从掩膜内部自动生成正点、从安全外环生成负点 → 完全冻结到其余帧”的几何锚点方案。该方案不依赖颜色；参考帧与评测帧必须分离，且仍按本轮像素指标评估。若不能明显超过当前基线并满足固定IoU/误纳门禁，则停止规则提示优化，转向有人工签收数据的mask decoder轻量微调。
