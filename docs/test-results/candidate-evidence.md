# 原 VLM 直接工具决策的候选证据图对照

使用同一 2B NF4、256 图像 token、参考、规范、缓存真实 SAM3 候选及原操作 schema，比较原四图输入与新增三张候选局部图的七图输入。新增图依次为最大掩膜的灰背景选中像素、原始裁图、无类别文字的轮廓，附 48px 候选 ID。追加文字说明图与 ID 对应、坐标仍属于原图；这是图像和说明文字组成的整体干预，不声称仅改变图片。

两帧原候选、两个人为类别翻转、两策略共八项，每项最多三轮，策略顺序交错。模型不知道对照身份。所有操作都来自新 VLM 请求，程序不复用类别判断、不构造 reclassify 操作、不强制 done。生产工作流及 schema 文件不变。

调用前固定要求：八项有真实响应；四对原提示/图片前缀与操作 schema 相同；新增图真实进入增强请求；无同类空操作；两错类经实际修改和后续复查恢复；两原候选保持并结束；原始输入与工作台不变。

## 结果

207 项完整回归通过。八次真实 VLM 请求均完成，新图输入为 7 张，原输入为 4 张，四对前缀及 schema 校验一致。两策略均原候选保留 2/2、错类恢复 0/2、实际编辑 0、直接 done 4/4。新增图没有让模型发现本组错类，要求未通过，不启用。

此结果不能否定上一轮缓存局部分类适配器的受控恢复 2/2；两者决策机制不同。本轮验证的是原模型直接输出工具操作，不能把模型返回结束当作类别正确。局部 ID 可读性曾是工作假设，本结果不支持仅靠这组三图和提示即可修复问题。

原始图片、候选轮廓、逐请求内容及预览保留在私有实验目录，只同步代码及脱敏汇总。后续将独立测试“实时局部类别观察 → 原模型工具决策”，不得复用分类缓存或由程序映射成目标操作。
