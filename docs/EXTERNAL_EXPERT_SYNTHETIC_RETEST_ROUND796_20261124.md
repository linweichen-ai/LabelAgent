# Round 796：外部专家 API 合成图复测

## 结论

用户环境中保存的外部专家配置仍然有效。使用既有环境变量中的真实端点和模型配置，对一张程序生成的 640×512 几何测试图执行连通复测，`openai/gpt-6-astra` 成功返回严格结构化结果，耗时 12.823 秒。

本轮没有上传工厂图片、MCAP、标签、答案或本地路径，没有使用 `test24`，也没有把外部结果写入人工真值或训练集。

## 过程与失败记录

第一次复测错误地将网关当作标准 OpenAI `/v1/chat/completions` 路径，服务返回 HTTP 405。该失败说明网关使用项目保存的专用基础路径，不能从域名自行拼接标准接口。随后只读取既有用户级环境变量中的端点、模型名和密钥存在状态，不打印密钥或完整配置，使用成功过的专用端点复测通过。

失败请求与成功请求均只涉及程序生成的合成图；没有真实数据外发。

## 部署边界与下一步

正式服务器工作台当前仍保持外部专家 `disabled`，不会自动上传图片。下一步只把外部专家接成默认关闭的服务器影子路由：普通帧继续走本地 Qwen8B，低置信度、类别冲突、SAM 不稳定、边缘局部坡道、遮挡和多轮不收敛帧才进入专家候选；外部失败时回退本地结果，并复用已经完成的 SAM3 候选。
